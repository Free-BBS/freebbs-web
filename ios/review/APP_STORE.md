## 中文文案草稿

副标题：让知识连接，让讨论发生

宣传文本：从课程知识点出发，阅读资料、参与讨论，把学习中的每个问题变成新的连接。

描述：

FREE-BBS 是课程学习与讨论社区。你可以浏览课程知识点、阅读课程资料，与同伴讨论问题，查看回复及公告，并管理自己的个人资料。

- 浏览课程与知识点，按知识、基本信息和应用分区阅读。
- 参与讨论，阅读公式、代码、图片及表格，发布 Markdown 内容、指定评论回复与点赞。
- 在电路实验室、电路挑战和代码实验室中运行实验，使用 HTML 工具工坊，分享实验结果。
- 查看回复、互动及课程公告，标记已读。
- 查看个人学习日程与重要事项摘要。
- 使用 Max 辅助理解知识，首次使用时确认数据发送，选择按账号在本机保存，可在「我的」撤回。
- 举报不当内容、屏蔽用户，或在 App 内发起账号删除申请。

注册需要课程组白名单及邮箱验证。公开课程和讨论可直接浏览。AI 回答可能有误，应结合课程资料核实。

关键词：课程,学习,知识点,讨论,校园,信号,电路,数学

版权：待填入经确认的运营主体及年份。

## 审核员说明草稿

本 App 面向课程学习社区。未登录可查看公开课程、知识点和讨论。账号注册使用课程白名单；为避免审核员被白名单与邮件验证阻挡，应提供专门的普通用户审核账号。

审核登录用户名、密码：通过 App Store Connect 的 App Review Information 私密填写，禁止提交到 Git。不能使用 README 中的管理员种子账号。

登录路径：我的 → 登录或注册 → 输入账号和密码 → 继续 → 完成随机的能带或文氏振荡器互动题 → 登录。服务端题目与账号绑定，五分钟过期，每次提交后需要重新获取。审核员需获得清楚的题目操作说明，不提供绕过验证的后门。

审核路线：

1. 今日 → 课程 → 进入知识点 → 切换三个分区 → 课程资料。
2. 讨论 → 查看详情 → 回复/点赞；右侧内容菜单举报和屏蔽。
3. 讨论右上角发表 → 选择版块 → 填写文字 → 预览 → 发布。
4. 今日右上角通知 → 打开回复 → 标记全部已读。
5. 我的 → 编辑资料、已屏蔽用户、帮助与联系。
6. 我的 → 删除账号 → 密码验证 → 提交删除申请。需补充实际执行期限与流程，当前只实现申请队列。
7. 实验室 → 电路、挑战、代码或工具工坊 → 运行/预览 → 导出或分享。
8. 今日 → 问问 Max → 查看数据发送说明并确认 → 输入课程问题。

后端及 AI 服务需要在整个审核期间保持可用。App 不要求校园 VPN；专门审核账号应能够访问准备好的课程、通知与日程示例。审核员邮箱无需注册新账号。

## App Privacy 问卷初稿

| 数据 | 与身份关联 | 用途 | 跟踪 |
|---|---|---|---|
| 姓名、邮箱 | 是 | 身份与账号功能 | 否 |
| 用户 ID、学号、用户名 | 是 | 账号、课程白名单 | 否 |
| 讨论、评论、个人简介、AI 问题 | 是 | 社区、学习、AI 回答 | 否 |
| 举报、删除请求及客服信息 | 是 | 支持与安全处理 | 否 |
| 服务器 IP/访问及故障日志 | 按实际部署核实 | 安全、故障排查 | 不应跟踪 |
| 校园日程等工作台数据 | 按实际部署核实 | 学习日程 | 否 |

没有广告、分析 SDK 或跨 App 跟踪。无 ATT 提示。随包的 `PrivacyInfo.xcprivacy` 是基于此客户端代码的初稿，不替代 App Store Connect 的隐私问卷；须核对服务器与 AI 服务商实际处理。

年龄分级需在当前 App Store Connect 问卷中根据 UGC、AI、内容过滤和实际内容回答，不能随意预先宣称 4+。中国大陆分发如涉及 App 备案等要求，需由运营方根据实际主体和分发地区确认适用性，当前网页 ICP 备案不能自动当作 App 的备案材料。

## 提交顺序

1. 注册 explicit App ID，创建 App Store Connect 记录并匹配团队、Bundle ID。
2. 确认运营主体、AI 数据处理说明、保留期限与删除执行期限，审批隐私政策。
3. 发布可公开访问的 HTTPS 隐私政策与支持页面；配置 URL 并在 App 内验证。
4. 部署迁移 032 和后端接口，完成普通/管理员权限及实际举报、删除全链路验收。
5. 提供审核账号，确认注册白名单不阻挡审核。
6. 使用 Xcode 27 与 iOS 27 真机/模拟器执行页面验证，另测试小屏、大屏、横屏、深色、大字、减少透明度和 VoiceOver。
7. 签名 Archive，Validate App；通过 TestFlight 安装并确认 Release 版本不载入 Debug 示例。
8. 使用真实 Release 内容拍摄 App Store 截图。当前自动测试截图带示例标识，仅供开发审查，不直接作为商店宣传。
9. 填写隐私问卷、年龄分级、描述、支持 URL 和审核说明，最后上传并提交。
