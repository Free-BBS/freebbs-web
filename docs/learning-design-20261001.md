本文件保留2026年10月1日至2日的阶段记录。2026年10月3日的当前实现、十二组合和验收边界，以 [学习链设计与实现](learning-chain-20261003.md) 为准；使用导引见 [学习指南](learning-guide-20261003.md)。旧版起点措辞、目的与原文克隆笔记空间已由本轮统一正文、私人批注和四起点三目标方案替换，以下旧流程不作为当前接口或发布依据。

2026-10-02 · 本地实现及下一阶段边界

## 一、学习页面的闭环

课程入口 → 章/板块 → 知识概览 → 正文与知识起源 → 自测或参与讨论 → 回看/订正/继续下一步。

每次进入课程页，必须确认本人对这门课程的熟悉程度：“还没接触过 / 见过但不稳 / 能独立做基础题 / 想深入”。本人上次选择可预填，本次目标可选；同一标签页、账号和课程内切换知识点不重复询问，未确认的知识点直达入口仍会询问。可随时调整。选择按账号在本浏览器保存，确认票据仅在当前标签页与会话复用；存储或加密能力不可用时仅在当前页面确认，不影响进入学习。

该选择是学生自述而非测评结论。右侧 Max 请求只附带枚举偏好，服务端重新构造难度提示，不自动提问，不限制资料，不改变分数、星级或管理员统计。

正文、资源、题目、继续、笔记、共建是六个工具入口，不是六种互相复制的页面。右侧继续使用现有 Max/讨论面板；“继续学习”只呈现可调整的行动结构，打开 Max 不自动发送问题。

| 工具 | 当前作用                                     | 不做什么                                 |
| ---- | -------------------------------------------- | ---------------------------------------- |
| 正文 | 官方内容、知识起源吸顶、章网络               | 不混入私人笔记或评分配置                 |
| 资源 | 知识点资料区暂为占位；共建接收资源推荐       | 不将未审核投稿直接公开                   |
| 题目 | 自测、错题订正、本文练习、人工复核           | 不以 AI 草稿或练习正确代替正式自测证据   |
| 继续 | 基于当前版本题目证据和个人选择给出可调整步骤 | 不重新建聊天框，不自动开始、不自动写日程 |
| 笔记 | 原文克隆视图上的高亮、下划线、评注及补充笔记 | 不修改官方正文，不默认送入 RAG           |
| 共建 | 纠错、优化、资料推荐及课程组处理             | 不由普通投稿自动覆盖讲义或发布资源       |

推荐默认只给几步；保存路径保留用户顺序和完成/跳过选择。路径手工完成不等于自测通过。历史正文上的路径保留，并提示核对版本。正式题目缺失时推荐不得声称已有掌握证据。

同题练习与正式自测分开取最近记录；练习正确不能清除正式错题，正式订正通过后才更新。编号顺序排除末段全零的章节点，但允许“00”绪论章里的普通知识点。手工标签和最近知识点在本浏览器内按账号隔离，刷新登录令牌不更换归属；旧版没有账号归属的存储原样保留，不自动分配给任何账号，也不作为新版推荐证据。

原文评注用节点、完整正文 SHA256、块锚点、文本范围和上下文定位。更新后只在可靠匹配时重定位；有歧义时保留为待定位，不随意贴到相似文字。公式、表格和图片可整块评注。

## 二、课程图放在哪里

课程首页左侧约2/3是图，右侧约1/3是知识点选择器与当前详情。默认只显示0级章/板块，使用真实章名；选择一个章只筛选选择器，不展开整章1级知识点。选择一个知识点后才显示它与全课程直接一跳知识点的关系，跨章关联按真实归属聚合为卫星，不递归铺开二跳。

选择器按章、名称、编号与别名筛选，每页最多40项；大量知识点不会一次生成全部按钮或全章图。点击关联节点可重新聚焦，返回操作同时恢复对应选择器页；退出聚焦返回0级章节图。旧目录视图保留供快速浏览，其“查看知识关系”也进入同一单点关系视图。在图中点击知识点后先看详情/学习概览，再主动进入正文。窄屏改为单列排布，跨章区域放在下方；缺0级稿时只显示现有章成员摘要，不伪造章稿或章关系。

当前使用既有坐标与确定性防碰撞布局，未新增 ELK Worker。已有 ordered/related 接口保持兼容，不冒充纲要中的六类学术关系；课程先后顺序与学术关系区分。ELK Worker、六类关系迁移及完整复习范围是后续工作，不作为本次已完成能力。

## 三、为什么分开记录

从纵向看，学习管理系统逐渐从成绩、完成条件扩展到事件日志和学习分析，但日志变多不等于能得出可靠的能力结论。从横向看，Open edX 将内容完成与成绩区分，Moodle 的预测模型明确依赖课程条件、时间片和足够的数据。我们据此采用“先可复盘事实、再检验解释”的阶段设计，不在184位公测用户、30—40位近期常用用户的条件下推出风险预测或能力画像。这里的取舍是本项目的推论，不是其他产品为本项目背书。

| 数据                 | 来源                                       | 可说明             | 不能说明                       |
| -------------------- | ------------------------------------------ | ------------------ | ------------------------------ |
| 知识点访问、工具打开 | 浏览器上报                                 | 使用入口、参与路径 | 学会、认真程度                 |
| 活跃时长估计         | 前台可见、有焦点、近期交互，服务端间隔封顶 | 记录到的参与时间   | 全部学习时间、净学习时间或能力 |
| 自己标记学过         | 用户主动选择                               | 主观进度           | 已通过正式题目                 |
| 题目作答/复核        | 服务端确定规则及课程负责人                 | 某版本某次作答结果 | 当前全面掌握或课程成绩         |
| 评注、路径、投稿动作 | 功能保存成功后                             | 使用了哪些工具     | 笔记质量或思维水平             |

个人页和管理员页按次数显示自测统计，包括重复作答和历史版本；推荐只采用当前正文与题目版本的最近正式证据。待人工复核不计通过或未通过，练习与正式题单列。参与数据不用于学生排名、考核、星级或六维雷达图。

星级另用必要测评业务证据计算，不依赖可选的过程记录。当前发布自测块的全部题目，逐题最新正式作答均与当前正文、题目版本匹配并已判通过，才授予自主学习星；主观题需人工复核。先取最新正式作答再校验版本，正文回滚不会重新启用被较新失败或待复核作答覆盖的旧通过。既得星保留来源，后续正文变化不撤销历史星。核心/一般节点显示三星，拓展节点二星，章节不计；课程点亮排除拓展与章节，未明确分类的节点不能被跳过。课程学习、深入掌握、完整复习和全面掌握尚无完整可信判据，保持灰色，不猜测授予。本次不发放货币奖励，界面不展示获取条件。

## 四、隐私与控制

细粒度过程记录默认关闭，用户在自己的主页主动开启。关闭后停止浏览器和服务端过程事件；笔记、路径和自测的必要业务保存仍可用。过程记录不含笔记、聊天、题目答案正文、自由文本、浏览器指纹或外站浏览轨迹。

用户可查看自己的统计、逐页导出过程 JSON，或删除全部过程记录并暂停收集。删除只影响学习分析，不删除自测结果和笔记。过程事件保留180天；界面和接口明确口径。管理员仅查看事实聚合与各用户计数，不因该新功能获得私人正文读取权限；课程资料维护权限不等于全站学习数据权限。

后台页以参与人数、课程分布、访问与正式自测/练习计数为主；小样本明确提示仅展示计数，不作群体结论。不按通过率、时长或活跃度对学生排序。相同请求 UUID 幂等，数值/事件类型严格校验；评分事件只允许服务端生成。

管理总览新增“学习变化证据”，与“使用与参与”分开。仅在同一学生、课程、知识点、题目、完整正文版本和题目版本下，比较统计窗口内首次与最近一次正式已判作答，分别显示未通过后再次通过、暂无后续已判复测、通过后再次未通过，并标明组数和人数。练习、待复核、不同版本不混入；没有复测不计失败。可比较人数少于5人时只显示计数，不作群体结论。同题结果变化仅为初步证据，不能单独归因于平台，也不能代替迁移或长期掌握测量；这两项尚需后续设计新任务、延迟测验与自愿反馈。

签到、钱包或资料刷新不算再次访问知识点。浏览器事件每用户每60秒最多120条，配额在数据库事务中按用户统一校验；合法重试不重复占用，服务端评测事件及导出、删除、偏好控制不受浏览器配额限制。

## 五、纲要的调整建议

保留5.6“不排名、不贴标签、结果可解释可复盘”的原则。将“学习净时间”区分为用户规划的预算与系统估计的参与时间，不将浏览器时间当真实净时间。把日志中的过程证据、主观状态、正式测评结果分开，不把它们合并为无解释的完成度。

当前继续步骤先使用可解释规则，依据题目证据、用户标记、有效知识点顺序和用户保存路径。RAG 可以在右侧给补充帮助，但不伪装已完成课程组前置关系模型。完整学习/复习双入口、复习预设、全局错题/路径入口、时间预算和工作台计划联动须另行实现、验证；本次不显示虚假的可用入口。

本地重开预览：在开发仓库运行 `npm run preview:learning`。默认端口3152；若已有预览占用，设置环境变量 `LEARNING_PREVIEW_PORT=0`，启动日志会给出实际空闲端口。设置 `LEARNING_PREVIEW_RELATIONS_DEMO=1` 可查看两章、多知识点的单点关系图夹具，不是正式教材。预览为内存记录，重启后清空；浏览器中的手工标签仍按模拟账号隔离保存在本地。

设置 `LEARNING_PREVIEW_EVIDENCE_DEMO=1` 可通过本地正式提交与复核接口生成模拟学习变化及星级证据，不写入生产数据库。使用 `npm run test:learning-stars` 验证授星与入口选择规则，`npm run test:learning-stars:browser` 验证隔离页面；运行浏览器测试需可用 Puppeteer 和 Chromium。
