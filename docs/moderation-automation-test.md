# 讨论区自动审核：台式机测试版

本版沿用现有禁止清单与严格模型输出校验，在隔离测试网站上提供提交后的文字与图片自动审核。文字模型为 `qwen3.6-27b`，图片模型为 `kimi-k2.6`，`glm-5.1` 为负责人手动文字试审的备选；不修改 Max 问答或系统模型设置，不在调用失败后自动换模型重试。

## 启用与范围

- 必须同时开启 `DISCUSSION_MODERATION_ENABLED`、`DISCUSSION_MODERATION_AI_TEST_ENABLED`、`DISCUSSION_MODERATION_AUTO_TEST_ENABLED`，网站地址、API 监听地址和数据库主机均为本机。自动模型固定为 `qwen3.6-27b`、备选固定为 `glm-5.1`；错误配置不启动机器处理。
- 配置可设置 `DISCUSSION_MODERATION_AUTO_MODEL=qwen3.6-27b`、`DISCUSSION_MODERATION_BACKUP_MODEL=glm-5.1`。未设置时即为这两个值。
- 含图自动审核另外要求 `DISCUSSION_MODERATION_AUTO_IMAGES_ENABLED=true` 和 `DISCUSSION_MODERATION_IMAGE_MODEL=kimi-k2.6`。关闭此开关时含图稿继续交人工。
- 启动幂等创建 `069_moderation_automation.sql` 的两个新表及 `070_moderation_image_reviews.sql` 的图片复核表。首次安装及图片版更新后暂停自动队列；管理员在审核工作台点击开启后处理队列。暂停状态跨重启保留。
- 只给自动测试开关开启后新提交的讨论区帖子、评论创建任务。已有公开内容和此前待审稿不补审。管理员、老师和普通用户遵循相同流程。
- 本版只验收虚构测试内容。运行环境只检查本机地址，无法识别是否为虚构数据；真实用户内容外发告知、提供商处理约定和生产运行方案仍需另行完成。

## 实际流程

1. 发帖或评论时，待审稿、附件绑定、机器任务和负责人站内提醒在同一事务保存。提交接口无需等待模型返回。
2. 后台每秒检查队列，整个数据库同时最多一个自动任务调用模型。先读取不可变稿件版本，检查原稿标题和正文的政治、心理关键词；任一类触发即转人工，记录“本次未调用模型”，不再调用 Qwen 或 Kimi。未触发时在本机脱敏，再发送文字副本。原稿不被改写；本地识别仍可能遗漏姓名或宿舍别称。
3. 文字可放行后，已上传本站的图片交 Kimi，每批最多 3 张，按顺序覆盖全部附件（最多 12 张）。文字已需人工或暂拦时可跳过图片请求。发送前与发布前均核对附件归属、绑定、大小、哈希与有效期。只发送验证过的本站图片，不抓取外链。送审文字中的这些附件地址替换为图片占位符，图片替代文字和其他隐私仍照常识别。
4. 结果回到本机后，再次校验模型、设置版本、规则版本、结构、规则编号、逐字证据、稿件版本及脱敏快照，并在发布事务内重算最终处置。机器执行者单独记录，不冒用管理员身份。
5. 文字与全部图片均严格通过、最终处置为允许、没有未解决事项、没有脱敏命中、没有关怀或政治重点提示且仍有负责人时，原稿进入讨论区正式表，并产生正常业务奖励和通知。
6. 含图内容自动发布后，负责人收到明确的“单独复核图片”站内提醒，稿件进入“图片待复核”队列。负责人逐张查看后确认无问题，或填写理由撤回整份帖子/评论。确认无问题后仍可撤回；“机器已审”与“人工已复核”分别记录。

| 情况                                       | 稿件状态与后续处理                                   |
| ------------------------------------------ | ---------------------------------------------------- |
| 正常纯文字，全部检查通过                   | 自动发布，负责人可复核、撤回                         |
| 明确违反禁止规则，模型结果有效             | 机器暂拦，保持待审；负责人最终通过或驳回             |
| 模型建议重点复核、未知等级或类别、结构不符 | 保持待审；有可用线索时展示为“尚未核实”               |
| 接口超时、拒绝、网络错误或保存失败         | 不因错误放行；转人工或待租约恢复后转人工             |
| 脱敏命中、模型报告隐私疑点                 | 继续人工检查，即使脱敏文字无风险也不自动发布原稿     |
| 文字与所有图片均通过                       | 可先发布，负责人收到图片单独复核提醒并进入专门队列   |
| 空白图片、关键信息缺失、模型表示无法辨读   | 统一转人工，负责人通过前不发布；不据此认定违规       |
| 政治相关关键词或模型提示                   | 统一转人工，负责人通过前不发布，单独突出政治相关提示 |
| 心理相关关键词、求助或关怀提示             | 统一转人工，负责人通过前不发布；不自动认定违规或诊断 |
| 没有可用负责人                             | 不自动发布                                           |

GLM 试审仅影响当前详情内的一次手动调用。它不会重新加入自动队列，也不会直接触发发布；仍需负责人点击通过或驳回。

图片目前发送的是本站规范化后的原图内容，**未做可靠的图片内文字脱敏**。文字副本本地脱敏不代表图片已脱敏；仍只在虚构内容的台式机测试环境启用。机器判断隐私时，普通理由与说明使用受控的隐私类型表述，原始模型判断、OCR 与逐字证据仅供有权限的负责人在折叠区查看。理由替换不代表模型本身的判断已改进。

空白与不可读图片统一转人工：任意一张图片被模型描述为整图空白、没有可辨识内容或无法可靠判读，即使模型同时建议无风险，本地也暂缓发布，不再要求正文必须依赖图片；刻意上传的纯白背景测试同样转人工。没有文字但主体清楚的正常风景、人物或物品照片照常审核，不把 OCR 为空等同于空白。此兜底检查的是模型的观察与理由，不是独立 OCR 或可靠的像素质量鉴定；若模型完全漏报图片状态，仍可能遗漏，所以自动发布的含图稿仍保留人工复核。

## 政治与心理：关键词强制人工 + 整句语义判断补充

这两类采用独立于禁止清单的本地人工复核规则。出现词库中的政治人物、政治制度、政治议题或心理相关关键词时，不等模型认定风险，直接保留待审并通知负责人。课程、学术、新闻引用、否定表达、本人声明“只是测试”等语境均不自动豁免；负责人核实后仍可以正常通过。关键词本身不是违法证据或心理诊断，也不能仅据此处罚用户。

原稿标题与正文在本地脱敏前检查，避免人物姓名被脱敏后漏过。图片则在 Kimi 返回的 OCR 与图片说明中检查；任意一张触发，整份稿件在负责人通过前不发布。图片触发不依赖模型是否列出风险类别或规则编号，模型建议无风险也不能覆盖本地转人工要求。图片检查仍依赖模型实际读出的内容，无法保证覆盖未识别出的文字或所有暗语、别称。

词库采用 2026-10-12 用户确认的 278 条：政治 229 条、心理 49 条。台湾、四通桥、8964、6.4、六四、XJP、JZM、CPC、CCP、人大独立触发；其他未保留的宽泛词没有重新加入。数字和拉丁缩写按完整片段匹配，忽略大小写和全半角；6.4 不扩展为 64、六月四日，也不匹配更长版本片段。

未命中词库时，自动审核同一请求另外返回 `reviewTopics`：political、psychological 各为一个证据数组。模型结合整句、标题和本次送审图片判断，不读取其他用户历史、不建立政治立场或疾病画像；本版不额外读取评论父帖或更远对话，因此依赖省略上下文的指代仍可能遗漏。相关语义即使无违规、无自伤紧迫信号，也转人工。正常校园建议、技术崩溃、普通短暂考试紧张是负向对照，不能无依据牵强推断。

字段缺失、类型错误或证据不在对应输入中时，自动审核不放行，也不补造空数组或自动重试。逐字校验只能验证文本引用自洽，不能证明模型语义判断正确；图片观察仍依赖 Kimi。旧七字段手动试审仍兼容，不能用其结果绕过新版自动审核要求。

工作台分别显示政治与心理重点面板，同时触发就同时显示。面板区分固定关键词和整句语义触发；语义原句及理由放在负责人可见、默认折叠的受限依据中，通知中不包含这些原文。心理提示要求核实支持需求，不把普通求助认作违规，也不作疾病诊断。负责人收到的是分类明确的站内提醒；通知不等于已经阅读、救助或完成复核。

## 暂停、失败与并发

暂停不会关闭人工审核或公开待审稿。已开始的外部请求可能仍完成，但暂停版本变化后，其迟到结果只能转人工；暂停后再开启也不能使旧结果复活。暂停期间的新稿保存在队列，开启后可依次处理。

机器任务具有一次性租约（最长 5 分钟，覆盖多批图片请求）。服务重启后尚未领取的任务可继续处理；已领取但中断的任务在租约到期后转人工，不自动重复付费请求。负责人抢先处理、稿件过期、版本变化或重复返回均不再发布。正式帖子、评论、奖励与通知的写入同事务提交，失败时一起回滚。

负责人收到的是站内通知。现有页面会刷新未读数；本版没有新增短信、离线推送或即时邮件。负责人需主动关注工作台，通知不等于已经完成复核。

## 撤回与保留期限

只有当前负责人可以撤回机器自动发布的内容，必须填写原因。撤回隐藏正式帖子或评论、清除对应置顶/精华，并更新相关站内通知中的正文快照；作者在自己的私有审核记录里可读撤回原因。重复提交同一撤回请求不会重复处理，失去负责人资格后不能继续操作。

撤回沿用讨论区软删除，不自动追扣此前业务奖励；已被用户阅读或已发送到外部的通知无法召回。没有自动封禁、处罚或删号。

审核正文副本、自动判断、脱敏元信息和撤回理由按提交创建时间保存 30 天，到期清理。任务已过期时不再外发、不再放行；保留必要状态标记用于去重。正常公开帖子和仍使用的正式附件不会因审核证据到期而删除。证据到期后的内容管理通过原有讨论区管理功能执行。

本机数据库备份、下载的测试报告及 API 供应商留存不属于上述自动清理范围。更新包不包含配置、密码、密钥或数据库备份。

## 台式机验收

更新后先确认 `/api/health` 返回 `ok:true`，`moderationAutomation.enabled:true`、`paused:true`、`model:qwen3.6-27b`、`backupModel:glm-5.1`。在工作台按 `Ctrl+F5`，管理员点击开启后，再提交新的虚构稿件；旧待审稿仍按人工流程处理。

1. **普通建议**：“建议自习室增加几个插座，方便同学使用电脑。”等待数秒后刷新讨论区和审核详情，确认仅发布一次且有通知。
2. **虚构骚扰**：“让我们每天轮流在这个虚构账号的帖子下面辱骂，直到对方退群。”应保持待审，查看机器依据，再由负责人处理。
3. **虚构隐私**：“我是李星云，2025010000，紫荆一号楼629A，欢迎来找我。”应继续人工检查；本地脱敏和模型结果可在自动记录查看，公开区不出现待审稿。
4. **图片**：提交普通建议及不含真实信息的正常测试图。全部通过后，应自动发布、通知负责人单独复核图片并出现在“图片待复核”中；打开原图确认后标记已复核，队列移除且仍可以撤回。分别提交关键文字模糊图、纯白空白图，以及多图中只有一张空白图的稿件，都应保持待审、等待负责人决定，不标成已经违规；正文完整或声称“只是背景测试”也不豁免。清晰但无文字的照片仍按视觉内容审核。如发生误放，先撤回并保留此次原始/本地处置报告。
5. **暂停**：暂停后提交普通建议，确认未自动发布；再开启，确认队列继续处理。
6. **撤回**：打开第 1 条自动发布记录，填写“虚构验收：测试撤回”后撤回。确认讨论区不可见、作者可见原因、重复点击不重复处理。
7. **GLM 备选**：在仍待审稿件中选择 GLM-5.1 手动试审。确认自动默认仍是 Qwen，结果只作人工建议。
8. **严格关键词人工审核**：分别提交“政治学课程作业：比较不同政治制度。”、“新闻阅读笔记提到了习近平。”、“心理咨询课程介绍。”和“这段材料讨论抑郁症，但不是求助。”，都应保持待审、显示对应触发词和“本次未调用模型”，负责人收到有区别的重点提示。课程、引用、否定语境不能自动通过，正常求助不应被当作违规处罚。再用一个同时含“政治制度”和“心理咨询”的虚构稿验证两类面板同时显示；将关键词只放在清晰测试图片中，验证 Kimi 读出后整稿转人工。普通建议对照仍按原流程自动审核，负责人可以人工通过这些内容。

真实调用按现有渠道计费；耗时包含排队、网络和模型响应。3–5 秒是待实测目标，接口变慢不会被当成通过。不要为了功能验收重复执行多模型 100 条批测；上述少量样例验证的是实际提交到发布、通知与撤回的完整流程。

## 开发验证

`npm run test:moderation-policy` 包括自动 worker、图片读取与合并、路由权限、人工流程、策略和页面回归。`npm run test:moderation-images` 验证图片请求、输出处理、评分和合成样例。`node scripts/test-mysql-isolated.js --moderation-only` 使用新建隔离 MySQL 实例验证任务事务、并发、附件发布、复核队列、暂停、撤回及原有审核存储。浏览器验收使用真实页面和合成接口，覆盖桌面/手机、浅色/深色；这些本地检查不替代台式机真实渠道验收。新版定向模型复测见 `docs/moderation-image-evaluation.md`。

## 新版语义定向验收

`node scripts/moderation-topic-evaluation.js` 仅预览固定虚构样例，不读取配置或数据库、不调用模型。加 `--run` 后读取台式机本地测试库的现有模型渠道，最多串行调用 Qwen 12 次；另有 4 条关键词本地样例，总计 16 条。连续 3 次接口或格式失败即停止，不重试、不发布帖子、不改审核记录。报告写入 `F:\FreeBBS-Test\moderation-topic-results` 的新时间目录。该脚本检查话题路由，不能替代违规类别评测、图片渠道测试或实际发帖验收。

更新脚本完成后队列保持暂停；先跑定向测试并检查每条原句依据，再开启队列，用一条普通建议、一条关键词稿、一条无关键词的心理困扰稿及一张清晰含政治关键词的图验证实际通知、人工通过与撤回。没有实际渠道报告前，不宣称识别率达标。
