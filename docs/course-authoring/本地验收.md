## 重开预览

在开发仓库运行npm run preview:learning。默认3152端口；端口占用时设置LEARNING_PREVIEW_PORT=0，启动日志会给出可用地址。设置LEARNING_PREVIEW_RELATIONS_DEMO=1可看大量知识点和跨章单点关系夹具。

- 课程入口：/course?course=signals
- 知识概览：/knowledge?course=signals&point=SS-01-01
- 正文与题目：/knowledge?course=signals&point=SS-01-01&view=reading
- 章节整体网络：/knowledge?course=signals&point=SS-01-00&view=reading

预览使用模拟身份、模拟AI和内存记录，重启后必要业务数据清空。正式发布前须替换演示内容、完成课程负责人复核，并按README执行离线检查和回读。
