# FREE BBS 学习世界本轮改动与课程组交付

2026-10-03，V4.2。本次为本地代码与模板适配，未上线，也未上传正式课程资料。

## 一、本次改了什么

### 1. 课程入口与知识关系

课程入口默认展示0级章节图，章节使用实际名称，不再只写“第X章”。右侧可按章、名称、编号或别名选择知识点，每页最多40项；不再展开一整章的全部1级知识点。

选中一个知识点后，图中只显示它及直接关联的知识点。关联可以跨章，但限于同一门课程；跨章节点按实际归属分组，不递归展开二跳。点击关联节点可重新聚焦，返回时恢复对应的选择器分页，退出聚焦返回章节图。手机采用单列排布，跨章区域放在下方。

章节0级稿内部的本章整体网络图仍保留，与入口的单点关系图分别使用。章关系只显示已经发布的真实0级连接，不从知识点连接推断。

### 2. 概览、正文与知识起源

知识概览统一课程、章节、名称、类型、层级、难度、重要程度、建议时长及参与同学字段，首屏精简，完整资料可折叠查看；可从概览查看知识关系或进入学习。

正文前保留“为什么学习这个知识点”的知识起源，使用紫色吸顶区域，可收起；公式、图片、正文练习与折叠参考解答继续使用现有Markdown渲染。没有起源或正式章稿时不生成虚构内容。

### 3. 学习反馈与自测

学习反馈以题目为主体，增加可作答的题卡与明确评分规则：

| 题型                 | 当前判分方式                                       |
| -------------------- | -------------------------------------------------- |
| 单选                 | 完整匹配标准选项，正确得满分，错误得0分            |
| 多选                 | 选项集合完整匹配；漏选、多选不给部分分             |
| 数值                 | 有限标量数值，按明确的绝对/相对容差判定            |
| 简答、计算过程、证明 | 依据rubric由有权限的课程负责人人工复核，可给部分分 |

正式自测、练习与可选探索分开。题目可标基础/标准/挑战（教师估计）、学习目标、解析与常见误区。未审核题目保持draft；只有published块中的selftest题且来源、审核人、版本和评分有效，才进入正式自测。自测始终要求全部正式题，练习筛选不缩小分母，探索不混入分母。主观题待人工复核，同题练习不替代正式订正，历史版本不充当新版通过。当前正式自测有效通过证据可用于自主学习星，不自动换成课程成绩或全面能力评价；深入掌握后续开发。

### 4. 继续学习

“继续”改为简短、结构化的下一步建议，首屏展示一个主要步骤、最多两个替代入口和简短顺序链。学生可自述四个起点（第一次学、不甚熟悉、能独立做题、完整掌握）并选择三个目标（理解知识、练习解题、探索研究），复用同一份正文和分层题目。自述不是测量能力，不替代正式评测；也不要求所有人依次阅读、做题、拿星。

步骤支持调整顺序、完成、跳过和保存；推荐依据当前版本正式自测结果、个人标记与已保存路径，默认先后顺序按有效知识点编号，不把关系连线当作学习顺序。真实错题与待复核状态会提示，学生仍可主动查阅或探索；已保存路径及未保存的手动调整不被新推荐覆盖。

右侧Max与讨论面板继续共用，不另建重复聊天区；打开Max不会自动发送问题。手工完成路径不等于自测通过，建议也不会自动写入个人工作台日程。

### 5. 个人笔记与参与共建

个人笔记直接在唯一官方正文上提供私人高亮、下划线、评注及补充笔记，不另维护正文副本，不改变官方文字。评注绑定正文版本和原文位置；正文更新后只在可靠匹配时重定位，有歧义的保留为待定位。记录按账号隔离，不默认送入RAG。

共建支持纠错、优化和资料推荐，并提供课程组审核及回复。投稿不会直接覆盖正文或公开发布资源；采纳后仍需课程组修订、审核并通过原有接口发布。知识点资源入口目前仍是占位。

### 6. 学习过程记录

过程记录默认关闭，用户可以主动开启、查看、导出或删除并停止收集，保留180天。过程数据不包含笔记、聊天或题目答案正文；删除过程数据不删除自测和笔记等必要业务记录。

时长只是前台可见、有焦点且近期有交互的参与估计，不是净学习时间。管理员看到事实计数，不据此排名、授星或贴能力标签。手工学习标记和最近知识点也按账号隔离，身份绑定、钱包更新和令牌刷新不改变归属。

## 二、课程组需要交什么

继续使用三个固定二级分区：基本信息、知识背景与应用、知识点正文。每个知识点提交一份完整稿；每章提交一份0级章节稿，另附关系表、布局表和课程提交清单。

四起点与三目标不新增上传分区，不要求十二份正文；课程组维护统一正文与真实题目用途、难度估计、作答后解析及误区即可。探索问题不自动授星，正式自测仍核对当前版本全部正式题。

- 概览首段不超过150字符；起源说明问题背景与学习意义，正文保留条件、推导、例子和依据。
- 统一使用实际章名与“参与同学”字段；署名、教材引用和图片授权须确认。
- 学习反馈题目具完整题干、来源与折叠解答；若需题卡判分，在正文末尾追加唯一的freebbs-quiz配置。
- 四种评分题型都有可复制模板；题目、评分、审核和版本须同步，默认draft，不把本地演示题当正式教学题。
- 当前可上传关系类型是ordered/related；六类学术关系尚未迁移。关系表中的教学说明不会自动进入网页或推荐模型。
- 当前整包关系工具只检查1级连接，不录入0级连接；节点位置仅在发布时显式传入，不自动移动已有节点。
- 更新前回读revision，保留旧稿；离线检查通过不等于教学审核或线上发布成功。

详细步骤见[README](README.md)，填稿文件见[templates](templates/)，可运行本地演示见[examples](examples/)。同包工具只做离线检查和导出，不连接真实账号、不自动上传。
