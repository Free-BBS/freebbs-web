## 2026-10-10：V4.3 本地人本流程调整

本轮基于已合入学习更新的主分支 `dde0ac1`，只在 `work/human-learning-flows-20261010` 本地修改，未提交或推送 PR，不操作线上课程、账号或成绩。下方 V4.2 保留历史记录，不代表本轮仍沿用旧分支。

- 进入学习不强制重选目标；起点与目标可选、可记住、可取消。继续学习复用一套正文与真实任务，少量推荐之外可主动查看全部可用入口，不用星数锁定探索或查阅。
- 课程已保存目标不因一次正式错题或刷新而被覆盖；错题、待复核继续单独可见。当前正式要求全通过后，建议里可主动打开下一知识点，不改原有个人路径；自测名称不伪称闭卷或无辅助检验。
- 章节归属与知识联系分开：左侧真实章名、点数与目录，右侧当前点的“可先了解 / 接着了解 / 补充联系”；辅助图默认收起。只显示真实直连，不把编号、章归属或 AI 类比当作先修边。
- 原文批注工具默认收起，点击“批注”打开一条图标工具栏，再次点击可收起，保存不跳转。不在此处调字号，正文随全站阅读设置放大；中断、切工具和开关 Max 后恢复段落，明确链接的题目入口优先。宽表格只在局部横向滚动，手机起源与工具栏不互相遮挡。
- 短窗口里一次只保留一层吸顶区域：普通阅读显示起源，选文时换为批注工具，另一层仍留在原文；不需要为中段评注长距离回到顶端。手机课程目录的焦点滚动避开底部导航。
- 一条工具栏包括高亮、下划线、批注、纠错、问问 Max、撤销和知识概览；前五项须选中原文或整块对象。高亮与下划线各有独立的四颜色菜单，不再把全部色块和说明常驻展开。
- 知识起源的作者原文也使用同一条工具栏，批注模式中仍可见；固定框标题、说明和空态不当作原文。起源与正文分别定位、分别校验版本，相同句子不串标，旧正文锚继续兼容，不新增数据库迁移或课程组字段。
- 批注与纠错在浮动便签中编辑，不占正文正常位置，也不展开下方笔记面板或目录。点击已有标记先看详情，可再编辑或删除；关闭按钮、Escape 和误点普通正文保留草稿及引用，底部“取消”才放弃草稿。纠错先私密保存，只有本人明确提交课程组才进入共建草稿。
- 撤销支持当前会话最多 20 次已确认的保存、修改和删除，不承诺跨页永久历史；删除核对记录版本，发生并发冲突时保护新版本。正文旧版本标注删除须确认且不能自动撤销。取消选区或删除后需重新选择原文才可再标注；图片来源变化时旧批注保留待定位，不贴到同名新图。闭合的参考解答不参与阅读书签，高对比显示下四色选项有文字区别。
- 未提交答案按当前会话、账户、正文和题目版本短期保存；刷新可继续，旧版本不乱填。失败重试保持同一提交意图，成功后清理对应草稿。旧答案与个人历史默认折叠，先尝试再主动对照。
- 当前题目、原文选区与本人主动提供的思路可放入 Max 草稿，仍须明确发送；不自动把批注、答案或聊天写入公开讨论。主动保存 Max 回答时才打开私人补充笔记草稿对话框，不恢复常驻笔记区。Max 是辅助老师，不替正式题评分或授星。
- 选区问问 Max 先在同页询问“这部分你理解了吗？想检查理解，还是需要我解释一下？”，可主动选择“解释一下 / 检查理解 / 我自己提问”。草稿保留来源与引用，不覆盖本人已写的问题，只有发送才请求模型；本地短引导不是聊天记录、能力诊断或掌握证明。
- 同页明确选择临时探索方向后，新的 Max 提问采用该方向，不覆盖课程默认目标；换活动不一定改变目标，没有自述时不虚构熟悉度。Max 的练习小题不计正式自测或星标。
- 窄屏 Max 使用独立面板，不把正文挤成隐式第二列；输入与关闭按钮保持可见，关闭后回到原阅读位置并保留未提交草稿。载入知识点时明确区分等待、失败与缺材料，不先打开空正文或沿用旧点。
- 正文尚未提供或只有题目配置时，不把系统提示存为原文批注或阅读位置；仍可写普通笔记、查资源或做已有题目。不通过句子内容猜测空态，作者写有相同文字的正式正文照常可标注。
- 教师自测复核可继续加载待处理记录，保留其他未提交输入；按提交时题目快照复核，缺失历史快照不冒充当前题。
- 资源入口接入已有公开附件，按真实知识点关联分组；只检查最近 200 份，不宣称全量或自动 RAG。投稿与正式资料发布仍分开。
- 管理端逐人作答列区分全部、正式自测与练习；没有分项不推算，重复与历史次数不等于当前题库通过或掌握。
- 课程组继续三个分区、一个唯一评分扩展、`schemaVersion: 1`；新增题号唯一对应校验，不新增课程字段。旧 Markdown 题不自动提取文字难度来配置分层题卡。星明确为历史学习记录，当前版本通过数另列。

课程组填写与发布边界以本包 README、编写指南和模板为准。界面测试不证明学生学习效果；真实课程内容、MySQL 迁移、线上权限与正式发布回读仍须另行验收。完整跨页 RAG 对话复盘、带权限的资源站内阅读与自动定位尚未完成；现有公开附件列表不是规划中的完整资源库。

## 一、本次改了什么

### 1. 课程入口与知识关系

课程入口默认展示0级章节图，章节使用实际名称，不再只写“第X章”。右侧可按章、名称、编号或别名选择知识点，每页最多40项；不再展开一整章的全部1级知识点。

选中一个知识点后，图中只显示它及直接关联的知识点。关联可以跨章，但限于同一门课程；跨章节点按实际归属分组，不递归展开二跳。点击关联节点可重新聚焦，返回时恢复对应的选择器分页，退出聚焦返回章节图。手机采用单列排布，跨章区域放在下方。

章节0级稿内部的本章整体网络图仍保留，与入口的单点关系图分别使用。章关系只显示已经发布的真实0级连接，不从知识点连接推断。

### 2. 概览、正文与知识起源

知识概览统一课程、章节、名称、类型、层级、难度、重要程度、建议时长及参与同学字段，首屏精简，完整资料可折叠查看；可从概览查看知识关系或进入学习。

正文前保留“为什么学习这个知识点”的知识起源，使用紫色吸顶区域，可收起；公式、图片、正文练习与折叠参考解答继续使用现有Markdown渲染。没有起源或正式章稿时不生成虚构内容。

### 3. 学习反馈与自测

学习反馈以题目为主体，增加可作答的题卡与明确评分规则：

| 题型                 | 当前判分方式                                       |
| -------------------- | -------------------------------------------------- |
| 单选                 | 完整匹配标准选项，正确得满分，错误得0分            |
| 多选                 | 选项集合完整匹配；漏选、多选不给部分分             |
| 数值                 | 有限标量数值，按明确的绝对/相对容差判定            |
| 简答、计算过程、证明 | 依据rubric由有权限的课程负责人人工复核，可给部分分 |

正式自测、练习与可选探索分开。题目可标基础/标准/挑战（教师估计）、学习目标、解析与常见误区。未审核题目保持draft；只有published块中的selftest题且来源、审核人、版本和评分有效，才进入正式自测。自测始终要求全部正式题，练习筛选不缩小分母，探索不混入分母。主观题待人工复核，同题练习不替代正式订正，历史版本不充当新版通过。当前正式自测有效通过证据可用于自主学习星，不自动换成课程成绩或全面能力评价；深入掌握后续开发。

### 4. 继续学习

“继续”改为简短、结构化的下一步建议，首屏展示一个主要步骤、最多两个替代入口和简短顺序链。学生可自述四个起点（第一次学、不甚熟悉、能独立做题、完整掌握）并选择三个目标（理解知识、练习解题、探索研究），复用同一份正文和分层题目。自述不是测量能力，不替代正式评测；也不要求所有人依次阅读、做题、拿星。

步骤支持调整顺序、完成、跳过和保存；推荐依据当前版本正式自测结果、个人标记与已保存路径，默认先后顺序按有效知识点编号，不把关系连线当作学习顺序。真实错题与待复核状态会提示，学生仍可主动查阅或探索；已保存路径及未保存的手动调整不被新推荐覆盖。

右侧Max与讨论面板继续共用，不另建重复聊天区；打开Max不会自动发送问题。手工完成路径不等于自测通过，建议也不会自动写入个人工作台日程。

### 5. 个人笔记与参与共建

个人笔记直接在唯一官方正文上提供私人高亮、下划线、评注及补充笔记，不另维护正文副本，不改变官方文字。评注绑定正文版本和原文位置；正文更新后只在可靠匹配时重定位，有歧义的保留为待定位。记录按账号隔离，不默认送入RAG。

共建支持纠错、优化和资料推荐，并提供课程组审核及回复。投稿不会直接覆盖正文或公开发布资源；采纳后仍需课程组修订、审核并通过原有接口发布。V4.2 当时的知识点资源入口仍是占位；V4.3 已接入有限的已有公开附件，范围见上方当前记录。

### 6. 学习过程记录

过程记录默认关闭，用户可以主动开启、查看、导出或删除并停止收集，保留180天。过程数据不包含笔记、聊天或题目答案正文；删除过程数据不删除自测和笔记等必要业务记录。

时长只是前台可见、有焦点且近期有交互的参与估计，不是净学习时间。管理员看到事实计数，不据此排名、授星或贴能力标签。手工学习标记和最近知识点也按账号隔离，身份绑定、钱包更新和令牌刷新不改变归属。

## 二、课程组需要交什么

继续使用三个固定二级分区：基本信息、知识背景与应用、知识点正文。每个知识点提交一份完整稿；每章提交一份0级章节稿，另附关系表、布局表和课程提交清单。

四起点与三目标不新增上传分区，不要求十二份正文；课程组维护统一正文与真实题目用途、难度估计、作答后解析及误区即可。探索问题不自动授星，正式自测仍核对当前版本全部正式题。

- 概览首段不超过150字符；起源说明问题背景与学习意义，正文保留条件、推导、例子和依据。
- 统一使用实际章名与“参与同学”字段；署名、教材引用和图片授权须确认。
- 学习反馈题目具完整题干、来源与折叠解答；若需题卡判分，在正文末尾追加唯一的freebbs-quiz配置。
- 四种评分题型都有可复制模板；题目、评分、审核和版本须同步，默认draft，不把本地演示题当正式教学题。
- 当前可上传关系类型是ordered/related；六类学术关系尚未迁移。关系表中的教学说明不会自动进入网页或推荐模型。
- 当前整包关系工具只检查1级连接，不录入0级连接；节点位置仅在发布时显式传入，不自动移动已有节点。
- 更新前回读revision，保留旧稿；离线检查通过不等于教学审核或线上发布成功。

详细步骤见[README](README.md)，填稿文件见[templates](templates/)，可运行本地演示见[examples](examples/)。同包工具只做离线检查和导出，不连接真实账号、不自动上传。
