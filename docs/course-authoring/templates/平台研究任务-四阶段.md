# 平台研究任务：课程部提供给战略部的可选模板

此文件用于独立的平台研究，不是知识点正文、正式自测或课程成绩要求。课程部核查知识目标、条件、选项与评分依据，战略部决定研究问题、招募和比较方案。不要为所有知识点强制填写；先选择一个明确的小目标试测。

## 提交前确认

- 前测、后测、间隔复查均覆盖同一目标，难度和条件尽量可比，不能只把同一道题换个编号；题数相同不等于测量等价。
- 新情境题要求把同一原理用于不同表述、条件或应用；仅重新答原题不能证明迁移。
- 每阶段 1–8 道单选题，每题 2–6 个唯一选项；前三阶段题数相同。各题等权，不支持主观题量规、不同题权或自动生成测量题。
- 逐题人工核对正确项及错误选项的含义。若预期专家或科研人参加，先确认任务没有过低的天花板；这套单选任务不能衡量完整科研能力或长期发展。
- 说明是否允许求助、平台外学习和预计用时；网页只记录本人申报的辅助方式，不能代替监考。研究自愿参加，可以暂停或退出，不改变正式评分或星标。
- 替换下方所有【占位说明】后试测。该 JSON 只检查接口结构，自动校验不能证明题目科学有效。

## 复核与版本

课程部在自己的交付记录中保留编写人、审题人、日期、目标覆盖和试测修改依据；这些不是当前接口强制审核字段。当前复用通用管理员权限，没有独立的课程部审核闸门，不能把“发布成功”写成“已通过课程部审核”。

当前研究任务只支持新建，不支持在线编辑、复制或停止招募。改题干、选项或答案时，保存旧稿，更新 `questionVersion`，另登记一项新任务；旧任务不会自动关闭、旧作答不迁移，新旧任务的结果不混合。正式应用前由课程部和战略部共同确认哪些任务可招募，暂不承诺系统能强制停止过时任务。

## 战略部如何解释

把本人体验、同人前后测表现、间隔保持和新情境表现分别报告。对高基线者，零分数增量可能是天花板，不是没有帮助；主观“有帮助”也不能自动转成知识掌握。未提交需区分未到期、前置未完成和已可提交未交，不能一概当成失访或零分。若要判断平台造成了提升，还需可靠测量、合理比较条件、起点与样本偏差分析；这个模板本身不提供因果识别。
