# 分层题目与评分扩展（可选）

将下方唯一围栏复制到“知识点正文”最后，填写占位符，按需保留 1–40 道题。同一道题在正文与扩展中使用相同题号、题干和解答；题号在当前知识点内唯一。普通 Markdown 题目本身不配置自动评分。

所有起点和目标使用同一份正文及本题目集合，不为十二种组合复制教材或试卷。根据课程真实目标安排分层练习、正式自测及可选探索；可不凑齐三档难度。私人笔记与学生答案不写入此配置。

- `draft`：未审核练习，不计入正式测评。审核完成后填写真实 `source`、`reviewedBy`，再改为 `published`；可另加 `reviewedAt`（如 `2026-10-01T00:00:00+08:00`）。检查工具只验证格式，不能代替教学审核。
- 单选 `answer` 是一个选项ID；多选 `answer` 是不重复的选项ID数组。两者均完整匹配，答对得满分，答错、漏选或多选得 0 分，不支持部分分。
- 数值题同步修改 `target` 和两种容差；允许误差为 `max(absoluteTolerance, |target| × relativeTolerance)`。题干写清单位，作答只填数值，可用科学记数法。
- 主观题使用 `short_answer` / `manual`，在 `rubric` 中写明分项及部分分依据；提交后待课程负责人人工复核，不自动判为通过或错题。
- `maxScore` 必须大于 0 且不超过 1000，`passScore` 必须大于 0 且不超过满分；评分数值不能加引号。变更题干、选项、解析或评分时更新 `version`，保留旧稿与历史作答。
- `difficulty` 选 `basic`（基础）、`standard`（标准）、`challenge`（挑战），是课程组对本题的估计，不是实测校准、学生能力定级，也不等于布鲁姆认知层次。可省略，不从知识点的1–5级难度或学生自述起点自动推断。
- `assessmentRole` 选 `practice`（练习）、`selftest`（正式自测候选）或 `exploration`（可选探索）。只有已审核published块中的selftest题计入正式自测；难度筛选不能删减自测分母。练习与探索正确不授正式自测星。旧稿省略本字段时，published默认selftest、draft默认practice。
- `learningObjective` 用不超过600字说明本题检查什么；`explanation`写参考解答、依据和适用条件，`misconceptions`用不超过4000字写常见误区，两者由服务器在作答后返回。不要把标准答案写进学习目标；它会随题干公开展示。普通Markdown的折叠参考解答仍可主动查看，不用于考试答案保密。
