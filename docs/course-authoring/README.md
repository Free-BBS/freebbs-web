# FREE BBS 课程组 Markdown 提交包 V4.3

本包用于统一提交章节概览、知识点概览、正文、知识起源、练习题与解答、章节网络图及知识点关系。课程组填写 Markdown；发布人员审核后用现有课程上传接口提交。不要把账号、密码、Token、学生作答或成绩放进本包。

## 快速上手：下载现稿 → 整理审核 → 预检 → 发布

1. 本包含 `README.md`（本文件）、[课程组编写指南](课程组编写指南.md)、模板、样例和工具。新版公共下载地址为 [课程组模板包](https://www.free-bbs.cn/downloads/freebbs-course-authoring.zip)，需 PR #180 对应版本部署后才包含本轮新工具；下载后先核对 README 与工具目录，不把分支代码当作已上线功能。
2. 登录官网，在“个人设置 → 课程组 Agent 接入”生成个人 Token、下载 Skill。管理员需先分配所负责课程；教师或助教身份本身不授予发布权限。安全配置 `FREEBBS_BASE_URL=https://www.free-bbs.cn` 和 `FREEBBS_UPLOAD_TOKEN`，不要把 Token 写进稿件、命令参数或发给别人。
3. 在模板包目录执行 `node tools/下载课程.cjs signals --out 现有课程-20261012`，下载《信号与系统》的完整作者分区、地图及 revision；其他课程使用自己有权限的课程标识。输出目录必须不存在。工具只读，不包含学生作答、个人笔记或聊天，不下载图片及附件文件本体。完整操作见第六节。
4. 对照现稿填写 `templates/知识点.md`，章概览使用 `templates/章节-0级节点.md`；保留已有 ID，并填写真实章名、知识起源和署名。缺内容需课程组补充，不能用机器编造史实、署名或审核结论。
5. 先离线检查和课程组审核，再执行 `node tools/上传知识点.cjs "课程包/知识点/SS-01-01.md" --revision "上次读取的64位revision"`。默认只校验与读取，不写网站；确认修改范围后追加 `--publish` 才发布该节点的完整三个分区，并回读核验。新建使用 `--revision new --x 200 --y 180`。

已经提供的“514 个节点、781 条关系”公开只读快照用于调试阅读，**不是完整作者备份**：学生公开接口可能裁去评分配置及参考评分答案；它的分区文件也不是可以直接上传的完整模板。课程组更新应先用课程 Token 读取完整作者稿，不直接把公开快照或单独的 `正文.md` 当三分区完整稿覆盖。节点发布会更新正式网站的可见内容，评分扩展 `draft` 不会隐藏整篇正文。

课程组开始编写前，先读[课程组编写指南](课程组编写指南.md)：它说明每个知识点最少交什么、如何区分概览/起源/正文、怎样安排分层题与正式自测，以及谁负责编写、复核和发布。本页保留文件格式、字段、离线检查和上传回读的技术说明。

每个知识点只写一份正文；先完成准确可用的稿件，再按需要加入评分题卡和可选探索，不必一次凑齐所有难度、题型或学习路径。

## 一、从哪里开始

先复制 `templates/知识点.md` 填一份知识点稿，再复制 `templates/章节-0级节点.md` 填所属章；完成后使用三个离线工具检查。其余模板用于提交说明、关系与布局，`自测题-评分扩展.md` 按需追加，不必给一个知识点上传六份文件。

```text
课程包/
├─ 课程提交说明.md
├─ 关系.md
├─ 布局.md
├─ 章节/
│  ├─ SS-01-00.md
│  └─ SS-02-00.md
└─ 知识点/
   ├─ SS-01-01.md
   ├─ SS-01-02.md
   └─ SS-02-01.md
```

0 级节点表示章，末段为 `00`，名称就是实际章名，例如“线性时不变系统的时域分析”。普通节点为 1 级，保持平台已有编号，不因改名或补零而更换 ID。章节 ID 如 `SS-01`；所有同章节点的“章节/单元”填写同一个实际章名。

章节目录优先显示已有真实章名：先取 0 级节点的有效名称，再取普通节点的实际章节字段，不用“第 X 章”覆盖已有名字。只有旧稿确实没有真实章名时才按编号作回退；这不是自动生成的章名，需课程组补齐。0 级节点不计入普通知识点数量，但可以打开章节概览并查看本章网络图；缺 0 级稿不能据编号虚构章节内容。

| 需要准备          | 对应模板           | 填写重点                                     |
| ----------------- | ------------------ | -------------------------------------------- |
| 每个知识点        | 知识点.md          | 概览、起源、正文、学习反馈题目、依据与署名   |
| 每章一个 0 级节点 | 章节-0级节点.md    | 实际章名、目标、本章知识点及整体联系         |
| 自测题卡（可选）  | 自测题-评分扩展.md | 题号、四种题型、评分规则、来源、审核和版本   |
| 课程交付清单      | 课程提交说明.md    | 节点文件、编写与复核、修改范围               |
| 已复核连接        | 关系.md            | 当前可用的 ordered/related，不把章归属当连线 |
| 节点位置          | 布局.md            | 已确认坐标，新建必填，更新不默认移动         |

## 二、填写要求

每个节点文件只保留三个二级标题，名称和顺序不变：

1. 基本信息：填写字段，不删除字段。参与同学列出同意公开署名的编写、修订与复核同学。
2. 知识背景与应用：首段是简短概览，最多 150 字符（含标点）；“知识起源”独立说明问题背景和学习意义，“应用场景”说明用途及边界。150 是本提交包的首段约束及概览展示长度，不是全部上传接口的 summary 上限。
3. 知识点正文：自由组织内容、例子、公式、推导、图片和代码；练习题采用模板的题干、目标、难度、来源及折叠参考解答格式。

其他标题用三级及以下。删除所有双花括号占位符。没有可靠历史资料时，说明知识要解决的问题，不杜撰人物、年份或历史故事。正文和参考解答的数学内容由课程负责人复核；格式检查不代替教学审核。

图片使用已授权、可访问的 HTTPS 或平台资源地址，不填本机盘符路径。公式使用行内美元符号或独立双美元符号。参考解答使用模板中的 details/summary，网页默认收起，点击后可查看。

## 三、网页对应关系

| 提交内容                         | 存储分区                        | 网页展示                                   |
| -------------------------------- | ------------------------------- | ------------------------------------------ |
| 章名、难度、重要程度、时长、署名 | 基本信息.md                     | 章节目录与学习概览；原始资料可折叠查看     |
| 简短概览首段                     | 背景与应用.md，同时生成 summary | 点击知识点后的概览                         |
| 知识起源                         | 背景与应用.md的“知识起源”小节   | 正文前的紫色吸顶框，可收起；没有内容不编造 |
| 正文、例子、题目、参考解答       | 正文.md                         | 知识正文；参考解答默认折叠                 |
| 0 级章节点                       | 同一节点上传接口                | 真实章名、章节概览入口                     |
| 节点布局坐标                     | 节点 position                   | 章节网络图及地图布局                       |
| 同课程学习连接                   | 地图边接口                      | 直接关联与 0 级节点中的章节网络图          |

没有新增数据库分区；整理工具把完整文件拆成现有三个分区。不要将一份完整稿直接当作正文覆盖旧节点，否则概览、起源会错位。网页里的个人笔记、复盘和共建建议属于用户记录，不由课程组稿件覆盖。

学习页的六个工具是正文、资源、题目、继续、批注、共建，不是六个上传分区。课程组主要维护官方概览、正文、起源与题目；“继续”按已上传内容和当前版本自测证据给出步骤。私人高亮、下划线、批注和纠错直接依托这份统一正文，不另建第二份教材，不改变官方文本。文字按选区批注，公式、图片和表格按整块定位；原文更新后仅在可靠匹配时重定位，有歧义的保留待定位。课程组保持稳定 ID、归档旧稿，不填写学生的批注锚点或上传私人记录。共建由课程组审核后另行修稿。

批注默认收起，主动点击后显示一条图标工具栏：高亮、下划线、批注、纠错、问问 Max、撤销、知识概览。前五项需要有效原文选区或整块对象；高亮和下划线分别有四种可选颜色。本处不提供独立字号选择器，正文使用全站阅读设置。

知识起源中的作者原文也可使用这套工具，批注模式下仍可阅读；框标题、固定说明和缺内容提示不参与标注。起源与正文分别保存位置与内容版本，即使有同一句话也不互相定位，起源修订不使未改版正文的标注失效。课程组继续填写现有“知识起源”小节，无需添加批注字段、拆成第二份正文或增加上传分区；已有正文批注继续兼容，无新增数据库迁移。

便签浮动显示，不占正文正常位置或展开常驻批注目录。点击已有标记先查看，再主动编辑或删除；关闭按钮与 Escape 保留草稿，底部“取消”放弃当前草稿。撤销仅覆盖当前会话最多 20 次已确认操作，不是永久历史；正文旧版本标注删除需确认且不能自动撤销。没有可靠位置时保留原记录、不猜新的位置。纠错先是私人记录，主动“提交课程组”才准备共建稿；问问 Max 仅预填问题、不自动发送。保存 Max 回答时才打开私人补充笔记草稿对话框。这些都是网页交互，不新增课程组字段，不要求另写笔记版正文。

选区问问 Max 在同页先询问理解情况，提供“解释一下 / 检查理解 / 我自己提问”三个主动选择。问题草稿带有来源和原文引用，按纯文本处理，不覆盖本人已写的问题，仍需主动发送才调用模型；这个本地引导不保存成已发送聊天、不判定掌握、不改变正式题评分或授星。课程组不用为三个选择另写三套教材，Max 仍以同一套经审核的课程内容辅助学习。

2026-10-11 交互适配不新增上传字段：批注型推荐明确要求选择相关作者原文，只提供起源时也能直接标注起源；缺材料时如实提供求助/暂停，不要求课程组为凑路径编造内容。“先停一下”只暂停本页步骤，不代替保存批注或路径，不算正式完成。Max 未发送问题在同一标签页、同一登录会话与内容版本下短期恢复，最多 24 小时；切账号或正文/起源更新不能自动沿用旧问题，仍不自动发送。首访窄屏先显示正文，再按本人选择打开 Max。课程组继续维护这一套审核内容、适用条件、例子和与目标对应的题目即可。

“资源”沿用已有公开课程附件接口，不新增作者字段或上传分区。按文件的真实 `nodeId` 区分本知识点关联资料和未指定知识点的课程资料；其他知识点附件不伪装为本点资料。当前仅检查课程最近上传的最多 200 份文件，不是全量资料库；加载失败与没有找到资料分别显示。附件发布与限制见本页第十节。

学生可选择四个自述起点（第一次学、不甚熟悉、能独立做题、完整掌握）和三个当前目标（理解知识、练习解题、探索研究）。选择是可选的支持偏好，不是每次进入都要填写的门槛；不选也能阅读、练习或直接自测。主动调整后按账号与课程在本浏览器恢复，取消或 Escape 保留原有选择，不宣称跨设备同步。这些选择只用于推荐下一步、题目入口和 Max 的辅助语境，不是测量得到的能力等级；“完整掌握”的自述不能替代正式作答。十二种组合复用同一份概览、知识起源、正文和题目，不需要课程组编写十二份正文或十二套必做题。

阅读—作答—正式自测是可用的基准通道，不锁定所有人的顺序。学生也可直接自测、查阅关系或开展探索；“继续”首屏给出一个主要步骤、最多两个替代入口及简短顺序链，已保存路径与手动调整不被新推荐覆盖。有正式错题或待复核时提示真实状态，但不封锁主动查阅和探索；任何路径标记、时间或对话都不替代正式自测证据。

已主动保存的目标在下次进入仍保留；标题、完整建议与主入口按该目标一致展示。错题和待复核单独提示并可打开，不自动覆盖探索目标；未主动选目标时仍可优先建议订正。全部当前正式题通过后可选择真实的下一知识点，但不会重写已保存路径。网页的“正式自测”不是闭卷、监考或严格无辅助的学习效果测验；课程组如需研究独立掌握，应另设无辅助任务。

在同一页通过“探索研究”明确选择临时方向时，后续 Max 提问采用该方向，不改课程默认偏好；原有提问保留发送时上下文。“换个任务”是查阅、练习等活动入口，不等于改课程目标，也不宣称已有三目标临时选择器。没有自述起点时不虚构熟悉度。Max 生成的小题只用于辅助练习，不加入课程组正式题库或星标证据，课程组不用为它另交教材。

## 四、网络图与关系

章节网络图取同一门课、同一章的普通节点，按已发布坐标绘制，并使用已发布连接。[布局.md](templates/布局.md) 记录坐标方案，不上传为正文；发布时用 `--x`、`--y` 明确提供，表格本身不会自动改坐标。不另维护一份与正式关系冲突的手绘线网。

当前关系接口兼容旧的 ordered（历史学习顺序）与 related（补充关联），不会自动把它们解释为学术前置关系。新推荐的默认先后顺序按有效知识点编号排列，不依赖关系连线。前置、推导、应用、推广、对比、等价是纲要中的学术关系，待正式接口迁移后再录入；检查工具目前拒绝这些未知类型，不静默转换。

课程入口把“章包含哪些点”与“点之间怎样联系”分开：左侧章目录显示实际章名、包含的普通知识点数量与选择器；右侧显示当前点及文字关系。`ordered` 的入边显示“可先了解”、出边显示“接着了解”，`related` 显示“补充联系”，只用已发布的真实关系，不代表必须先修。手机也优先展示文字，辅助图默认收起；不绘制章围栏，不展开整章知识点。

选择器支持按章、名称、编号与别名查找，每页最多 40 项；课程全点查找显示匹配总数和分页。在关系视图内部返回时恢复章节、关键词与所在页；从正文回课程只定位当前点或所属章，不宣称恢复完整搜索和导航历史。选中一个知识点只显示同课程内的直接一跳关联，可跨章，不递归展开二跳。0 级辅助图只连真实的 0 级到 0 级关系，不根据普通节点关系推断章关系。缺少 0 级稿时可显示真实章成员的摘要，但不制造新知识点或虚构章概览。0 级稿内部的章节网络图仍保留，与课程入口的单点关系视图分开。

同一条关系只填写一次，引用的节点要在包内且先发布。跨课程关系暂不由现有接口连线，可在正文提供准确链接。正式修改关系前先回读现有地图，确认新增与删除清单；不要用本地清单批量删除旧关系。

目前整包关系检查只收录 1 级到 1 级连接，拒绝 0 级连线。入口可以展示系统中已经发布的真实 0 级到 0 级关系，但本包不负责其离线录入；不要将章节点与每个子节点连接来代替归属。关系表中的教学含义和条件供课程组审核、保存在提交材料里，当前 `connect` 命令只上传起点、终点与网页类型，不会把六类学术语义自动写入推荐模型。

## 五、离线检查与导出

下列三个离线检查工具仅依赖 Node.js，不连接网络。`下载课程.cjs` 与 `上传知识点.cjs` 则调用课程 API，需要配置凭据。以下命令在本包目录执行：

```sh
node tools/整理知识点.cjs "课程包/知识点/SS-01-01.md"
node tools/检查课程包.cjs "课程包"
node tools/检查自测.cjs "课程包/知识点/SS-01-01.md"
```

单节点检查分区、字段、编号、章名、概览、起源与题目小节，并自动核验可选自测扩展。有评分扩展时，每个 JSON 题号必须对应正文中唯一的三级至六级“题目 ID”标题；代码围栏里的示例标题不参与，额外普通练习可以保留。缺失或重复对应会阻止导出。题干语义、答案正确性与授权仍须人工核对，不能写成机器已保证。

整包检查 0 级章节节点、同章名称、重复编号、关系引用、复核状态、重复连接及有向学习顺序环。检查自测工具也可单独运行；它检查评分格式，不单独核对正文标题。无评分扩展的旧稿仍可使用，非法、重复或未闭合的扩展不能导出。

生成可上传数据时，使用新的输出目录。工具拒绝覆盖已有输出：

```sh
node tools/整理知识点.cjs "课程包/知识点/SS-01-01.md" --out 待发布 --revision new --x 200 --y 180
```

新建用 `--revision new` 并提供坐标。更新时先用 `get-node` 读取节点与 64 位 revision，合并修改后把该 revision 传给工具；不传坐标就保留旧位置。导出基本信息.md、背景与应用.md、正文.md、发布数据.json，完整稿不变。

## 六、发布与回读

### 6.1 已有上传渠道及权限

官网“个人设置 → 课程组 Agent 接入”已提供个人 Token 和 Skill 下载，课程 API 支持读取、创建及更新节点。仅有对应课程资料维护权限的人员或站点管理员能操作；教师账号不会自动获得课程上传或题目复核权限。Token 是个人凭据，不要共用，401/403 时停止并检查账号、Token 或管理员分配，不能换身份绕过权限。

已有 Python `upload-node` 只把输入 MD 写入知识点正文，**不识别本包完整三分区模板**；它可用 `--basic-info` 与 `--applications` 分别指定另外两个分区，或用 `put-node` 提交整理后的 JSON。本轮补充的 Node 工具直接解析完整模板，并在明确 `--publish` 后调用同一个节点更新 API。当前不是网页拖入一份模板就立即更新的表单，也不提供整包一键覆盖；新版工具须随 PR #180 部署/下载更新后使用。

模板包工具位于 `tools/`；Skill 包同时带有相同工具，路径为 `scripts/course-authoring/`，三个离线检查工具也在该目录。环境变量由本地安全配置注入：站点为 `https://www.free-bbs.cn`，Token 不写入任何下载文件。Node 工具使用 Node.js 18 或以上，Python 旧命令继续兼容。

### 6.2 怎么下载当前知识点

在新版模板包目录运行：

```sh
node tools/下载课程.cjs signals --out 现有课程-20261012
```

这条命令仅 GET 所选课程的地图与逐点作者稿，保留完整三分区、节点位置与 revision，拒绝覆盖已有输出目录。下载不会修改线上节点、关系或学生记录；图片/附件仍保留原链接，不打包文件本体。即使旧资料不能通过新模板检查也如实保存原稿，不自动补章名、起源、署名、审核人或发布状态。回读数据中的 `node.revision` 是 64 位并发校验值，不是题目版本号。

输出包含 `课程地图原始.json`，每点的 `知识点/ID/节点原始.json`、`revision.txt`、`基本信息.md`、`背景与应用.md`、`正文.md`，以及全部下载完成后才生成的 `快照清单.json`。请求先完成校验，再写本地文件；本地写出途中失败时可能留下部分文件，保留用于核查，不把它们当完整快照，重试应指定另一个不存在的新目录。工具会复查地图是否变化，但逐点读取不是数据库事务级快照；不能据此保证所有内容在同一瞬间版本完全一致。工具不把旧分区自动拼成合格的完整模板；补齐并审核后再准备完整稿。

如果正式站点还未提供新版 Node 工具，可在现有 Skill 目录使用以下只读命令，输出 JSON 是作者源回读，不是本包完整稿：

```sh
python scripts/freebbs_course_upload.py courses
python scripts/freebbs_course_upload.py map signals
python scripts/freebbs_course_upload.py get-node signals SS-01-01
```

### 6.3 完整模板的预检与发布

当前知识点正文没有独立的草稿/发布状态：保存到课程节点后即进入可见内容。评分扩展的 `draft` 仅表示题目未进入正式自测，不能隐藏整篇稿件。请先在本地完成正文、授权和教学复核，再由发布人员上传；不要把演示稿或未审核正文当线上草稿保存。

以下更新使用准备修改前读取的 revision。先运行默认预检，核对课程标识、知识点 ID、名称和三个分区，确认后才追加 `--publish`；同一次命令不会自动批量发布其他节点或关系。

目标课程和知识点 ID 取自完整稿里的“课程标识”和“知识点ID”，不另传课程参数；发布前务必核对这两个字段。下载出的 `revision.txt` 可用于该知识点的 `--revision`，不要借用其他节点的值。

```sh
node tools/上传知识点.cjs "课程包/知识点/SS-01-01.md" --revision "上次读取的64位revision"
node tools/上传知识点.cjs "课程包/知识点/SS-01-01.md" --revision "上次读取的64位revision" --publish
```

新建示例（ID 与坐标均须确认，不直接照抄）：

```sh
node tools/上传知识点.cjs "课程包/知识点/SS-03-01.md" --revision new --x 200 --y 180
node tools/上传知识点.cjs "课程包/知识点/SS-03-01.md" --revision new --x 200 --y 180 --publish
```

更新不传坐标则保留原位置；完整模板发布会替换三个分区、名称与概览，不把缺失字段当“保留”。想只改正文时使用旧 Python 的分区更新。401/403/409 时停止；409 需重新下载和人工合并，不能强制覆盖。写入超时或回读失败不自动重试，先检查线上 revision 和实际内容，避免误认为未发布或重复写。

已有 JSON 与关系命令继续兼容，在 Skill 目录运行：

```sh
python scripts/freebbs_course_upload.py map signals
python scripts/freebbs_course_upload.py get-node signals SS-01-01
python scripts/freebbs_course_upload.py put-node signals SS-01-01 "待发布/SS-01-01/发布数据.json"
python scripts/freebbs_course_upload.py connect signals SS-01-01 SS-01-02 --type ordered
```

先发布节点（含 0 级章节节点），再按通过复核的关系表逐条发布连接。超时先回读；409 表示内容已变，重新读取并合并，不强制覆盖。此包没有自动批量上传、改权限、发布课程或删除地图的操作。

回读后核对：实际章名、参与同学、概览首段、知识起源吸顶、正文公式、练习题与解答、章网络图、连接方向。上传成功不等于教学审核通过；只有正式环境回读验证后才记录为已发布。

交付前逐项确认：

- 三个二级标题保留原名和顺序，其他标题为三级及以下；全部占位符已替换。
- 概览首段精简，起源解释“为什么学”，章名与署名一致，引用和图片已确认授权。
- 普通练习具完整题干、来源、折叠解答；可选评分题号与对应题目一致，答案和容差已人工核对。
- 未完成教学审核的评分配置保持 `draft`；正式发布填写出处、审核人和版本。审核日期可记录，不是接口强制字段。
- 改正文或评分规则时保存旧稿、使用回读的 revision；不把历史作答当作新版已通过。
- 章网络图与已发布节点/关系一致，课程入口只聚焦直接关联；正式环境再检查移动端、公式与题卡。

## 八、可选自测评分扩展

复制 `templates/自测题-评分扩展.md` 中的围栏，填好后放在知识正文的最后。每个节点只允许一份完整的 `freebbs-quiz` JSON。它随现有正文上传，不增加上传步骤；学生正文不显示该配置，课程编辑接口保留原配置。

发布状态为 `published` 时须提供真实来源、版本、审核人和每题评分规则。未完成审核使用 `draft`，仅作练习反馈。配置有歧义、不完整或位于正文中间时不会进入正式自测。版本变更后旧作答保留，但不当作当前版本已通过的证据。

| 题型               | type            | method  | 判分                                              |
| ------------------ | --------------- | ------- | ------------------------------------------------- |
| 单选               | single_choice   | exact   | 与答案选项完全一致                                |
| 多选               | multiple_choice | exact   | 选项集合完全一致，不给部分分                      |
| 数值               | numeric         | numeric | 绝对或相对误差在明确容差内；仅接受有限标量数值    |
| 简答/计算过程/证明 | short_answer    | manual  | 依据 rubric 人工复核，之前显示待复核而非通过/失败 |

`maxScore` 是满分，`passScore` 是通过线。正式题未通过写入个人错题，正式订正通过后更新状态；同题练习不替代正式订正，也不改变正式自测证据。系统不把题目通过次数、浏览时长或手工标记换成课程成绩或能力标签。参考答案不是原文评注，学生答案也不放进课程包。

数值题容差按 `max(absoluteTolerance, abs(target) × relativeTolerance)` 判断，边界包含在内；0.01 的相对容差表示 1%。题干写清单位，但答案只接受有限标量数值，不支持把带单位字符串或公式表达式作为数值答案。主观题用 rubric 列出评分点与部分分规则，提交后为待复核，由有权限的课程负责人处理，不由 Max 自动判正式通过。

这版暂不使用模型自动判主观题、不支持考试监考或全局题库。已审核题目可被课程负责人复核；处理意见随作答版本保存。

## 九、分层练习、自测与探索

评分扩展继续使用 `schemaVersion: 1`，在每题中可增下列字段；所有工具与网页使用同一契约：

| 字段              | 允许值与含义                                                  |
| ----------------- | ------------------------------------------------------------- |
| difficulty        | basic 基础、standard 标准、challenge 挑战；可省略，是教师估计 |
| assessmentRole    | practice 练习、selftest 正式自测候选、exploration 可选探索    |
| learningObjective | 可省略，不超过 600 字；公开说明本题检查的知识或方法           |
| misconceptions    | 可省略，不超过 4000 字；作答后与解析一起显示                  |

难度不是布鲁姆认知层次，也不是实测题目参数或学生能力定级。本版不接受“已校准”字段；日后校准需另行提供样本、测量方法和依据。知识点的难度（1–5）仍用于概览，不自动换成本题难度；自述起点只建议先试某层，不限制学生选择。

练习页允许筛选基础、标准或挑战，并可单独查看探索题；系统可以根据自述起点建议先试某一层，用户仍可自由更换。推荐路径里的做题步骤进入练习模式，不能把选择“练习解题”视作同意正式交卷；用户可明确选择“直接自测”。正式自测页始终显示当前发布的全部 selftest 题，不受练习难度筛选影响；练习正确不顶替正式作答，探索题不进入授星分母。正式自测只有客观题按已发布规则判分，主观题须课程负责人复核；待复核不是已通过。

旧题不必补字段：旧 published 默认 selftest，旧 draft 及普通 Markdown 题默认 practice。没有评分扩展的旧 Markdown 题卡统一回退为 `short_answer` / `manual` / `practice`；文字写“单选”“自测”“难度”不会自动配置题卡类型、三档筛选或正式证据。需要这些功能时使用评分扩展；不要把旧示例的“难度：1/2”当作已进入分层筛选。

新增字段、修改用途、题干、答案或解析时更新评分扩展顶层的 `version`，并保存旧稿；不在单题添加独立 `version`。`difficultyBasis`、`questionVersion`、`documentVersion`、`official`、`reviewed` 等是服务端派生结果，不填入作者 JSON。网页会核对正文与题目版本，旧作答不充当新版通过依据；已获星保留历史来源而非自动撤销。

网页对应练习、自测、订正三种题目板面；题目来源、用途、学习目标与教师估计难度可见，评分扩展中的参考答案、详细评分依据、`explanation` 解析与 `misconceptions` 误区通过服务器在作答后返回。普通 Markdown 练习原有的折叠参考解答仍可主动查看，不作为答案保密或考试防作弊功能。可选探索问题用于提出和检验思路，不自动授星；AI 临时题不能混入本配置的正式题或据此授星。

新增示例 `SS-02-01` 展示完整概览、起源、正文、例题、基础/标准/挑战题、正式自测候选与可选探索；`SS-02-00` 使用实际章名，并由关系/布局展示 `SS-01` 与 `SS-02` 的跨章关联。所有示例仍是 `draft`，仅供本地验收，不能未审核直接发布。

课程组只需提交一份完整正文，保留概念、条件、推导、例题与依据；分层题覆盖真实学习目标，按用途区分练习、正式自测和可选探索，不按十二种组合重复复制。学习目标优先写可观察的行为，如解释条件、独立计算、比较方法或论证边界；不要仅写“全面掌握”。查阅和科研探索可以直接使用正文、关系与依据，不要求逐题作答。题目多少和难度分布由课程目标决定，不为凑齐三档而编造题目；未配置正式题时不展示虚构的正式通过或星标。

## 十、公开课程附件

沿用现有课程上传工具，在其 Skill 目录安全配置凭据后，由有权限的发布人员操作：

```sh
python scripts/freebbs_course_upload.py file signals chapter-1.pdf --node-id SS-01-01
python scripts/freebbs_course_upload.py files signals
```

不指定 `--node-id` 的文件归入课程资料；关联节点必须已存在。仅上传获准公开的资料，不放学生信息、私人作答或限制传播的文献。公开列表和下载无需登录；相同课程中相同 SHA-256 的重传会保留首次文件名和节点关联，不是更改归属的操作。文件不会自动进入 RAG；必要依据仍应写进正式正文。上传成功后回读列表、打开目标知识点的资源入口并验证下载，不能用本地模拟文件证明线上资料已发布。

学习支架与证据边界的研发依据见 [人因与学习依据](../learning-human-factors-evidence-20261010.md)。课程组不必按十二种起点/目标组合复制正文，也不必为凑齐难度档位编造题目；先保证内容、条件、依据与评分可复核。
