# FREE BBS 课程组 Markdown 提交包 V4.2

本包用于统一提交章节概览、知识点概览、正文、知识起源、练习题与解答、章节网络图及知识点关系。课程组填写 Markdown；发布人员审核后用现有课程上传接口提交。不要把账号、密码、Token、学生作答或成绩放进本包。

课程组开始编写前，先读[课程组编写指南](课程组编写指南.md)：它说明每个知识点最少交什么、如何区分概览/起源/正文、怎样安排分层题与正式自测，以及谁负责编写、复核和发布。本页保留文件格式、字段、离线检查和上传回读的技术说明。

每个知识点只写一份正文；先完成准确可用的稿件，再按需要加入评分题卡和可选探索，不必一次凑齐所有难度、题型或学习路径。

本模板对应本地学习区改版代码，尚未上线。保留原有三个分区和题目正文；可在正文末尾追加一份评分扩展，支持分层题卡、客观判分及主观人工复核。没有评分扩展的题目仍是练习，不会被认定为已通过正式自测。正式自测星只接受当前发布版本全部正式自测题的有效通过证据，不能靠练习、探索、时长或手工标签获得；深入掌握星暂不自动授予。

2026-10-03 适配：在V4.1齐套包基础上加入题目难度、用途、学习目标与作答后误区，补齐跨章实例，并同步统一正文上的私人批注及起点/目标推荐。课程稿仍用三个分区、一个唯一评分扩展、schemaVersion 1，不增加上传步骤，也不要求为不同学习路径另写教材。先部署兼容解析器，再上传新字段；旧部署会拒绝未知字段。模板版本不要求每份题目的版本号也改为4.2。

## 一、从哪里开始

先复制 `templates/知识点.md` 填一份知识点稿，再复制 `templates/章节-0级节点.md` 填所属章；完成后使用三个离线工具检查。其余模板用于提交说明、关系与布局，`自测题-评分扩展.md` 按需追加，不必给一个知识点上传六份文件。

```text
课程包/
├─ 课程提交说明.md
├─ 关系.md
├─ 布局.md
├─ 章节/
│  ├─ SS-01-00.md
│  └─ SS-02-00.md
└─ 知识点/
   ├─ SS-01-01.md
   ├─ SS-01-02.md
   └─ SS-02-01.md
```

0级节点表示章，末段为00，名称就是实际章名，例如“线性时不变系统的时域分析”。普通节点为1级，保持平台已有编号，不因改名或补零而更换ID。章节ID如SS-01；所有同章节点的“章节/单元”填写同一个实际章名。

章节目录先取0级节点名称，其次取普通节点的章节字段，最后保留旧资料的章名或编号。0级节点不计入普通知识点数量，但可以打开章节概览并查看本章网络图。

| 需要准备         | 对应模板           | 填写重点                                    |
| ---------------- | ------------------ | ------------------------------------------- |
| 每个知识点       | 知识点.md          | 概览、起源、正文、学习反馈题目、依据与署名  |
| 每章一个0级节点  | 章节-0级节点.md    | 实际章名、目标、本章知识点及整体联系        |
| 自测题卡（可选） | 自测题-评分扩展.md | 题号、四种题型、评分规则、来源、审核和版本  |
| 课程交付清单     | 课程提交说明.md    | 节点文件、编写与复核、修改范围              |
| 已复核连接       | 关系.md            | 当前可用的ordered/related，不把章归属当连线 |
| 节点位置         | 布局.md            | 已确认坐标，新建必填，更新不默认移动        |

## 二、填写要求

每个节点文件只保留三个二级标题，名称和顺序不变：

1. 基本信息：填写字段，不删除字段。参与同学列出同意公开署名的编写、修订与复核同学。
2. 知识背景与应用：首段是简短概览，最多150字符（含标点）；“知识起源”独立说明问题背景和学习意义，“应用场景”说明用途及边界。150是本提交包的首段约束及概览展示长度，不是全部上传接口的summary上限。
3. 知识点正文：自由组织内容、例子、公式、推导、图片和代码；练习题采用模板的题干、目标、难度、来源及折叠参考解答格式。

其他标题用三级及以下。删除所有双花括号占位符。没有可靠历史资料时，说明知识要解决的问题，不杜撰人物、年份或历史故事。正文和参考解答的数学内容由课程负责人复核；格式检查不代替教学审核。

图片使用已授权、可访问的 HTTPS 或平台资源地址，不填本机盘符路径。公式使用行内美元符号或独立双美元符号。参考解答使用模板中的 details/summary，网页默认收起，点击后可查看。

## 三、网页对应关系

| 提交内容                         | 存储分区                       | 网页展示                                   |
| -------------------------------- | ------------------------------ | ------------------------------------------ |
| 章名、难度、重要程度、时长、署名 | 基本信息.md                    | 章节目录与学习概览；原始资料可折叠查看     |
| 简短概览首段                     | 背景与应用.md，同时生成summary | 点击知识点后的概览                         |
| 知识起源                         | 背景与应用.md的“知识起源”小节  | 正文前的紫色吸顶框，可收起；没有内容不编造 |
| 正文、例子、题目、参考解答       | 正文.md                        | 知识正文；参考解答默认折叠                 |
| 0级章节点                        | 同一节点上传接口               | 真实章名、章节概览入口                     |
| 节点布局坐标                     | 节点position                   | 章节网络图及地图布局                       |
| 同课程学习连接                   | 地图边接口                     | 直接关联与0级节点中的章节网络图            |

没有新增数据库分区；整理工具把完整文件拆成现有三个分区。不要将一份完整稿直接当作正文覆盖旧节点，否则概览、起源会错位。网页里的个人笔记、复盘和共建建议属于用户记录，不由课程组稿件覆盖。

学习页的六个工具是正文、资源、题目、继续、笔记、共建，不是六个上传分区。课程组主要维护官方概览、正文、起源与题目；“继续”按已上传内容和当前版本自测证据给出步骤，个人笔记直接依托这份统一正文提供私人高亮、下划线、评注与补充笔记，不另建第二份教材，不改变官方文本。共建由课程组审核后另行修稿。知识点资源入口目前仍是占位，不在本包虚构已开放的资源库或上传字段。

学生可选择四个自述起点（第一次学、不甚熟悉、能独立做题、完整掌握）和三个当前目标（理解知识、练习解题、探索研究）。这些选择只用于推荐下一步、题目入口和Max的辅助语境，不是测量得到的能力等级；“完整掌握”的自述不能替代正式作答。十二种组合复用同一份概览、知识起源、正文和题目，不需要课程组编写十二份正文或十二套必做题。

阅读—作答—正式自测是可用的基准通道，不锁定所有人的顺序。学生也可直接自测、查阅关系或开展探索；“继续”首屏给出一个主要步骤、最多两个替代入口及简短顺序链，已保存路径与手动调整不被新推荐覆盖。有正式错题或待复核时提示真实状态，但不封锁主动查阅和探索；任何路径标记、时间或对话都不替代正式自测证据。

## 四、网络图与关系

章节网络图取同一门课、同一章的普通节点，按已发布坐标绘制，并使用已发布连接。布局.md记录坐标方案，不上传为正文；发布时用 --x、--y 明确提供，表格本身不会自动改坐标。不另维护一份与正式关系冲突的手绘线网。

当前关系接口兼容旧的 ordered（历史学习顺序）与 related（补充关联），不会自动把它们解释为学术前置关系。新推荐的默认先后顺序按有效知识点编号排列，不依赖关系连线。前置、推导、应用、推广、对比、等价是纲要中的学术关系，待正式接口迁移后再录入；检查工具目前拒绝这些未知类型，不静默转换。

课程入口先展示0级章/板块，点击后在右侧显示详情并筛选知识点选择器，不展开整章知识点。选择器支持按章、名称、编号与别名查找，并分页显示；选中一个知识点后才显示其同课程内的全部直接一跳关联，跨章关联按实际归属聚合，不递归展开二跳。0级图只连真实的0级到0级关系，不根据普通节点关系推断章关系。缺少0级稿时可显示真实章成员的摘要，但不制造新知识点或虚构章概览。0级稿内部的章节网络图仍保留，与课程入口的单点关系视图分开。

同一条关系只填写一次，引用的节点要在包内且先发布。跨课程关系暂不由现有接口连线，可在正文提供准确链接。正式修改关系前先回读现有地图，确认新增与删除清单；不要用本地清单批量删除旧关系。

目前整包关系检查只收录1级到1级连接，拒绝0级连线。入口可以展示系统中已经发布的真实0级到0级关系，但本包不负责其离线录入；不要将章节点与每个子节点连接来代替归属。关系表中的教学含义和条件供课程组审核、保存在提交材料里，当前connect命令只上传起点、终点与网页类型，不会把六类学术语义自动写入推荐模型。

## 五、离线检查与导出

工具仅依赖 Node.js，不连接网络。以下命令在本包目录执行：

```sh
node tools/整理知识点.cjs "课程包/知识点/SS-01-01.md"
node tools/检查课程包.cjs "课程包"
node tools/检查自测.cjs "课程包/知识点/SS-01-01.md"
```

单节点检查分区、字段、编号、章名、概览、起源与题目小节，并自动核验可选自测扩展。整包检查0级章节节点、同章名称、重复编号、关系引用、复核状态、重复连接及有向学习顺序环。检查自测工具也可单独运行；无评分扩展的旧稿仍可使用，非法、重复或未闭合的扩展不能导出。

生成可上传数据时，使用新的输出目录。工具拒绝覆盖已有输出：

```sh
node tools/整理知识点.cjs "课程包/知识点/SS-01-01.md" --out 待发布 --revision new --x 200 --y 180
```

新建用revision new并提供坐标。更新时先用get-node读取节点与64位revision，合并修改后把该revision传给工具；不传坐标就保留旧位置。导出基本信息.md、背景与应用.md、正文.md、发布数据.json，完整稿不变。

## 六、发布与回读

仅有课程资料维护权限的发布人员可以操作。教师账号也不会自动获得课程上传或题目复核权限；由管理员明确分配负责课程，不以“教师”身份默认升权。在个人设置下载课程上传Skill，按其配置安全注入凭据。以下路径按实际Skill位置调整：

当前知识点正文没有独立的草稿/发布状态：保存到课程节点后即进入可见内容。评分扩展的 `draft` 仅表示题目未进入正式自测，不能隐藏整篇稿件。请先在本地完成正文、授权和教学复核，再由发布人员上传；不要把演示稿或未审核正文当线上草稿保存。

```sh
python scripts/freebbs_course_upload.py map signals
python scripts/freebbs_course_upload.py get-node signals SS-01-01
python scripts/freebbs_course_upload.py put-node signals SS-01-01 "待发布/SS-01-01/发布数据.json"
python scripts/freebbs_course_upload.py connect signals SS-01-01 SS-01-02 --type ordered
```

先发布节点（含0级章节节点），再按通过复核的关系表逐条发布连接。超时先回读；409表示内容已变，重新读取并合并，不强制覆盖。此包没有自动批量上传、改权限、发布课程或删除地图的操作。

回读后核对：实际章名、参与同学、概览首段、知识起源吸顶、正文公式、练习题与解答、章网络图、连接方向。上传成功不等于教学审核通过；只有正式环境回读验证后才记录为已发布。

交付前逐项确认：

- 三个二级标题保留原名和顺序，其他标题为三级及以下；全部占位符已替换。
- 概览首段精简，起源解释“为什么学”，章名与署名一致，引用和图片已确认授权。
- 普通练习具完整题干、来源、折叠解答；可选评分题号与对应题目一致，答案和容差已人工核对。
- 未完成教学审核的评分配置保持draft；正式发布填写出处、审核人和版本。审核日期可记录，不是接口强制字段。
- 改正文或评分规则时保存旧稿、使用回读的revision；不把历史作答当作新版已通过。
- 章网络图与已发布节点/关系一致，课程入口只聚焦直接关联；正式环境再检查移动端、公式与题卡。

## 八、可选自测评分扩展

复制 `templates/自测题-评分扩展.md` 中的围栏，填好后放在知识正文的最后。每个节点只允许一份完整的 `freebbs-quiz` JSON。它随现有正文上传，不增加上传步骤；学生正文不显示该配置，课程编辑接口保留原配置。

发布状态为 `published` 时须提供真实来源、版本、审核人和每题评分规则。未完成审核使用 `draft`，仅作练习反馈。配置有歧义、不完整或位于正文中间时不会进入正式自测。版本变更后旧作答保留，但不当作当前版本已通过的证据。

| 题型               | type            | method  | 判分                                              |
| ------------------ | --------------- | ------- | ------------------------------------------------- |
| 单选               | single_choice   | exact   | 与答案选项完全一致                                |
| 多选               | multiple_choice | exact   | 选项集合完全一致，不给部分分                      |
| 数值               | numeric         | numeric | 绝对或相对误差在明确容差内；仅接受有限标量数值    |
| 简答/计算过程/证明 | short_answer    | manual  | 依据 rubric 人工复核，之前显示待复核而非通过/失败 |

`maxScore` 是满分，`passScore` 是通过线。正式题未通过写入个人错题，正式订正通过后更新状态；同题练习不替代正式订正，也不改变正式自测证据。系统不把题目通过次数、浏览时长或手工标记换成课程成绩或能力标签。参考答案不是原文评注，学生答案也不放进课程包。

数值题容差按 `max(absoluteTolerance, abs(target) × relativeTolerance)` 判断，边界包含在内；0.01的相对容差表示1%。题干写清单位，但答案只接受有限标量数值，不支持把带单位字符串或公式表达式作为数值答案。主观题用rubric列出评分点与部分分规则，提交后为待复核，由有权限的课程负责人处理，不由Max自动判正式通过。

这版暂不使用模型自动判主观题、不支持考试监考或全局题库。已审核题目可被课程负责人复核；处理意见随作答版本保存。

## 九、分层练习、自测与探索

评分扩展继续使用schemaVersion 1，在每题中可增下列字段；所有工具与网页使用同一契约：

| 字段              | 允许值与含义                                               |
| ----------------- | ---------------------------------------------------------- |
| difficulty        | basic基础、standard标准、challenge挑战；可省略，是教师估计 |
| assessmentRole    | practice练习、selftest正式自测候选、exploration可选探索    |
| learningObjective | 可省略，不超过600字；公开说明本题检查的知识或方法          |
| misconceptions    | 可省略，不超过4000字；作答后与解析一起显示                 |

难度不是布鲁姆认知层次，也不是实测题目参数或学生能力定级。本版不接受“已校准”字段；日后校准需另行提供样本、测量方法和依据。知识点的难度（1–5）仍用于概览，不自动换成本题难度；自述起点只建议先试某层，不限制学生选择。

练习页允许筛选基础、标准或挑战，并可单独查看探索题；系统可以根据自述起点建议先试某一层，用户仍可自由更换。正式自测页始终显示当前发布的全部selftest题，不受练习难度筛选影响；练习正确不顶替正式作答，探索题不进入授星分母。正式自测只有客观题按已发布规则判分，主观题须课程负责人复核；待复核不是已通过。

旧题不必补字段：旧published默认selftest，旧draft及普通Markdown题默认practice。新增字段、修改用途、题干、答案或解析时更新题目version，并保存旧稿。网页会核对正文与题目版本，旧作答不充当新版通过依据；已获星保留历史来源而非自动撤销。课程学习星不由课程导入或浏览自动产生，深入掌握星后续开发。

网页对应练习、自测、订正三种题目板面；题目来源、用途、学习目标与教师估计难度可见，评分扩展中的参考答案、详细评分依据、`explanation`解析与`misconceptions`误区通过服务器在作答后返回。普通Markdown练习原有的折叠参考解答仍可主动查看，不作为答案保密或考试防作弊功能。可选探索问题用于提出和检验思路，不自动授星；AI临时题不能混入本配置的正式题或据此授星。

课程组只需提交一份完整正文，保留概念、条件、推导、例题与依据；分层题覆盖真实学习目标，按用途区分练习、正式自测和可选探索，不按十二种组合重复复制。学习目标优先写可观察的行为，如解释条件、独立计算、比较方法或论证边界；不要仅写“全面掌握”。查阅和科研探索可以直接使用正文、关系与依据，不要求逐题作答。题目多少和难度分布由课程目标决定，不为凑齐三档而编造题目；未配置正式题时不展示虚构的正式通过或星标。
