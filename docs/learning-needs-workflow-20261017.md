# 按需复习、问题驱动探索与 Max 当前步骤同步

日期：2026 年 10 月 17 日。本文说明本地实现与验证边界，不是部署公告或教学效果报告。

## 普通学习入口

保留四种当次目的与四档自述熟悉程度，不增加问卷，不重新要求已确认的课程偏好。16 种组合是可修改的起始建议，不是固定人群、能力诊断或 16 份正文。

复习入口不再将所有建议排列为本次待办。先回忆或尝试；用户表示卡住才展开定点查漏；可以尝试真实已有题，也可以直接结束。结束只是本次自主决定，不更新已保存路径的完成标记、正式成绩或星标。暂停与恢复同样不等于失败或通过。

探索四档都从本人问题出发。可以暂时留空，让 Max 帮助确定方向；概览、起源、原文、已有题与批注按需选择，不要求先读完或做完。问题不写入新增研究表；输入先留本页草稿，明确选择后才成为当前任务意图，并在用户明确发送聊天时进入 Max 上下文。

原有已保存路径保留，仍可查看、调整和明确保存。阅读或做题时保留紧凑的本次任务入口，能够返回或结束，不把工具栏做成第二个长对话框。

## 模块与数据边界

- `learning-policy.js`：共同课程资料上的 16 种建议；探索问题优先，按含义标记可选、条件和真实资源可用性。
- `learning-workflow.js`：纯函数、本页运行状态；不联网、不持久保存、不评分。复习包括回忆、查漏、检验、结束；探索包括提出问题、按需查证、结束。
- `learning-workflow-panel.js/.css`：独立的简洁视图；按钮只调用明确的回调，输入不自动发消息。
- `knowledge-workspace.js`：连接工具、当前步骤和本页状态。账号、令牌、课程、知识点、正文版本、目的或程度变化时旧上下文失效；手动离开当前任务不继续声明旧步骤。
- `knowledge.js`：每次主动聊天读取 `currentStep()`；不会因步骤变化自行发送、替换已有问题草稿或宣布完成。
- `learning-companion.js`：服务端重新校验当前意图和材料版本，再基于实际资料构建建议链与辅导提示。页面自由提供的链、成绩或材料不能冒充可信证据。

当前步骤包含受控目的、程度、模块、阶段、本人 `gap/clear` 自述及 active/paused/finished 状态；探索问题最多 1,000 个 JavaScript 字符。课程、知识点与正文版本必须匹配。问题以明确标注的个人任务数据传入，不是改变模型角色、访问权限或评分规则的指令。

Max 同时获知默认建议链与当前自选步骤。自选模块可以不在默认顺序中；复习顺利时不催促补题，探索优先回应问题，暂停时不催促。本人说“理顺了”、打开正文、自勾完成和真实正式测验记录是不同证据，不能互相代替。

## 本地预览与验证

继续使用隔离的公开快照、本地合成账号、内存记录与模拟 Max。公开快照不是含评分源的作者备份；预览必须让客户端与本地服务端使用同一份重建公开材料的版本，不能为方便演示关闭生产校验。

```text
npm run test:learning-policy
node scripts/check-learning-needs-workflow-browser.js --origin=<本地隔离预览>
node scripts/check-learning-normal-policy-browser.js --origin=<另一全新隔离预览>
node scripts/check-human-learning-unit-suite.js --include-shared-ui
```

浏览器场景包括四档复习直接结束、缺口查漏与阅读返回、四档探索问题到服务端的实际传递、理解与练习步骤、草稿、暂停与恢复、手动换工具、账号和版本失效、旧路径保留、手机暗色和键盘。只检查浏览器已发送还不够，必须核对服务端实际接收与使用的上下文。

回归测试证明的是确定性规则、权限与界面接线，不证明真实模型每次讲解正确或产生学习收益。真实 MySQL、全字体专项和实时模型教学质量须分别说明覆盖情况，不能写成已经全部验证。

最终冻结记录：99 份测试文件共 1,626 项，1,624 通过、0 失败、2 跳过（真实 MySQL 集成及可选的全字体预设 Chrome 专项）；292 个公开脚本、样式与 HTML 的受测指纹稳定。报告：`output/learning-needs-release/2026-10-16T18-08-43-979Z/report.json`。

正常入口回归 21/21，通过 16 种组合及偏好、草稿、旧路径和移动端检查，来源指纹稳定。报告：`output/learning-normal-policy/2026-10-16T18-06-02-744Z/report.json`。按需流程专项先后复验，最终 22/22，含服务端实际步骤与问题回声、清楚即结束、缺口查漏、暂停、账号及正文版本失效、390 px 暗色放大字体和键盘。报告：`output/learning-needs-workflow/2026-10-16T18-09-47-174Z/report.json`。两套浏览器报告都是 0 页面异常、0 外域请求；不把重叠的场景重复计为独立样本。

曾发现公开快照原作者版本与本地重建材料版本不一致，导致新步骤被服务端正确拒绝；仅修复隔离预览的版本一致性，未关闭生产校验。旧失败轮与来源变化轮保留用于诊断，不当作最终绿色证据。未连接生产账号或数据库、未调用实时模型、未提交或部署。
