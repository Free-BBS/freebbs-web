# 学习世界的人因与学习依据

2026-10-10，本地开发笔记。与 [20 个使用场景](human-learning-scenarios-20261010.md)、[课程组交稿说明](course-authoring/README.md) 配套。

## 2026-10-11：学习记录的实施依据

当前产品要求已从可选开启过程记录，改为默认记录必要过程，并移除“不记录”入口。这是产品策略变更，不是论文证明所有行为都应该采集：只保留原有受控事件、前台活跃时长估计与本人明确选择，不增加键盘轨迹、设备指纹、私人批注、聊天或答案正文。180 天过程保留、本人导出与清空继续有效；清空只删除历史过程，后续记录继续。更早规划中的“默认关闭”作为历史设计保留，以本次实现与界面告知为准。正式作答、私人笔记及原有课程复核权限相互独立。

看板按“事实 → 可解释的变化 → 自己选择下一步”组织。个人先看近况与可回看的位置，再查看知识点证据和作答复盘；管理员先看平台使用与覆盖，再查看学习支持证据、路径和明细，课程待办单独折叠。不生成掌握分、预测成绩、学习态度标签或学生排名。无记录不等于没学习，未复测不等于又失败，正式作答也不自动代表无 AI 辅助。

“少于 5 人只显示事实”是产品展示规则，不是统计可靠性的保证或充分匿名化。管理端细分仍受已有管理员权限约束，不公开给教师、企业或访客。若进一步开展学习效果研究，需独立、自愿的样本与告知，明确评分、辅助条件、缺测和退出；本次默认业务过程记录不代替研究同意。

可计算指标包括：有过程/有作答/只有作答证据的人数，用户 × 课程 × 知识点单元，练习/正式/待复核次数，同题同完整版本的本期首末结果，曾订正后最新状态，明确起点与目的及修改，实际选择的路径，工具参与和北京时间活动节奏，以及版本/时间/用途来源缺口。历史题目或版本的结果不能认定当前完整题库已通过；“曾通过”和“最后通过”必须分别命名。管理员过程明细不含私人文字，课程主观复核保持原有单独权限。

## 2026-10-11：课程部与战略部的分析分工

课程部研究具体教学材料与题目：哪段讲解不清、哪些先修条件或例题缺失、题目与评分是否合理、哪些作答需要复核。战略部研究整个 FREE BBS 平台及学习范式：是否方便学习与发展、是否支持自主学习和不同需求、是否帮助形成可独立检验的知识理解。课程诊断为课程部提供改稿线索，不能代替战略部的平台效果研究。

| 战略部研究问题                 | 当前可以参考的证据                     | 尚需设计的验证                                       |
| ------------------------------ | -------------------------------------- | ---------------------------------------------------- |
| 能否方便地开始、求助与恢复学习 | 学习页面工具参与、路径选择、可用性测试 | 真实任务观察、遇阻与放弃原因、跨模块任务完成         |
| 是否支持不同起点与自主选择     | 自报起点、目标、实际路径及更正         | 新手、熟练者与研究者的体验反馈，不把自报当能力等级   |
| 是否帮助知识掌握               | 同一完整题目/正文版本的首末作答变化    | 可比前测、无辅助新题后测，记录辅助条件与缺测         |
| 能否保持知识并迁移应用         | 已实现四阶段研究采集与固定题评分管道   | 真实试测、延迟测试与不同情境任务，不把同题订正当迁移 |
| 是否支持学习发展、探索与合作   | 学习页面参与记录；自愿跨模块体验反馈   | 真实任务、作品与合作评价及长期随访                   |

管理端据此改为“平台使用、学习支持证据、学习路径、记录明细”。逐知识点的课程支持待办折叠并标明课程部归属；这是研究与工作分工说明，不是新增部门角色或访问权限。当前记录仍只覆盖学习页面，不能声称已有完整平台链路分析，更不能声称平台已经造成知识掌握提升。参与多、得到帮助后答对、感觉有用和独立掌握是不同证据；战略部的研究需要结合学生反馈、任务结果与适当的比较设计，并关注基线、流失和混杂。[WWC 研究标准](https://ies.ed.gov/ncee/wwc/standardsbriefs)说明这些研究质量问题；[学习看板系统综述](https://arxiv.org/abs/2312.15042)也提醒仅比较自愿使用者与未使用者可能混淆参与差异与工具效果。

本轮进一步实施了[本人 Max 与平台研究模块](learning-platform-research-20261011.md)，不只是更改看板文案。本人主动提问时，Max 可参考本知识点保存的笔记、批注、复盘和作答；战略部接收自愿的跨模块分类体验反馈，并可登记/评分四阶段任务，观察前后配对、延迟保持、新情境应用与不同目的/辅助情况。不把私人原文默认交给战略部，不把研究结果改成正式成绩或星标。此前表格中的“尚需设计”仍指真实试测、可比测量与科学研究方案；现在有采集与评分管道，不代表已有真实学习效果证据。全站自动任务追踪、个人内容战略部语义聚合和因果验证仍未实现。

## 2026-10-10：原有设计结论

保留“阅读正文、形成自己的理解、练习与自测、查看反馈”的完整基准通道，但不把它变成所有人的必经流水线。有人需要入门，有人只查条件，有人要独立检验，有人正在找研究灵感；同一个人也会改变任务。正文只维护一套，差别放在提示、题目用途、难度建议与可选择的下一步，不复制十二套教材。

四档起点仍是本人自评，不是诊断。目标只保留“理解知识”“练习解题”“探索研究”三类；它们是便于选择任务的产品分类，不是经论文验证的能力量表，也不等同于布鲁姆认知层次。四档起点与三类目标的十二种建议是明确的初始支架，不限制正文、题目、资料或星级。困难时可回基础，专家也可临时查一个初等条件。

## 信息与证据分开

学生需要知道正在读什么、为何学、已有条件、当前题目的结果、未完成思路和下一步可选任务。书签只是位置；自评只是支持偏好；完成勾选只是本人路径记录；正式通过只针对明确版本与评分要求。历史星记录与当前版本进度并列，不混成“你现在全部会了”。

课程组需要复核原提交题干、选项、评分依据和待处理项，不能只看到新版题目。处理一位同学时，不应让另一份回复丢失。教师身份不自动获得全部私人批注和 AI 对话；企业或访客也不默认取得学生个人记录。

管理端若要回答“平台是否帮助学习”，应比较有意义的学习结果，而不是仅展示活跃或星数。当前已有的业务记录不能替代前测、无辅助后测、延迟保持和迁移任务。页面停留很久可能是在离席，少点击也可能是在认真读；不能据此给同学贴能力或态度标签。

## 后续验证，不先宣称有效

1. 小规模可用性观察：覆盖新手、熟练学生、专家或科研人及课程教师，请其完成查条件、批注、独立尝试、恢复中断、处理投稿等真实任务。记录任务完成、迷路、误操作、输入丢失和本人解释，不将每次点击作为考核。
2. 学习效果研究另行设计：由课程组确定同目标、适当难度的前后测与迁移题；区分有无 Max、提示程度和重复练习，设置无辅助检验及必要的延迟测量。样本量、分组、主要结果、缺失数据和隐私同意应在采集前明确。
3. 本轮不新增隐蔽行为追踪、键盘录制或将私人批注自动送给模型。若以后需要研究数据，先说明目的、权限、保留期和退出方式，再决定采什么；“能采”不等于“应采”。

眼下优先保证：同学能直接做自己的学习任务，不被配置打断；输入和阅读上下文不丢；提示确实针对当前内容；学习证据诚实、可追溯。真实学习效果仍需真实同学的检验。

## 本轮检查发现的具体边界

正式错题是需要呈现的证据，不自动决定学生此刻必须换目标。研究者可能一边保留待订正项，一边先查一个边界条件；因此已选的探索目标继续有效，订正和待复核以独立入口保留。正式全部通过后提供实际下一点，但不强迫离开当前材料，也不抹去个人路径。

缺材料时仍应有可做的事，而不是把占位文字伪装成材料。空正文提示不进入原文批注或书签；只有题目配置时不推荐去读不存在的正文，但正式题目、普通笔记和现有资源入口继续开放。Max 生成的小题用于思考，不能混成课程组正式题或评分证据。

输入也需要保留上下文。真实鼠标与键盘复现了旧保存回执清掉后来输入的评注，已改为只清理它对应且未改变的草稿；之后的新思路、选区和焦点保留，由本人再次保存。它只是本地中断保护，不是离线或跨设备同步。

查阅关系后还要能回去。章的归属、直接知识联系与正文分开；返回关系时保留可用键盘焦点，回课程定位当前知识点。这个定位线索不应包装成完整导航历史，更不能将当前文本关系推断为经课程组认证的必修先修链。

## 下一轮真实试用：先看人能不能完成任务

下面是待执行的观察方案，不是已经完成的访谈或学习效果实验。可以先邀请几位愿意试用的同学和一位课程教师，每人约 15 分钟；不要求提供私人课程记录，不记录键盘或完整屏幕内容，不与成绩挂钩。

| 试用者与任务 | 给出的任务，而不是操作指令                                                                   | 重点观察                                                                                 |
| ------------ | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 新手         | 读一个已有知识点，找到一处不理解的内容并留下私人标注；自行决定是否问 Max，再尝试一道基础练习 | 是否先被配置挡住、能否发现批注工具、能否区分保存标注和公开讨论、提示是否让本人继续思考   |
| 已学过的同学 | 查一个公式的适用条件；离开正文后再回来；不看旧答案先完成一次自测                             | 是否只为查阅也被推着走流程、能否恢复到原段、是否误把练习通过当正式自测通过               |
| 专家或科研人 | 找一个边界、反例或相关知识点，形成一个待检验的问题；随后临时做一道练习                       | 章归属与知识联系是否分得清、能否查完即走、做练习后是否误以为探索目标被永久改掉           |
| 课程教师     | 核查两份合成主观作答，先编辑第二份，再处理第一份；遇到旧版本时解释采用什么评分依据           | 另一份意见是否保留、答案属于谁是否明确、能否找到提交时题干和规则、缺档案时是否知道须查证 |

观察者先让本人尝试，不教点击顺序；卡住时再询问“你原本以为这里会发生什么”。记录具体的迷路、误操作、输入丢失、未找到入口和本人解释，不按点击次数或星数评价学习者。

任务结束时，请本人用自己的话解释：刚才哪条是私人记录，哪条是正式自测结果；完成路径一步和拿到学习星是否同一件事；这次问 Max 是否自动分享了全部笔记。解释不一致时先改界面和措辞，不归咎于同学“不看说明”。
