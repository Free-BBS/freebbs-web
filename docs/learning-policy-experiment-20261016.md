# 共享材料上的模块化学习链原型

日期：2026 年 10 月 16 日。此页是开发边界与复现说明，不是教学效果报告或部署公告。

## 本轮决策

目的采用“理解知识、练习解题、复习知识、探索研究”四个入口。它们描述这次主要想做什么，可交叉、可切换，不宣称构成互斥且穷尽的人群类型。四档自述熟悉程度提供初始支架线索，因此有 16 个起始配置，而非 16 种学生或 16 份教材。

复习默认只展开三步，核心是先回忆或短尝试，有缺口才定向回看，之后短练习或结束。不是把初学全文加速播放。忘光时可获得微型解释或自行切回理解入口，不自动降级，不设置统一倒计时。

完整理论与探索方案另存在项目“平台战略与产品设计 / 学习端”的同日 Markdown；原 24 页调研 PDF 保留，不覆盖历史文件。文献启发模块设计，不把任一论文说成本平台整体背书。

## 实现结构

### 正常学习入口（本次接入，尚未部署）

正常知识页现已使用四个目的 × 四档熟悉程度，不需要实验 URL。学生只看到“这次想怎么学？”：理解知识、练习解题、复习知识、探索研究，以及第一次学、不甚熟悉、能独立做题、完整掌握。两项选择后点击“按这个方式学习”生效；也可直接阅读。回访恢复本人当前课程的偏好，仅显示摘要与调整入口，不反复询问。

“继续学习”和同页 Max 采用同一套规则。本人自述不是能力认证，不机械映射题目难度。复习先回忆、有缺口再查漏，不强迫重读全文。旧做题偏好不改称复习；已有路径、编辑草稿、完成和跳过状态保留。缺资料时使用真实可用入口，不造题、不修改评分或星标，也不自动发送 Max 消息。

普通学习界面不展示“实验”“16 类”等研究术语。既有记录与隐私说明保留，本次仅在原有受控目的枚举中加入复习，不新增隐蔽追踪或随机分组。若后续开展专门研究、采集新增敏感内容或发布研究结论，应另行明确用途和适用告知；不能把自然学习体验当作免除这些要求的理由。

以下独立实验页说明保留用于开发回归；它不再是新规则的唯一入口。下文旧验证数字属于上一次原型冻结，不代表本次改动已通过同样验证。

- `public/learning-policy.js`：共享纯规则，版本 `purpose-level-v1`，目的 `learn/practice/review/explore`，四档值 `new/familiar/basic/advanced`。目的只影响初始建议与辅导，不改评分、星标或访问权限。
- `public/learning-policy-lab.html/.js/.css`：独立实验页，读取真实公开地图、正文及有权限时的题目清单。缺材料明确回退，所有直接入口保留。
- `knowledge.html/knowledge.js`：正常入口的当前选择直接提供受控上下文；合法旧实验 URL 仅作兼容回退。按钮点击才准备问题，保护已有草稿，不自动发送。
- `backend/learning-companion.js`：服务端重新规范化受控枚举，以真实课程资料构建辅导提示，客户端材料、分数、完成状态和自由提示不能冒充可信证据。
- `backend/server.js`：服务端重新构建正常策略，存在有效新策略时不并列矛盾的旧目的提示；未知自述保持未知。
- `scripts/preview-learning-workspace.js`：模拟响应正确说明新策略；不把模拟链路说成真实模型已验证。

旧 `concepts/practice/explore` 目标仍保留原语义。新目的使用独立 `learningPolicyContext`，不会把旧练习偏好静默迁移成复习，也不覆盖已存个人路径。

## 本地预览

实验页支持 `/learning-policy-lab.html`。现有真实公开快照预览限制新 HTML 路由，需用新增包装器：

```powershell
node scripts/preview-learning-policy.js --preview-module="真实公开快照预览模块的绝对路径" --complete
```

CLI 输出仅本机可访问的随机端口，入口形如：

```text
/learning-policy-lab?course=signals&point=SS-02-01&purpose=review&level=familiar
```

阅读链接携带以下受控实验参数，课程与知识点仍由现有页面及服务端真实范围确定：

```text
policy=purpose-level-v1&purpose=review&level=familiar&module=retrieve
```

这些参数表示本人选择的入口意图，不证明始终停在该模块。实际工具及用户当前请求优先。返回实验页保留明确目的，不被另一条已保存链覆盖。

## 数据与边界

实验页的本人勾选只是自述安排，不表示掌握、评分或授星。保存采用独立本地 schema 2，按已核实账号隔离；身份未确认时只保留在页面内。导出只包含本人当前实验的最小配置与操作状态，不含 uid、token、正文、私人笔记或答案。

本原型未把策略曝光、采用、研究测验和反馈连成正式研究数据库，也没有新增管理员研究报表。模块生成和本地导出不等于已接通这些能力。后续可以先通过任务观察、短访谈、具体求助与材料反馈找改进方向，不必先做复杂因果试验。


本轮改动的 JavaScript 静态检查通过；`backend/server.js` 的 HEAD 原有 `import/order` 问题不在本轮顺手重排。未连接生产数据库、未读取真实学生数据、未提交或部署。
