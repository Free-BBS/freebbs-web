# 工作台重复安排、课程周次与讨论区 UI

## 本轮范围

- 新增安排统一支持普通事件、独立 DDL、固定课程（含旁听）
- 普通事件和课程可选不重复、每天、每周、每两周、自定义每 N 天或周；可按截止日期（含当天、北京时间）或次数结束
- 提交前可以展开核对全部日期；每次最多 200 项、生成跨度最多 730 天，每次安排不超过 24 小时
- 重复安排一次事务保存；任何冲突先不写入，明确再次确认才保存；相同规则重复提交不重复写入；所有读取和写入按当前账号隔离
- 保存后逐次编辑，只修改选中的那一次；节假日、补课和调停课仍需手动调整；没有加入整组编辑或无限重复
- 网络学堂“全周、单周、双周”结合用户确认的本学期教学周数生成；前八周固定 1–8 周，后八周固定 9–16 周，不随学期总周数变化
- 缺少星期、时间被截断、有调停课说明的课程继续明确提示，不推测具体安排
- 工作台标题跟随全站字体预设，放大桌面正文、辅助文字和操作项；新增安排弹窗保持手机可滚动操作
- 讨论分区依次为日常、数学、物理、电路、信号、计算机、实验、更新日志；保留已有 slug、ID、帖子、版主和管理员编辑的介绍，不猜测迁移原数理帖的学科归属
- 更新日志仍保留管理员发布限制，所有分区可浏览
- 首页讨论动态最多 24 条，综合/最新/热帖可选；动态与分区互动等高并独立上下滚动；热力榜移到下一整行，避免旁边留下空白
- 综合排序保留置顶优先，其余使用 `(1 + 评论数 × 3 + 互动数) / (1 + 帖龄天数)^1.3`，最终以发帖时间和 ID 稳定排序；评论/点赞/点亮/烟花只来自原有可见性过滤后的聚合
- 讨论区增加大字号、轻边框卡片与多层回复引导线；深层缩进封顶，折叠无需重绘即可更新，删除父评论仍可追踪回复关系；手机导航结构和激光装扮不改
