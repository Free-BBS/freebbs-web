# PR #97：回帖与作者统一柔光

- 回帖列表、新回帖响应和单条回帖读取均按回帖作者的当前激光器租期返回状态；与主帖作者、发布时间无关。
- 历史帖子、历史回帖和新内容使用同一个账号租期。匿名主帖及已删除内容不暴露装扮状态。
- 主帖正文使用独立发光区域，不包含评论列表。嵌套回复仍是各自独立区域，A 的回复不会使 B 的主帖或回复发光。
- 客户端收到作者新状态时同步刷新页面上该作者的卡片与回复，按服务端时钟修正到期时间；到期本地自动熄灭。没有新增跨客户端推送，其他客户端重新读取内容时获取最新租期。
- 商城说明同步为帖子与回帖、历史内容统一生效。
