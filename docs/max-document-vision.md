# Max 文件上传、预览与逐页视觉

附件使用 8 MiB 分片上传，单文件上限 100 MiB，最多四个文件。分片按登录用户隔离，校验总大小与连续偏移；未完成上传十分钟后清理。每片低于现有 Nginx 20 MiB 请求限制，不需要扩大所有 API 的入口限制。保留旧 JSON 解析接口以兼容已打开的旧页面。

PDF、PPT、PPTX 转成有页码的 JPEG，上传完成自动选择视觉模型。一次最多十二页文件图片，总视觉图片（含普通图片）最多十三张。超页数或超过六万字时明确要求拆分，不静默丢弃页面。图片顺序和提取文字一起交给模型；扫描 PDF 无文字也可处理。聊天显示“预览文件”卡片，点击可逐页查看；页面图片和文字保存在该用户的原有私有对话中。单张压缩图不超过 1 MiB。

PDF 在受限 Worker 中渲染。PPT 通过本机 Docker 内网 `http://172.30.77.2:8080` 的转换器转 PDF，可由 `DOCUMENT_CONVERTER_URL` 覆盖。转换器不接受外部 URL，只接受上传字节；独立用户、只读容器、临时目录、禁止外网、禁用宏，限制内存、CPU、进程数及执行时间。

首次部署或更新转换器，在有 Docker 权限的服务器账号下运行：

```sh
bash services/document-converter/deploy.sh
curl -f http://172.30.77.2:8080/health
```

转换器独立于 Web 发布，自动随 Docker 重启。转换器位于固定的隔离内网，不映射宿主机端口，也不能连接外网。转换器不可用时 PDF 仍正常，PPT 会提示稍后重试或导出 PDF。
