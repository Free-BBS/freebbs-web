# 首页与可编辑课程校历 · 2026-09-29

基于已合并的 PR #167，并已同步 PR #168（origin/main c3fe2f9）的三叶草功能。本批统一提交审核，不自动合并。

## 内容

- 首页恢复左侧讨论动态、右侧分区互动与热力榜上下排列；保留独立、限高的纵向滚动。
- 同步课程和作业 DDL 使用普通事件编辑入口。修改只作用于个人计划，不回写网络学堂；完成状态仍有独立按钮。
- 个人修改和删除以用户、校园绑定代次、课程出现标识隔离存储，重复同步不会重复生成同一出现。只覆盖用户改动的字段，其余字段仍跟随上游更新。
- 修改采用事务和校园连接行锁；同时校验版本与源数据指纹，防止旧窗口覆盖新修改。账号重新绑定后不继承旧账号个人修改。
- 本学期默认 2026-09-14 开始、16 周，保留已有有效设置。顶部每天按北京时间显示当天日期、校历周和星期；表头日期不变。
- 同课、同日、同地点的相邻大节（中间休息不超过 30 分钟）合并；周次只在共同上课的日期合并，不把其他课程或不同地点合并。
- 课程卡片和编辑窗口只显示名称、时间及地点/备注，移除逐条教学周说明。
- 第 2 大节可选 09:50–11:25 / 12:15；第 5 大节可选 17:05–17:50 / 18:40；第 6 大节可选 19:20–20:55 / 21:45。设置按课程保存，不改动明确写出的钟点。
- 每小时纵向刻度从 40px 增加后收紧至 48px。一小时及以下事件采用紧凑留白和行距，保留字号，一小时事件可显示名称和一行地点；长事件保留原行距。卡片内名称和备注作为整体垂直居中，文字保持左对齐。备注按剩余高度自动换行，有空间就完整显示，空间不足时省略并可点击查看全文。真实起止位置、分钟级短事件、冲突重叠和重复安排颜色仍保持一致。
- 修复 Max 将“备注里包括……”和“可以持续到17:30”误判为额外事件的问题；明确的结束时间支持直接预览。跨日、互相矛盾或缺失的时间仍交给 Agent 澄清，不移除多事件完整性校验。
- 注册和重置密码验证码按绝对到期时间显示 60 秒冷却，切换标签、窗口恢复及刷新后不重新等待；同页会话保存到期时间，发送中仍禁止重复请求，服务端限流规则不变。
- 三叶草改为每个 1 磁元，同步商城和两处牧场入口。历史收据、库存不改写；旧价格请求需刷新确认后再买。广场按钮文字与相邻场景选择器统一，覆盖浅/深色及手机端。

## 校历范围

日期来自本轮用户提供的清华 2026–2027 校历截图。

- 秋季：2026-09-25、2026-10-01 至 10-07、2027-01-01。
- 春季：2027-04-05、2027-04-30 至 05-05、2027-06-09。
- 跳过这些日期但不顺延教学周，另可填写停课日期或假期照常上课日期。
- 不把调休工作日、校庆教职工上班或混合夏季学期/暑假误判为课程安排；补课请按教务通知添加/移动事件。
- 2027 年假期可能调整，预设不是实时教务接口。
- 普通手动安排不因校历假期而被删除；明确手动移动的课程保留个人修改。

## 兼容与部署

- 添加非破坏性迁移 `database/migrations/058_editable_campus_calendar.sql`：新增个人覆盖表及可空校历选项列。
- 运行时初始化与迁移均可重复执行；不改写网络学堂原始快照，不批量改写现有手动事件。
- 旧客户端仍可读取原有字段；旧服务返回的不可编辑课程仍有只读详情回退。
- 校历预设须与第一周日期一致，避免把其他学期的放假日期误套入当前课表。
