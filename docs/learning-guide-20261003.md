# FREE BBS 学习区使用指南

## 从哪里开始

进入课程，先确认“第一次学 / 不甚熟悉 / 能独立做题 / 完整掌握”。这只是你希望怎样开始，可以随时修改；不是考试，不影响星标。可再选择理解知识、练习解题或探索研究，不选时只给建议，不替你决定。

同一课程中换知识点，不重复打断。点击知识点先看概览，主动进入正文；熟悉的内容可以直接查阅或跳到题目。

## 想系统学一遍

看概览和知识起源，知道为什么学 → 阅读正文，用自己的话做批注 → 尝试分层练习 → 按正式题目范围自测 → 看反馈、订正或等待人工复核 → 在“继续学习”选择下一步。

这条完整路线一直保留，不要求每个人都走完。直接自测、查阅定义和条件、查看关系或探索问题，都可以。

## 我的批注在哪里

直接在课程正文选择文字，高亮、划线或评注；公式、图片和表格可整块标注。“我的批注”打开工具和目录，点击即可定位。正文仍然只有一份，批注仅本人可见，不默认交给 Max 或管理员。正文更新后无法可靠定位的旧批注会保留，不乱贴位置。

## 练习、自测与星标

练习题按基础、标准、挑战筛选，也可以查看探索题。难度是课程组估计，想换题随时可以。

自测使用完整正式题目范围，不因起点或练习筛选而减少题目。客观题按公布规则判定；主观题待课程组复核。订正看正式题的真实记录，练习正确不能代替正式通过。

自主学习星来自当前版本全部正式题目的有效通过记录，不来自阅读时长、手工完成或 AI 赞扬。尚未开发的星保持灰色；没有星不等于不会，更不影响你使用资料。

## 继续学习与 Max

继续学习先显示一个主要建议和最多两个替代入口。展开可看完整顺序、调整、跳过并保存；已保存路径不会被新推荐覆盖。

右侧 Max 根据同一课程内容、你确认的起点与目的及当前任务辅助讲解。需要基础时可请它从术语和原理细讲；熟悉时可请它比较方法、检查条件或讨论反例。它不替课程组判正式题，也不会自动读取私人批注。打开面板不自动发消息。本版没有语音功能。

## 学习记录与隐私

个人主页可看自己的真实作答、订正和待复核记录。过程记录默认关闭，主动开启后才记录访问与工具操作等受控事件，可导出、删除并暂停；关闭不影响笔记和自测。

立即订正与长期掌握不同；延迟保持、陌生情境迁移尚未采集，不会凭空生成结论。管理端看描述性统计，不读取私人笔记、聊天和答案正文，不按时长或星数排名。

页面“学习指南”可随时打开、关闭和重看。需要反馈内容错误或推荐资源时使用“参与共建”，由课程组审核处理，不直接改官方正文。

本地预览的题目、身份和 AI 回复是模拟验收材料，重启会清空服务端内存记录；不要在预览填入真实隐私信息。
