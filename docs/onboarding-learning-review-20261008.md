# 本轮学习与新手导引更新

## 本 PR 的范围

将本地学习链改动与本轮导引、注册提示和加载恢复一起提交。不包含线上部署或 Docker / Podman 迁移，生成的 PDF 和浏览器截图不进入仓库。

学习部分保留一套官方正文：概览与知识起源、正文上的私人批注、分层练习与正式自测、继续学习、课程内 Max、学习记录和参与共建。课程组使用 [V4.2 Markdown 提交包](course-authoring/README.md)，无需为不同起点另写教材。

## 基础导引

max-v5 共 17 个画面，11 个目录站。可以暂停、返回、选站和重看，不要求走完才能使用平台。

| 顺序            | 画面                                                                     |
| --------------- | ------------------------------------------------------------------------ |
| 开始            | 首页                                                                     |
| 学习，保留 7 步 | 学习世界、领域概览、课程入口、知识点选择、直接关联、学习概览、正文       |
| 八页，各 1 步   | 讨论区、工作台、实验室、创意工坊、PBL 计划、问问 Max、发展端、电磁场商城 |
| 结束            | 随身手册                                                                 |

其他页面只高亮稳定入口，不等待可选帖子、商品或个人数据，不自动发帖、发送 AI 请求、运行代码、购买、同步校内账号或填写资料。建设中的页面明确当前状态。

首次进入课程仍由同学选择学习起点，不替用户选择或保存。确认后导引自动续接；同一课程内不反复要求选择。

max-v4 的 16 步及 max-v3 的 58 步按原顺序保留，已发布短游与收据不重排。基础导引升级不重复发奖，仍按账号仅一次 10 电元和 10 磁元，与学习星标无关。

## 学习证据与星标

起点四选一：第一次学、不甚熟悉、能独立做题、完整掌握；目的可选理解知识、练习解题、探索研究。12 个组合有确定的初始建议，同学可以调整。起点是自我报告，不等同于实际掌握或成绩。

正文始终只有一份，私人批注只属于本人。题目按用途和难度组织；正式自测不能通过缩小题目集合、做练习或探索题获得通过。客观题按发布规则判定，主观题等待课程组复核。

自主学习星依据当前正文与题目版本的全部正式自测有效通过证据。历史已得星保留，同时显示当前版本的学习进度。深入掌握等后续星保持灰色，课程学习星尚未接入成绩。

Max 的辅助上下文使用真实题目版本和每题最新正式作答，再检查当前版本，避免把旧通过记录误作当前证据；不自动上传私人批注。AI 教学质量、生产模型和真实课程覆盖仍需上线验收。

## 注册与加载

注册的用户名、姓名、学号、邮箱、验证码、密码、确认密码、公约错误在各自控件旁显示红色；输入纠正会清除相关错误。网络或服务错误不误标某个字段。验证码重发按绝对时间计算，后台、刷新和页面恢复均继续计时。

前端静态 HTML / JS / CSS 保持重新校验缓存的既有策略；导引依赖使用一致的新版本 URL。失败依赖可原地重新加载，成功模块不重复下载，控制器不重复初始化，普通页面仍可使用。

## 提交前验证

本地独立内存夹具与独立 Chrome，不使用生产账号、数据库、校内连接或外部模型。浏览器包括电脑/手机、明暗主题、大字、慢加载、用户确认课程起点后的续接、模块 404、连接中断恢复和三轮真实热缓存刷新。

常用复跑入口：

```sh
npm run test:onboarding
npm run test:auth
npm run test:onboarding:browser
npm run test:onboarding:reliability:browser
npm run test:learning-workspace:browser
npm run test:learning-stars:browser
npm run test:learning-chain:browser
```

浏览器需配置 PUPPETEER_MODULE 和 CHROMIUM_EXECUTABLE。内存测试不等同于生产 MySQL、运行容器或真实 AI 的验收；没有将缺少 Docker daemon 的本机检查写成沙箱集成通过。
