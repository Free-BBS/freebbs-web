# 设置页对齐与新版导航导引适配

## 界面调整

- 姓名和个人网页字段顶端对齐且同高，姓名下的管理说明只影响本字段高度；1024px 及以下仍沿用原有单列布局
- 邮件通知开关开启绿色、关闭灰色，保留原生复选框和 44px 触控区域，支持键盘；开关和状态文案间距统一为 8px，只有点击保存才写入偏好
- 1180px 以上邮件通知与修改密码并排等宽等高，提交按钮底端对齐；窄屏保留上下排列
- 左下角发展端按钮比资产行下移更多：相对本轮最初布局，移除 12px 按钮间距及 12px 底部留白，资产行仍有内部触控留白
- 修复手机折叠标题箭头旋转后产生的横向溢出，保留原有手机布局

## 导引兼容

- 新桌面顶栏替换了旧的伪元素标题，导引现在按真实顶栏底部计算高亮目标的安全位置，兼容大字号
- 同步设置和明暗图标、左下角资产说明、前往发展端、实验室两层入口的文案
- 不增加或重排既有 48 步，不更改版本、进度与奖励资格；导引仍不提交邮件、密码、AI、发帖或购买操作
- 导引浏览器预览补齐与生产一致的 desktop-shell、personal-polish 和统一页脚，避免测试旧布局

## 验证

- 设置页 120 组组合：5 种宽度、2 种明暗模式、4 套字体、3 档字号，无横向溢出和浏览器异常；验证输入框、卡片与开关状态对齐
- 模拟账号点击和键盘切换开关，确认未保存时不发送修改请求，保存后刷新可恢复状态
- 完整导引在桌面亮色、手机暗色、桌面暗色中宋大字号三个场景各走通 48 步；课程接口延迟 3.5 / 6.5 秒后仍可继续，包含暂停恢复与课程学习面板开关
- 浏览器记录无非预期业务写入，只写导引进度和一次性奖励；验证奖励仅增加 10 电元和 10 磁元，不改热力或物品
- onboarding 测试集 258 项通过、2 项 MySQL 集成测试未启用；另外设置、个人空间、字体与页脚相关 70 项通过

复现命令：`npm run test:settings-layout:browser`、`npm run test:onboarding:browser`、`npm run test:onboarding`

上述均使用真实前端代码及隔离内存接口，不等价于线上真实账号验收；本轮未提交或推送。
