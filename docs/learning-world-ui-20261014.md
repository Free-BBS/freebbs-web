# 学习世界：现有知识点兼容与界面调整

## 展示与导航

- 真实章名目录、独立知识点选择器、当前知识点分开呈现。章节先展示数量、已有层级及最多三个真实入口，不把整章全部知识点自动展开成图。
- 选择一个知识点后展示“可先了解 / 接着了解 / 补充联系”，保留真实跨章归属；关系图默认作为折叠辅助，不将连线解释为强制先修。
- 学习概览按课程与章节、完整标题、简介、事实、真实署名组织；空事实和空署名区不占位。底部始终保留查看关系、进入学习，正文独立滚动。
- 备用目录支持本章名称/编号搜索和每页 12 项。输入保留焦点、光标与中文输入法组合状态；切章重置旧章筛选，切换两种视图保留当前章。
- 若目录筛选脚本不可用，明确提示并显示全部本章内容，不静默截断。保持既有概览加载失败提示与迟到响应隔离。
- 没有作者知识起源的旧稿不显示紫色空框；有真实起源仍可吸顶、收起和批注。阅读标题统一换行和层级，不改变正文阅读字号。

## 兼容边界

沿用原有三个 Markdown 分区和课程组模板。真实零级章稿可以打开章概览，没有零级稿时仅按已有元数据组织目录；缺真实章名以编号回退，不编造内容。缺起源不会删除正文，也不将应用简介冒充起源。评分扩展、参考解答、正文/起源版本指纹及私人批注归属未改变。

匿名公开调试数据包含数学 296 点、信号与系统 165 点、电路 53 点、数字逻辑空课程；公开详情不是含评分配置的完整作者备份。最新地图于 2026-10-14 读取，部分详情使用 2026-10-12 的公开快照，无生产写入。
