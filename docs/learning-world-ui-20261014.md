# 学习世界：现有知识点兼容与界面调整

本分支从已合并 PR #180 的主分支继续开发，以下按日期保留本地验证边界。未修改线上课程稿、节点 ID、题目评分、星标或权限协议；本地预览、PR 合并均不等于已经部署。

## 2026-10-16：以真实学习任务检查入口与接续

学习入口同时保留路线、直接查找与完整目录，不要求不同使用者走同一条通道。

| 使用任务                     | 可见入口与接续方式                                                 | 不作出的推断                               |
| ---------------------------- | ------------------------------------------------------------------ | ------------------------------------------ |
| 第一次接触，不知道从哪儿开始 | 一次六个点的分段路线，点击先看概览；可选指南说明入口               | 路线不是锁关，浏览不代表掌握               |
| 临时查一个概念、公式或编号   | 全课程搜索、真实章名与宽幅完整目录；可以直接进入对应内容           | 不强制重新选择目标、读完正文或先做题       |
| 中断后回来继续               | 上次位置、原查找和目录分页接续；浏览器后退也恢复原目录             | 最近位置不是学习完成证明                   |
| 复习、订正或夯实基础         | 保留统一正文、私人批注、已有反馈题与“继续学习”的自主选择           | 路线不覆盖已保存个人路径，自述不当能力测量 |
| 教师查阅或研究者探索         | 查找和真实跨章联系直接可用，概览可转到关系区；支持独立标签页查阅   | 不据教师身份放宽资料、评分或分析权限       |
| 手机、大字或键盘操作         | 手机六点路线随整页滚动，完整标题换行；目录、概览关闭后恢复可见焦点 | 桌面触屏模拟不等于真机验证                 |
| 想暂停或求助                 | 暂停当前路径、随时改活动；选文后主动准备 Max 问题，明确发送才调用  | 不自动发言，不把暂停当放弃或能力不足       |

路线仅使用已发布的章内 `ordered` 关系，显示真实分支、汇合和循环；缺这种关系时标注目录顺序，不画装饰性先修链。`related` 与跨章关系仍在直接联系中查看。阅读端的避障排布不回写作者坐标，也不要求课程组再提交一套教材或新增字段。

完整目录每页最多 40 点，支持名称、编号、别名与真实章名；本章筛选只是可选收窄范围。打开知识概览后取消，回到原卡片；从正文返回保留原查找、章、路线分段与目录状态。明确点击“查看知识关系”时直接定位并聚焦当前关系区，不只关闭概览让同学继续翻找。

另一个标签页接续阅读时，只局部更新上次位置、路线标记与顶部计数，不替换正在输入的目录。账号失效或切换时立即清掉旧账号的私人提示；其他账号、其他课程的存储变化不冒充当前学习位置。初次课程请求失败有明确的手动重试和返回入口，等待中不重复请求；请求成功也不抢走用户在等待期间已移开的焦点。

课程入口的上次位置与手动标签沿用按账号隔离的浏览器存储，本轮验证同浏览器刷新、多标签页和返回，不宣称已完成跨设备最近位置同步。这不改变私人笔记、批注和正式作答的既有后端保存方式；换设备接续是后续需要单独研究、实现和验收的使用场景。

路线按钮采用可见标题、编号、状态和分支文字的原生名称，不让固定的辅助标签盖住“上次看到”等变化；圆形序号只是装饰。操作说明与名称分开。这与 [WAI 按钮模式](https://www.w3.org/WAI/ARIA/apg/patterns/button/) 的原生内容命名、补充描述和按操作交接焦点原则一致；仍需真实屏幕阅读器使用者补做检查。

手机 Max 覆盖式面板打开后，Tab 和 Shift+Tab 在当前可见、可用的面板控件间接续，不进入背后看不见的学习标记；桌面仍是可自由切换的非模态侧栏。关闭或 Escape 返回原入口并保留草稿、阅读位置，子对话框和批注浮层优先处理自己的键盘操作；窗口变宽时立即解除手机范围，不自动发送任何问题。

可选模块未加载时保留可用通道：辅助图故障不拖垮路线与查找；缺路线脚本仍能用目录；缺概览组件或浏览器原生对话框能力，明确进入对应正文并保留安全返回地址。不会用残缺的空面板冒充已加载课程。

本轮另修正过程统计的局部口径：暂停当前路径时不累计该路径板面的活跃停留估计；本人仍可去读正文或做题。隐藏、失焦、闲置、账号切换均不能继续归给当前阅读。没有新增上传的统计事件类型、后端学习记录协议、自动作答或授星。

本地完整预览将真实公开课程快照与隔离的导引、账号和模拟 Max 接到同一个来源；不必跨端口来回找。公开快照不含完整作者评分配置，不可当作课程备份上传。

### 验证与解释边界

检查包括新手、临时查阅、复习、探索、教师多标签页以及手机大字场景；实际操作覆盖搜索与中文输入法、目录深处打开与返回、关系区定位、阅读与批注、明确发送前的 Max 草稿、暂停和重新接续。真实时钟检查将前台阅读与后台、失焦、闲置、暂停区分，不能只靠人工改 `document.hidden` 或伪造计时器得出结论。

时长仍是参与估计而非净学习时间。当前闲置阈值 60 秒、心跳约 20 秒；截止前的有效尾段可能在后一次心跳才上报，观察到新上报不能直接解释为新学习。独立闲置检查须在未暂停的正文上等待阈值和心跳尾账排空，再观察零新增，并用真实交互恢复作为阳性对照；不以已暂停板面的零值代替闲置证据。后台、暂停和账号切换另测，不混为同一个原因。

静静阅读长段落超过 60 秒也可能没有输入，因此这套统计会低估部分真实学习；不能据“记录少”认定没有学习，更不能用于能力排序、授星或判定平台效果。本轮不另改闲置政策，也不把它宣传成精确阅读时长。

所有接口写入均为隔离本地内存，模型为模拟响应。它验证的是交互、归属、输入资料和版本范围，不能证明真实模型回答正确或学生已经受益。正式发布仍需生产权限、数据库、真实模型和学生任务观察分别验收。当前本地响应的 `no-store` 策略未让 Chrome 命中 BFCache；已验证实际浏览器后退重载，但不宣称已验证 BFCache 命中后的恢复。物理手机、真实屏幕阅读器与非 Blink 浏览器仍需补做真人检查。

最终冻结版本的本地学习与共享 UI 套件：1,487 项中 1,485 通过、0 失败、2 跳过；跳过项分别为真实 MySQL 集成和可选的全字体预设 Chrome 专项，不将其算作验证通过。界面冻结版本另有 Chrome 23 场、Edge 23 场、四种学习起点与账号隔离共 9 场流程全部通过；Edge 与 Chrome 同属 Blink，不当作独立引擎覆盖。目录、Max 的 320px / 两倍根字号、原生正反向 Tab、来源状态辅助名称均单独检查。

最后的真实计时发现闲置恢复首次心跳会补算输入前的空闲：25 秒窗口累计 38 秒。已限定在从闲置恢复时结清合法旧尾段，并从实际输入时刻重新开始计时；连续活动不重置累计，旧尾段不能重复上报。最后这步只改统计脚本、缓存键和测试，未改上述界面布局与导航；新增七项单元覆盖恢复上限、尚未上报的合法旧尾段、连续活动不丢失，以及隐藏、失焦、暂停、账号替换的归属保护。原先只判断恢复后大于零的绿色报告不当作精度通过，保留其原始记录与评注，以严格上限的真实时钟复验为准。

最终计时版本以真实 Chrome 标签页完成约七分半钟、十三阶段的连续复验，源指纹全程未变：后台 45 秒、路径暂停 30 秒、目录停留 25 秒及旧账号隔离 35 秒均无阅读时长新增；未暂停的正文经过 90 秒尾账排空后，再闲置 45 秒仍为零。实际输入恢复后的 25 秒窗口有正向记录，且不超过真实窗口上限；独立闲置复验也通过同一严格判据。此处验的是计数边界，不是对安静阅读或学习成效的准确测量。

每轮浏览器验收比对源指纹；开发中途改动引起的混合版本运行保留作诊断，不计入最终冻结通过数。预览的 85 个直接引用脚本与样式均可取到，课程组下载包分别核对 28 / 9 个来源文件。课程加载一次失败后的显式重试、多标签接续与账号失效另有真实交互验证，不以自动重试掩盖首次失败。

## 2026-10-14：原有目录与单点关系调整

### 展示与导航

- 真实章名目录、独立知识点选择器、当前知识点分开呈现。章节先展示数量、已有层级及最多三个真实入口，不把整章全部知识点自动展开成图。
- 选择一个知识点后展示“可先了解 / 接着了解 / 补充联系”，保留真实跨章归属；关系图默认作为折叠辅助，不将连线解释为强制先修。
- 学习概览按课程与章节、完整标题、简介、事实、真实署名组织；空事实和空署名区不占位。底部始终保留查看关系、进入学习，正文独立滚动。
- 备用目录支持本章名称/编号搜索和每页 12 项。输入保留焦点、光标与中文输入法组合状态；切章重置旧章筛选，切换两种视图保留当前章。
- 若目录筛选脚本不可用，明确提示并显示全部本章内容，不静默截断。保持既有概览加载失败提示与迟到响应隔离。
- 没有作者知识起源的旧稿不显示紫色空框；有真实起源仍可吸顶、收起和批注。阅读标题统一换行和层级，不改变正文阅读字号。

### 兼容边界

沿用原有三个 Markdown 分区和课程组模板。真实零级章稿可以打开章概览，没有零级稿时仅按已有元数据组织目录；缺真实章名以编号回退，不编造内容。缺起源不会删除正文，也不将应用简介冒充起源。评分扩展、参考解答、正文/起源版本指纹及私人批注归属未改变。

匿名公开调试数据包含数学 296 点、信号与系统 165 点、电路 53 点、数字逻辑空课程；公开详情不是含评分配置的完整作者备份。最新地图于 2026-10-14 读取，部分详情使用 2026-10-12 的公开快照，无生产写入。

### 验证范围

覆盖真实密集章节、长标题、跨章关系、无零级节点、无连接及空课程；在 Chrome 中检查明暗模式、1440×900、390×844、320×500 与放大字体。另验证搜索分页、中文组合输入、正文/起源私人批注保存、删除、撤销、刷新和 Max 草稿流程。

本地接口使用隔离内存和模拟 Max，不能证明真实模型教学效果、生产数据库兼容或真机触屏体验；数据库与运行时另以 PR 自动检查结果为准。
