# 新版全站导引 UI（2026-09-27）

## 范围

基于本地分支 `feat/home-copy-polish-20260926` 的兼容合并 `c6bd346` 开发，
包含 main 至 `353308c` 的页面结构。本轮只调整导引、手册与相应测试，
不改变导航布局、牧场产出规则或生产数据。

## 新版体验

- 完整导引升级为 `max-v3`，共 19 章、58 步
- 顺序：全站入口 → 首页 → 学习世界 → 课程地图 → 知识点 → 讨论区 →
  我的工作台 → 实验室 → 创意工坊 → PBL 计划 → 问问 Max →
  活动报名（试用）→ 发展端 → 资产入口 → 商城 → 仓库与账本 →
  设置 → 个人主页与牧场 → 随身手册
- 手册采用带编号的章节卡片；引导卡使用清晰标题、较小的 Max 插图、
  连续进度条和可跳转章节目录；窄屏保留紧凑说明与展开功能
- 签到步骤只打开月历，不代签；未登录用户只介绍入口，不打开登录窗口
- 实验室区分已开放的电路、制作工具与规划中的运行环境；
  创意工坊、PBL 明确显示规划状态
- 手机资产提示指向实际可见的仓库入口，不强行展示隐藏的桌面资产区
- 已加载的空活动列表立即解释，不再等待目标卡片 10 秒；
  后续真实卡片出现时仍会重新定位

## 从新版开头开始

按本轮确认，不保留旧完整导引的续接 UI，也不把旧数字步骤映射到新版。
老用户和新用户首次进入 v3 时均从头开始，可主动选择章节、暂停或重看。
旧完成及奖励记录仍留在服务器，既不删除账户历史，也不重复发放奖励。
已领过的账号不会再领；未领取的账号完成完整导引仍获得 10 电元和 10 磁元。
短导览不获得完整导览奖励。

旧短版本的记录标识保留在协议层，避免历史记录失去识别；普通入口只展示
新版完整导引和本次布局更新概览，不呈现旧版完整导览。
