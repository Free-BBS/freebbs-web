# FreeBBS 个人信息收集与使用清单草案

审阅稿 v0.1 · 2026 年 10 月 13 日 · 尚未生效

本清单配套[隐私政策草案](privacy-policy-draft.md)。仅在对应功能使用或所述处理发生时适用。字段列举主要类别，不能据此增加与功能无关的收集；未核实的生产配置及期限列入[审阅说明](privacy-draft-review.md)，发布前补齐。

## 功能和数据范围

| 功能 | 信息来源及主要类别 | 处理目的 | 可见或接收范围 |
| --- | --- | --- | --- |
| 注册白名单 | 相关老师或院系提供的姓名、学号、邮箱；资格有效与使用状态 | 邀请范围及注册资格核对、防止重复占用 | 管理员与账号服务；不向公众展示名单 |
| 账号和登录 | 用户填写或管理员建立的身份资料、用户名、邮箱、密码验证信息、角色及验证记录 | 建立账号、身份核对、登录和找回、权限控制 | 本站账号系统、必要的管理员；验证邮件经邮件服务发送 |
| 个人主页 | 用户名、头像、简介、个人链接、年级或专业、选择展示的活动与作品 | 个人展示、识别内容作者和站内互动 | 按页面及功能设置向访客或其他用户展示；后台保留身份关联 |
| 讨论区 | 帖子与评论正文、图片、作者关联、回复、点赞、时间、可见性和处理状态 | 展示交流内容、维持回复关系及管理内容 | 按公开或登录可见等实际设置；管理人员按权限处理 |
| 内容检查 | 待发布的文字图片、送审副本、必要上下文、机器结果、人工决定和说明版本 | 社区规则检查、复核、异议处理 | 对应作者、审核负责人及处理所需后台服务；外部模型见服务清单 |
| Max 文字和图片 | 用户提问、相关历史、回复、所附图片及任务上下文 | AI 问答和保存会话 | 用户本人、相应处理服务；管理员必要调查见政策第五部分 |
| Max 文件分析 | 文件名、提交的文件、转换后页面、提取内容和笔记 | 按用户请求分析文件 | 本站文件服务及当前任务需要的模型服务；文件分析可能覆盖整份文件 |
| 评论及课程中的 AI | 提问所在帖子、评论、课程资料、电路或其他任务内容 | 结合上下文答疑和生成回复 | 当前任务所需的内部及外部服务；上下文可能包含其他用户发言 |
| 笔记、自测和课程反馈 | 用户记录的笔记、答案、结果、学习状态、反馈及回复 | 保存学习进度、答疑、课程反馈 | 本人及对应功能授权人员；课程反馈范围与私人笔记分别控制 |
| 学习分析 | 启用后产生的学习事件、参与情况、时间；相应统计涉及已有业务记录 | 展示学习情况和提供课程分析 | 本人及代码授权的课程管理范围；关闭事件收集不删除业务记录 |
| 课程表、作业和日程 | 用户填写、课程发布或授权同步的数据、备注、提醒、规划偏好 | 安排学习任务、同步和提醒；用户调用时生成 AI 规划 | 本人及相应课程功能权限范围；AI 规划外发必要任务上下文 |
| 校内服务连接 | 授权时提交的校内账号和必要验证信息、会话凭据、选择同步的课程或作业内容 | 连接所选服务并获取授权内容 | 本站连接器及实际校内/Info 服务；须核实正式启用模式 |
| 通知与邮件 | 接收账号或邮箱、通知正文或摘录、链接、发送及已读状态 | 发送活动、互动、验证和服务提醒 | 接收人、本站通知系统及实际邮件服务商 |
| 活动与问卷 | 用户填写的邮箱、选项、自由文本、附件、必要身份关联及回执 | 活动报名、组织、抽签及查询 | 活动说明指定的组织方、负责人和管理员；免登录或凭回执查询不等于匿名收集 |
| 课程资料和工具 | 上传资料、作者关联、代码或电路、输入输出、结果及保存状态 | 资料维护、仿真、编程或主动请求的 AI 辅助 | 对应资料访问者、工具服务及授权人员；浏览器本地计算与服务器处理分别核实 |
| 签到、积分和展示 | 签到、积分账本、奖励、互动和装饰记录 | 活动激励、个人记录和展示 | 本人、相应管理功能及按页面公开的部分；不据此声称收集真实支付账户 |
| 发展板块 | 主站身份映射、组织关系、动态表单答案、附件、报名/参与/财务活动或作品资料 | 组织活动和资料管理 | 对应组织权限范围；公开作品按相应展示安排处理 |
| 浏览器存储 | 登录令牌、偏好、草稿、进度缓存和活动回执 | 保持状态、恢复操作和本地使用体验 | 主要保存在使用的浏览器；有关功能也可能向服务器同步 |
| 安全和运维 | 必要请求信息、访问时间、状态、安全事件、错误及管理操作记录 | 安全保护、故障处理、恢复和责任核查 | 有职责的运维与管理人员及必要基础服务商 |
| 反馈与个人信息请求 | 来信地址、账号或内容标识、问题描述、必要核验及处理记录 | 处理咨询、权利请求和投诉 | 指定工作人员及处理所需的相关服务方 |
| AI 对话调查导出 | 选定用户、会话和时间内的对话及必要身份关联；调查理由和操作记录 | 调查具体社区规则事件等必要事项 | 网站管理员按调查范围使用；目标功能待实现后生效 |

上传图片或文件可能在最终提交之前已经发生；告知和相应确认应覆盖实际上传时点。文字替换和匿名显示都不能保证无法关联个人。

## 保存与删除安排

下表保留了代码事实与尚待决定事项的区分。含“待定”的项目不能直接用于正式发布。

| 数据类别 | 本轮可确认的安排 | 定稿和验收要点 |
| --- | --- | --- |
| 审核提交证据 | 从提交创建时起设置 30 天到期；到期限制读取，并由清理任务移除原稿、相应理由与模型结果等 | 核实任务运行和清理延迟；未发布附件到期清理，已发布图片不在该范围内 |
| 审核关联记录 | 编号、作者关联、状态、时间等不会全部随证据清理删除 | 单独确定必要字段、期限及删除方式，不能称 30 天后全部审核数据消失 |
| 学习分析事件 | 代码删除创建时间早于 180 天的事件，另有个人清除能力 | 核实生产执行；不包含所有答题记录、笔记和课程数据 |
| 未完成 Max 文件分片 | 代码在分片等待超时后清理，超时为十分钟；收到后续分片会重新计时 | 验证异常退出残留；不适用于完整文件 |
| 已完成 Max 文档与 AI 对话 | 当前未核实统一到期清理期限 | 待定；需覆盖文档、页图、历史中的附件引用和导出副本 |
| 校内连接凭据 | direct Learn 授权代码限定最长八小时；原始密码不持久化是该模式的设计 | 核实实际模式；不将这一期限套用于 Info、已同步课表或其他记录 |
| 账号、白名单和资格占用 | 数据库保存，移除名单可为停用；删除账号不会自动释放全部资格记录 | 待定；分别处理未注册、毕业、退出资格和注销场景 |
| 帖子、评论及图片 | 公开内容继续保存供展示；隐藏或撤回可能仅更新状态 | 待定；删除请求需要检查正文、图片直链、索引和必要记录 |
| 学习、问卷及发展记录 | 各业务记录分别保存 | 待定；按个人历史、活动结束及组织管理目的确定期限 |
| 调查导出副本与审计 | 导出改进已确定，审计未实现 | 两类期限分别待定；审计应记录操作和范围，避免再次复制对话正文 |
| 反馈、权利请求和备份 | 取决于运营流程和部署 | 待定；明确受理期限、轮换周期、访问及恢复后的删除落实 |
| 网络安全日志 | 按适用法定要求保留；正式部署策略尚待核实 | 相关网络日志不少于六个月的要求不能扩展成所有业务内容都保存六个月 |
| 供应商记录 | 不由本站删除接口直接控制 | 见外部服务清单，核实具体期限与协调删除机制 |

删除或注销应核查主站数据库、发展板块数据库、附件、派生内容、相关导出和备份。首次可通过邮箱申请并由工作人员处理，政策不应描述尚不存在的全站一键注销能力。

代码依据及详细边界见[调研证据](privacy-research-20261012.md#代码证据索引)和[最新主站核对](privacy-verification-20261013.md)。相关日志要求依据[《网络安全法》第二十三条](https://www.cac.gov.cn/2025-12/29/c_1768735112911946.htm)。这些依据用于审阅，不代表正式环境已完成验收。
