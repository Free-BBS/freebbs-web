# 首页结构实验稿 · 2026-09-11

本轮是供 NotingSr 比较和调整的本地实验，不是 V1.0 全部功能完成声明。未提交、推送或合并；开发基线为 `68ba4fa`。不修改此前的昵称规则、知识起源框、课程地图、后端或数据库。

## 依据与取舍

依据《FREE BBS平台定位与V1.0规划-20260728》5.2“主页：一站式平台入口”，以及已确认的“让学习自由而不孤独”和学生主导、长期公益、独立于评价体系的定位。

- 首页先回答“下一步做什么”：学习世界作为主入口，讨论区、工作台、Max 紧邻，不以纯社区榜单开场。
- 延续 BBS 仿生羊的深青与米白配色，复用已有数学、信号岛屿素材，不重新制作视觉资产。
- 三个 FREE 用简短文字解释：知识联系、交流判断、尝试验证。电路实验室作为自主探索的现有入口。
- 社区动态放在行动区之后；保留原来的热帖/最新切换、分区互动和热力榜加载、空态、失败重试逻辑。热力明确不代表学习能力。
- 删除没有实际功能的首页搜索表单；底部保留“关于FREE BBS”和“FREE BBS工作人员名单”两个可展开区域，按最新反馈均显示“正在施工”，不编造名单。首页暂时移除 Feedback / 邮件反馈入口。
- 小屏三个快捷入口并排，课程链接可横向滚动；沿用原有小屏隐藏分区互动的策略。页面自然滚动，不再把整屏切成两个内部滚动窗口。

## 继续浏览：当前边界

复用工作台已有的 `free_bbs_last_learning_route`，首页只读，不新建学习进度或账户数据。

1. 没有记录、记录损坏、存储不可读：默认“进入学习世界”。
2. 已知课程页记录：显示“继续上次浏览”。
3. 知识点记录：通过现有只读接口确认知识点仍可读取，再呈现入口；请求失败或知识点失效时保留默认入口。
4. 对路由、课程、参数做允许列表和长度检查，不接受外部地址；异步返回不覆盖较新的记录或会话检查。
5. 明确显示“本浏览器最近访问”“非账号同步记录”。它不是学习完成度，也不是跨设备、按账号隔离的学习档案。旧记录不进行静默迁移。

## 预览方式

在开发仓库的 Git Bash 中运行：

```bash
npm run preview:home
```

打开 `http://127.0.0.1:3107/`。这是只读、独立来源的首页实验服务：无数据库、无真实登录、无线上请求，不使用 3000/3001，不更改真实资产或课程。底部黄色提示条明确标出演示数据；所有写请求拒绝。其他功能入口在此展示隔离预览说明，不模拟完整产品功能。

- 新访客：`http://127.0.0.1:3107/?resume=no`
- 有浏览记录的演示成员：`http://127.0.0.1:3107/?resume=yes&session=member`
- 暗色：`http://127.0.0.1:3107/?theme=dark`
- 空数据：`http://127.0.0.1:3107/?case=empty`
- 加载失败：`http://127.0.0.1:3107/?case=error`

原本的完整本地系统仍使用 `bash scripts/start-local.sh`，访问 `http://127.0.0.1:3000/`。本轮没有启动真实后端或执行数据库迁移；只有你主动使用完整系统时才会连接该系统配置的 API/数据库。

- 开发者与致谢的正式名单及维护页面。

## 验证

自动化入口：`npm run test:public-pages`（已纳入现有 CI），25 项首页测试，覆盖布局契约、资源存在、继续浏览参数校验、失效回退、存储异常、异步竞态、施工占位以及隔离预览的只读限制。

本轮回归：74 个独立测试文件，811 项测试，其中 804 通过、0 失败、7 项真实数据库集成测试按原有条件跳过。未将跳过项当作已验证。

Chrome 隔离浏览器检查覆盖 1440 / 1024 / 768 / 390 / 320 宽度、明暗主题、无记录与有记录、空数据与加载失败、动态排序、关于区域展开，以及阅读字体/字号适配。演示 API 请求全部限制在隔离来源；这不是线上数据验收。
