# 知识图阅读布局调整（2026-10-15）

## 展示方案

- 当前知识点居中，前序和后续节点沿左右扇面轻微错落；首个补充关联利用中心下方空位。
- 位置确定、无持续动画；颜色只帮助区分分支，真实方向仍由箭头表达，关联仍为无方向虚线。
- 正交圆角连线避开全部节点矩形，箭头沿末段指向目标，端点与框留出间距。
- 关系图占课程内容区全宽；密集图保留可读字号和拖动、缩放，不宣称全部关系能塞进一屏。
- 320/390 px 窄屏采用单列，首卡完整可见，键盘焦点会将整张卡片带入视口。
- 标题最多两行，按实际 SVG 字宽排版；长 ID 保留头尾，完整信息仍在可访问名称、提示和链接中。

`public/learning-graph-layout.js` 供课程结构图与 0 级章节的本章网络共用。它只派生阅读坐标，不写回课程组的 `position`、知识点或边，不改编辑器的作者坐标操作。

结构图仍只展示选中点的真实一跳关系，未展开整章所有点。历史材料没有 0 级节点时，不补造章节节点或关系。章节网络仍只纳入本章普通知识点。

## 选型依据

参考 [Cytoscape 的邻域与布局说明](https://blog.js.cytoscape.org/2020/05/11/layouts/) 和 [ELK Layered 的端口、分层和正交路由说明](https://eclipse.dev/elk/reference/algorithms/org-eclipse-elk-layered.html)。这里采用轻量、稳定的扇面分组与避障路由实现，并未新增 D3、Cytoscape 或 ELK 依赖。适用性是本平台的设计选择，并非证明某一种布局普遍最优。

## 验证

- 17 项共享布局专项：输入不变、重复坐标、循环、自环、双向/平行边、密集中心、真实曲线采样、长标题、宽字母 ID、不可测量时的保守回退。
- 514 个现有公开点分别按桌面/窄屏遍历，共 1,028 个布局、3,124 条路由，无丢边和布局异常。
- 相同学习/共享 UI 单测全集以 `--test-concurrency=4` 跑完：1,382 项通过、0 失败、2 项显式可选检查跳过。默认高并发曾有不同 loopback 请求暂态失败，降低并发的相同全集复核通过；没有通过业务重试掩盖失败。
- 实际 Chrome：13 个真实课程场景，加 2 个跨章完整示例，全部通过；另有 18 个章图边界场景，全部通过。覆盖明暗、320/390/1400/1440、SVG 路径/箭头/文字实际几何、键盘、导航返回和源文件哈希。
- 课程组模板 ZIP 与源文件一致：28/9 个源文件检查通过。没有改模板、上传协议、后端或数据库。

浏览器脚本：`scripts/check-learning-graph-layout-browser.js`（需显式本地隔离预览）与 `scripts/check-learning-chapter-graph-browser.js`（自建隔离夹具）。本轮截图和 JSON 报告保存在 `output/knowledge-graph-20261015/`，保留旧轮次输出、不自动提交。

真实课程图来自已有公开快照，身份和学习记录为本地内存模拟；章图压力夹具不是生产课程。没有生产写入、真实模型调用、数据库集成验收或学习成效结论。
