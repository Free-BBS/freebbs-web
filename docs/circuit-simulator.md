# 电路实验室使用说明

电路实验室可以在浏览器中搭建电路、运行分析并引用到讨论帖子、评论和课程知识点。入口是站内 `/circuits`，新建与编辑页面为 `/circuit`。

也可以点击「识别电路图」，上传、拖入或粘贴一张原理图；手机端可直接点击「拍照识别」调用相机。检查识别预览和待核对项后，生成可编辑的新电路草稿，再保存获得 CID。支持 PNG、JPEG、WebP，单张最多 8 MiB；详见 [电路图识别](circuit-recognition.md)。

## 创建、接线和保存

1. 在“我的电路”中选择新建，填写标题和说明；也可以从页面提供的示例开始。
2. 从元件列表添加元件。拖动元件调整位置，点选后在元件旁的参数浮层修改，也可使用右侧“元件参数”标签；右侧另有 Max 对话标签。使用“旋转 90°”或镜像调整方向，标注和电流指示会跟随变换。
3. 从引脚拖到另一个引脚或导线建立连接，也可依次点击。落在已有导线上会拆分导线并显示实心连接点；选中导线点击“从此处连线”，再点击另一导线或引脚，可直接接线。普通交叉不接通。连接过程有虚线预览与落点提示；拿起导线后，点击空白画布设置拐点，再点击目标引脚或导线完成。Escape 或“取消连线”取消未完成连接，不留下连接点。
4. 放置“参考地”并连接电源公共端或其他参考节点。所有参考地元件表示同一个零电位。电路应具有确定的电位和满足约束的回路；浮空节点、冲突的理想电压源等情况会报错。
5. 选择分析类型并运行，检查测量通道和波形。参数或接线改变后重新运行，结果才对应当前草稿。
6. 登录后点击“保存并获取 CID”。每位普通学生都能创建电路，首次保存获得 `c_` 加 24 位小写十六进制字符组成的唯一 CID；再次保存生成同一个 CID 的新版本。

可以保存尚未接完或尚未接地的草稿，仿真时再检查电路是否可求解。标题为 1–120 个字符，说明最多 2000 个字符；每份文档最多 80 个元件（含连接点）、200 条导线，服务端保存的电路文档不超过 256 KiB。

所有数值使用 SI 单位，可以输入科学计数法，例如 `1000` 表示 1 kΩ，`1e-6` 表示 1 µF，`10e-6` 表示 10 µm。元件参数须为有限数值，绝对值不超过 `1e15`；数值非常大或非常小时仍可能超出求解器的有效范围。

### 编辑导线形状

画布预览、落下的新拐点、元件和拐点移动均吸附到可见的 20 单位格点。选中导线后，可直接拖动线段调整位置，真实端点保持连接，必要时自动增加拐点；也可拖动圆点，点击线段中间的 `+` 或双击线段添加拐点。接到已有导线时，水平/竖直线沿线吸附，非格点引脚、旧角点及斜线仍保持精确接通。点击一个拐点后，使用“删除拐点”按钮或 Delete / Backspace 删除它。方向键移动一格，Shift + 方向键移动五格，Escape 取消本次线段或拐点拖动。

删除最后一个拐点后，导线成为两端之间的直线。“恢复自动走线”会重新按默认方式布线。移动元件时导线端点继续跟随引脚，拐点位置独立保留。改形状不会改变连接关系或测量结果，导线交叉仍不代表连接。每条导线最多 32 个拐点，保存电路、保存示例、导入导出和固定版本引用都会保留形状。

### 管理员维护示例

示例列表由服务器统一保存。在元件面板下展开“管理示例”，管理员可以：

- **新增**：在画布准备好电路，填写电路名称和实验说明，点击“当前电路添加为示例”。
- **修改**：选择并载入示例，修改名称、说明、元件参数、接线、导线形状或分析设置，然后点击“保存示例修改”。面板会显示正在修改的示例名称和版本。
- **删除**：选择示例，点击“删除所选示例”，核对名称后确认。

普通同学可以载入示例、修改并另存为自己的电路。示例的修改或删除不会改变已经另存的电路及引用；初始的三个示例也可以修改或删除，服务重启不会恢复已删除示例或覆盖修改。若两个管理员同时修改同一个示例，后保存的一方会收到版本冲突提示，当前画布草稿保留。

## 元件、引脚和参数

下表中的参数名也用于 JSON 文档和参数扫描。

| 元件                             | 引脚顺序                       | 可调参数与说明                                                                                              |
| -------------------------------- | ------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| 电阻                             | 正、负                         | `resistance`，Ω，必须大于 0                                                                                 |
| 电容                             | 正、负                         | `capacitance`，F，必须大于 0                                                                                |
| 电感                             | 正、负                         | `inductance`，H，必须大于 0                                                                                 |
| 独立电压源、独立电流源           | 正、负                         | `dc`、`waveform`、`amplitude`、`frequency`、`phase`、`delay`、`duty`、`acAmplitude`；电压单位 V，电流单位 A |
| 压控电压源 VCVS、压控电流源 VCCS | 输出正、输出负、控制正、控制负 | `gain`；分别为电压增益和跨导 A/V                                                                            |
| 流控电压源 CCVS、流控电流源 CCCS | 输出正、输出负                 | `gain`、`control`；`control` 选择电压源或电流表的元件 ID，增益分别为跨阻 V/A 和电流增益                     |
| 二极管                           | 阳极、阴极                     | `is`、`n`、`thermalVoltage`，均必须大于 0；采用 Shockley 关系                                               |
| BJT                              | 集电极 C、基极 B、发射极 E     | `polarity` 为 `npn` 或 `pnp`；`beta`、`betaReverse`、`is`、`thermalVoltage` 均必须大于 0                    |
| MOS                              | 漏极 D、栅极 G、源极 S         | `polarity` 为 `n` 或 `p`；`kp`、`w`、`l` 必须大于 0，`lambda` 不能小于 0；另有阈值 `vto`                    |
| 运放                             | 正输入、负输入、输出           | `gain` 必须大于 0；`railNegative` 小于 `railPositive`，输出相对于参考地并受这两个电压限制                   |
| 自定义伏安元件                   | 正、负                         | `expression`、`k`；表达式定义从正端流向负端的电流                                                           |
| 电压表、示波器                   | 正、负                         | 理想高输入阻抗，测量两个引脚之间的电压；并联到被测节点                                                      |
| 双通道示波器 `oscilloscope2`     | CH1 正、CH1 负、CH2 正、CH2 负 | 两个独立差分电压通道，理想高输入阻抗；在结果中切换 X–T / X–Y                                                |
| 二端口网络 `twoport`             | P1 正、P1 负、P2 正、P2 负     | `parameterSet` 为 Z/Y/H/G/ABCD；矩阵实部 `m11`–`m22`、虚部 `i11`–`i22`                                      |
| 电流表                           | 正、负                         | 理想零压降，串入支路测量从正端流向负端的电流                                                                |
| 参考地                           | 地                             | 零电位节点，无参数                                                                                          |

MOS 的 `w` 和 `l` 单位均为米，电流随 W/L 比例变化。PMOS 的 `vto` 使用阈值电压的**幅值**：填写 `1` 或 `-1` 都按 1 V 的阈值幅值处理。NMOS 保留 `vto` 的符号。当前 MOS 模型不包含体二极管、体效应或独立体端。符号中的极性箭头位于源极支路，镜像和旋转不改变 D/G/S 引脚身份。

电压和电流读数以引脚标注为准。电源对外供电时，按“流入正端”为正的电流约定，其电流可能为负。晶体管的电压通道取首末引脚之间的电压，即 BJT 的 VCE 和 MOS 的 VDS；电流通道取集电极或漏极电流。

### 二端口矩阵

每个端口的电压均按“正端减负端”测量，I1、I2 均以流入各自正端为正；两个负端不在元件内部短接，可以分别连接到外部参考节点。矩阵采用以下定义：

| 参数类型 | 定义                        | 矩阵元素单位，按 11、12、21、22 排列 |
| -------- | --------------------------- | ------------------------------------ |
| Z        | `[V1,V2] = Z · [I1,I2]`     | Ω、Ω、Ω、Ω                           |
| Y        | `[I1,I2] = Y · [V1,V2]`     | S、S、S、S                           |
| H        | `[V1,I2] = H · [I1,V2]`     | Ω、无量纲、无量纲、S                 |
| G        | `[I1,V2] = G · [V1,I2]`     | S、无量纲、无量纲、Ω                 |
| ABCD     | `[V1,I1] = ABCD · [V2,-I2]` | 无量纲、Ω、S、无量纲                 |

这里方括号表示列向量。ABCD 的第二个输入为 **−I2**，因此接负载时第二端口电流通常为负。定义参考 [Analog Devices 二端口实验](https://wiki.analog.com/university/courses/alm1k/circuits1/alm-cir-two-port-network)和 [Berkeley EE142 二端口讲义](https://rfic.eecs.berkeley.edu/courses/ee142/pdf/module8_twoports.pdf)。

`m11`、`m12`、`m21`、`m22` 分别填写矩阵四个元素的实部；`i11`、`i12`、`i21`、`i22` 填写相应虚部，默认为 0。例如 `m12=100`、`i12=50` 表示矩阵第 1 行第 2 列为 `100+j50`，单位由参数类型决定。新元件默认 Z 矩阵为对角线各 1000 Ω、其余元素为 0。切换参数类型后需要重新填写对应矩阵，编辑器不自动换算数值。

实数矩阵表示无记忆线性关系，支持 DC、瞬态、参数扫描和 AC。复数矩阵表示**不随扫描频率变化的相量关系**，仅支持其他元件均为线性器件的 AC 电路；不定义直流等效，因此这类结果不显示直流仪表读数。若与二极管、晶体管、非线性元件或限幅运放组合，会提示无法建立直流偏置。要模拟随频率变化的电容、电感等物理网络，请使用相应元件构建，不能用一个固定复数矩阵代表其全部频响。

求解器直接加入所选矩阵的两条约束方程，不要求先求逆；例如奇异 Y 矩阵表示的串联阻抗，以及 ABCD 单位矩阵表示的理想直通都可以使用。整个外部电路仍须有确定解。

### 电源波形

- `dc`：恒定值，也是工作点和交流线性化使用的直流偏置。
- `sine`：偏置加正弦波，`amplitude` 为峰值幅度。
- `pulse`：在 `dc` 与 `dc + amplitude` 两个电平之间切换。

`frequency` 使用 Hz，`phase` 使用度，`delay` 使用秒。延迟结束前输出为 `dc`；正弦和脉冲频率必须大于 0，脉冲占空比满足 `0 < duty < 1`。交流小信号分析另外使用 `acAmplitude` 和 `phase`，不会把瞬态波形的峰值自动当作 AC 激励。

正弦不需要占空比，编辑器仅在脉冲模式显示 `duty`。源参数标明峰值、偏置及 V/A 单位，画布区分直流、正弦和脉冲。设置周期波形后应选“瞬态响应”；DC 与参数扫描只计算直流工作点。

## 四种分析

| 分析          | 设置                                         | 结果与用途                                                                                          |
| ------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 直流工作点 DC | 无扫描区间                                   | 计算固定直流偏置下的节点电压和支路电流；电容为直流开路，电感为直流短路                              |
| 瞬态响应      | 截止时间、时间步长、初始状态                 | 计算随时间变化的电压和电流，可播放动态图或拖动时间游标                                              |
| 参数扫描      | 元件、数值参数、起点、终点、采样点数         | 在每个参数值下重新计算直流工作点，例如扫描电压源 `dc`、BJT `beta`、MOS `w` / `l` 或自定义特性的 `k` |
| 交流小信号 AC | 起始频率、截止频率、采样点数、对数或线性间隔 | 在直流工作点附近线性化，显示峰值幅度和相位；可用于 RC/RLC 频响和放大器小信号分析                    |

瞬态时间和步长必须大于 0，步长不能超过截止时间；包含初始点在内最多 100001 点。初始状态可以选择“零初始储能”，对应电容初始电压与电感初始电流为零，或选择“直流工作点”作为初始状态。瞬态采用后向欧拉法，大步长会带来数值阻尼；建议每个周期至少取 100 点，并用减半步长比较结果。

页面会提示周期源的采样不足，并提供一键调整。以 10 kHz 正弦为例，时间步长 0.0001 s 恰好等于一个周期，可能只采到零点；改为 0.000001 s，保留 0.1 s 截止时间，共 100001 点，可观察 1000 个周期。

参数扫描和 AC 扫描均为 2–2000 点。参数扫描起点和终点必须不同，并满足该参数本身的范围要求；允许正向或反向扫描。参数扫描逐点求直流工作点，因此只有参与直流方程的参数才会影响结果。要观察频率响应，应使用 AC 分析。AC 频率满足 `0 < 起点 < 终点`，结果幅值为峰值而非 RMS。

选择电压、电流等测量通道后，波形按单位分图；AC 分析可以同时显示相位。长波形绘制按屏幕宽度保留峰谷，CSV 导出和游标读数仍使用全部采样数据。鼠标移动到曲线或在手机上触摸曲线，可以查看附近采样值。动态图的颜色来自真实节点电压，流动方向来自元件电流正负，回放速度经过缩放；高频波形自动慢放，避免跳帧后看似不动。动态图引用只在瞬态多帧结果下播放；其他分析显示静态工作点，并可展开波形。

求解在浏览器 Web Worker 中执行，可以取消；超过 20 秒会停止。计算量还受电路规模和采样点数共同限制。未收敛、浮空、非法公式或数值溢出会显示错误，不会用零曲线代替失败结果。

## 双通道示波器与波形数学运算

运行仿真后，在图像设置里指定 CH1 和 CH2。可选任一实际电压、电流通道；双通道示波器的两个差分探头会分别产生 CH1、CH2 电压读数。原有两引脚示波器仍按单通道工作，旧电路无需改线。

- **X–T**：各曲线随时间或扫描量变化；DC 显示工作点，参数扫描横轴为所扫描的参数，AC 横轴为频率。
- **X–Y**：选择一条曲线为 X、另一条为 Y，按相同采样时刻连接，可显示李萨如图或电压–电流关系，也能把数学曲线指定为坐标轴。要观察实际随时间形成的轨迹，应使用瞬态分析。AC 的 X–Y 使用各频率点的相量幅值关系，不把频率扫描转换成时域波形。
- **坐标范围**：分别填写 X/Y 下限和上限，留空自动缩放；下限必须小于上限。X–T 中纵轴范围作用于各单位分图。

展开“数学运算”，可添加最多 8 条曲线 M1–M8。公式使用所选 CH1、CH2 或列表中前面的 M 通道，例如 `CH1-CH2`、`CH1/CH2`、`abs(CH1)`、`M1*CH2`。名称最多 40 字符，公式最多 160 字符，单位可留空自动推导，或填写最多 12 字符的自定义标注。

支持 `+ - * / ^`、括号、一元正负号、常数 `pi` / `e`，以及 `abs`、`sqrt`、`sin`、`cos`、`exp`、`log` / `ln`、`min`、`max`、`pow`；三角函数使用弧度，`log` 为自然对数。瞬态还支持 `diff(CH1)` / `derivative(CH1)` 和 `integral(CH1)`：导数按采样时间数值计算，积分按梯形法从第一个采样点累积，初值为 0。采样密度会影响微分和积分精度。

AC 运算先结合幅值与相位恢复复数相量，再计算结果的幅值和相位，例如 `CH2/CH1` 可表示复数传递比。AC 不支持 `min` / `max` 和时间微积分。表达式由受限数学解析器处理，不执行 JavaScript。除零、缺失通道或计算溢出会显示提示；无效采样在图上断开，在 CSV 中留空，不替换成零。

图像设置不会改变电路求解方程，无需为了切换模式或公式重新仿真；修改电路元件、接线或分析设置后仍需重新运行。

## 波形标记与注释

运行仿真后，点击“在波形上添加标记”或“在图上选点”，再点击或轻触曲线。编辑器会选取当前图中距离最近的有效采样点；拖动、滑动和取消选点不会新增标记。也可以点击“按坐标添加”，选择曲线、标记样式，填写采样坐标和注释。注释可留空，每条最多 160 字符，每份电路最多 32 个标记。

标记样式支持“点”“竖线”“横线”。图内只显示小圆点或细虚线，完整注释、编号和实际坐标统一放在对应图像下方的图例中，避免文字挡住曲线。竖线取采样点的横坐标，横线取该点的真实纵坐标；旧标记默认显示为点。点击图中的标记、图例或下方编辑列表，可以修改样式、注释、曲线和采样位置；“删除”移除对应标记。修改会写入当前草稿，点击电路的“保存”后才会生成可分享的版本。只读引用显示相同的图例，复制为新电路后才能修改。

标记的位置绑定**原始仿真采样坐标**：瞬态为秒，AC 为 Hz，参数扫描为被扫描参数的 SI 数值，DC 为 0。X–Y 模式也使用这一坐标选择同一采样时刻的横纵轴数值，不能把横轴电压直接填作时间。AC 开启相位图后，可以分别给幅值和相位添加标记；数学曲线也可标记。

调整步长或采样点数后，标记会在同一坐标附近重新吸附到实际采样点。切换 X–T / X–Y、改变 X–Y 的坐标曲线、隐藏通道、关闭相位图、改变分析类型或扫描目标，以及标记坐标超出当前范围时，相关标记暂时隐藏，列表会说明原因；竖线只要求横坐标可见，横线只要求纵坐标可见。恢复原设置后可以再次显示。公式除零等无效数据不会产生虚假的标记值。修改电路或数学公式后，标记仍按原坐标读取新的结果，不会自动重新查找峰值；请同时检查注释是否仍符合新的波形。

## 在电路编辑器中请 Max 调整图像

在右侧选择 **Max** 标签，默认的“自主执行”模式会读取当前电路、执行操作，再根据真实结果继续下一步。可以一次交代完整实验目标，例如“运行瞬态仿真，计算两通道差值，切换 X–Y，再在差值的采样峰值处添加注释”。也可以分别要求：

- “把 CH1 设为 S1 的第一通道、CH2 设为第二通道，增加 `CH1-CH2`，名称为差值，单位为 V。”
- “切换到 X–Y，横轴用 CH1，纵轴用刚才的差值曲线；坐标范围自动。”
- “切回 X–T，同时显示两个通道和差值曲线。”
- “标记差值曲线的采样最大值，并注释为输出峰值。”
- “在 1 ms 的输出电压上添加标记，注释为开始衰减。”
- “在失效开始的采样位置画一条竖线，把说明放在图例中。”
- “把 A1 改成横线，标出该采样点的电压。”
- “把 A1 的注释改为稳态起点，删除 A2。”

自主执行会显示每一步的操作和结果，不需要逐次点击应用。遇到参数或求解错误时，Max 会收到错误信息并尝试修正；修改参数后会等待新的仿真结果，再进行图像计算和标记。点击“停止执行”可中止后续操作；收起侧栏后仍有状态条和停止按钮。“撤销 AI 修改”恢复本轮开始前的草稿和图像。切换为“仅给建议”时，仍由你点击“应用到草稿”。需要保存电路才能分享新版本。

每轮最多 12 次决策、10 分钟；连续失败或重复无效操作时会结束并说明原因。执行过程中手动修改电路、切换电路或登录状态后，Max 会停止使用旧快照继续操作。未完成时可根据已保留的草稿继续提问。

Max 获得的是有限的采样摘要及从完整采样计算的极值坐标，所标注的是**采样极值**，不保证是连续曲线的解析极值。自主执行会先获得有效仿真结果再标记；旧结果上的标记建议不能直接套用到新结果。讨论区或普通聊天中的电路链接可以让 Max 读取已保存的设置和注释；对当前草稿执行这些操作，需要在电路编辑器的 Max 标签中进行。

## 自定义伏安特性

例如添加自定义伏安元件，输入：

```text
i=k*u^3
```

这里 `u` 为元件正负端电压，`i` 为从正端流向负端的电流；`k` 是元件面板中的可调系数。把该元件接到电压源两端，连接参考地，再扫描电压源的 `dc`，即可查看 I–V 曲线；也可以扫描 `k` 比较特性。

表达式支持：

- 运算符：`+`、`-`、`*`、`/`、`^` 和括号，支持一元正负号；`^` 表示乘方。
- 变量与常数：`u`、`k`、`pi`、`e`。可以省略开头的 `i=`。
- 单参数函数：`abs`、`sqrt`、`exp`、`log`、`ln`、`sin`、`cos`、`tan`、`tanh`；`log` 与 `ln` 都是自然对数，三角函数使用弧度。
- 双参数函数：`min(a,b)`、`max(a,b)`、`pow(a,b)`。

例如 `i=k*tanh(u)` 或 `i=k*(exp(u/0.026)-1)`。每个公式最多 256 个字符、128 个词法符号，表达式括号等嵌套最多 24 层。表达式由专用数学解析器处理，不执行 JavaScript，也不支持对象访问、任意函数、循环或条件表达式。请让公式在实际求解电压及其附近都有定义；除零、对负数取实数平方根、溢出和不光滑特性都可能导致求解失败。

## CID、权限与引用

保存的电路默认按 CID **公开可读**；任何获得链接的人都能查看，包括未登录访客。个人列表只列出自己的电路。作者和管理员可以保存新版本，其他同学可选择“复制为新电路”，修改后保存为自己名下的新 CID。复制不会覆盖原作者的电路。

每次保存保留一份独立版本快照。若另一个标签页已经保存新版本，旧版本继续保存会提示冲突并保留当前草稿；可以先导出 JSON 或复制为新电路，再重新打开最新版本比较修改。账户注销后仍保留既有公开电路与引用，作者显示为“已注销用户”。

使用页面中的“复制动态图引用”“复制波形引用”或“复制原理图引用”，把生成的 Markdown 粘贴到讨论帖子、评论或课程知识点的 Markdown 正文中。首次保存前因为没有 CID，复制按钮不可用，并会显示原因。电路或图像设置存在未保存修改时，也需要先保存，才能复制引用；这样分享的固定版本会包含刚刚选择的曲线、模式、运算公式及标记注释。例如：

```markdown
[电路动态图](/circuit?cid=c_0123456789abcdef01234567&revision=1&view=live)
[电路波形](/circuit?cid=c_0123456789abcdef01234567&revision=1&view=waveform)
[电路原理图](/circuit?cid=c_0123456789abcdef01234567&revision=1&view=schematic)
```

示例 CID 需要替换为实际保存得到的 CID。阅读时链接会显示为可操作的嵌入内容，仍有“打开电路”入口。引用必须包含合法 CID、正整数版本号和三种展示方式之一；普通电路链接保持为链接，代码块中的文字也不会转换成嵌入。

固定版本保存元件、接线、参数、分析设置，以及图像的通道选择、数学公式、X–T / X–Y 模式、相位开关、坐标范围及标记注释；后续保存新版本不会改变旧引用。嵌入图会恢复分享时的图像配置，访客临时切换显示不会修改原版本。动态图和波形引用在打开时重新计算；需要保留某次计算的数值结果时，可以导出 CSV。浏览器设置减少动态效果时，嵌入的瞬态回放默认暂停。

### 发表到讨论区

保存电路后，点击顶部“发表到讨论区”。讨论区会打开现有发帖编辑器，默认选择“电路”分区，标题为“看看我的神秘电路！”，正文包含刚保存版本的动态图引用。分区、标题和正文都能修改，最后点击发布才会创建帖子。当前电路存在未保存修改时，需要先保存，再使用发表按钮。

电路发帖草稿会暂存在当前浏览器标签页，刷新或完成登录后可以继续编辑。切换账号不会把上一账号的草稿交给新账号；发布成功后清除这份草稿及 URL 中的发帖意图，刷新不会再次预填发布。

## JSON 与 CSV

- **导出 JSON**：保存当前电路文档以及标题、说明，适合备份、交换和后续编辑。
- **导入 JSON**：接受电路文档本身，或包含 `document` 的导出文件，文件不超过 1 MB。导入会替换当前草稿的电路内容；存在未保存修改时会要求确认。文件中的 CID 不会取得原电路所有权，最终保存仍遵循当前页面的作者权限和版本校验。
- **导出 CSV**：运行成功后导出横轴、全部电压电流通道及当前配置中成功计算的数学曲线；AC 结果包含相位列，可用电子表格或其他绘图工具继续分析。

电路文档仍采用 `version: 1`，可选 `display` 字段保存图像配置，旧文档缺少该字段时自动选择默认通道。例如：

```json
{
  "version": 1,
  "mode": "xy",
  "traceIds": ["V:S1", "V:S1:CH2", "M:M1"],
  "ch1": "V:S1",
  "ch2": "V:S1:CH2",
  "xyX": "V:S1",
  "xyY": "M:M1",
  "math": [{ "id": "M1", "label": "差值", "expression": "CH1-CH2", "unit": "V" }],
  "phase": false,
  "ranges": { "xMin": null, "xMax": null, "yMin": null, "yMax": null },
  "annotations": [
    {
      "id": "A1",
      "traceId": "M:M1",
      "at": 0.001,
      "text": "开始衰减",
      "marker": "vertical",
      "mode": "xy",
      "axis": "value",
      "xTraceId": "V:S1",
      "analysisKey": "transient"
    }
  ]
}
```

以上对象放在电路文档的 `display` 中。实际曲线 ID 为 `V:元件ID` / `I:元件ID`；双通道示波器第二通道为 `V:元件ID:CH2`，二端口第二端口为 `V:元件ID:P2` / `I:元件ID:P2`，数学曲线为 `M:M1` 至 `M:M8`。CH1、CH2 选择物理曲线，XY 坐标轴可选择物理或数学曲线。`annotations` 可省略，旧文档不会自动新增标记。标记的可选 `marker` 为 `point`、`vertical` 或 `horizontal`，省略时按点显示且不改写旧文档。`at` 是原始采样坐标，`axis` 为 `value` 或 `phase`；X–T 的 `xTraceId` 为 `null`。`analysisKey` 为 `dc`、`transient`、`ac`，或 `sweep:元件ID:参数名`。JSON 保留这些标记配置，CSV 仅导出采样数值，不包含注释文字。

导入上限与云端保存上限不同：即使 JSON 文件能导入，实际电路文档仍须满足服务端 256 KiB、80 元件和 200 导线限制。

## 模型范围

本实现采用修改节点分析法、非线性迭代、二极管 Shockley 模型、BJT Ebers–Moll 模型、MOS 长沟道平方律，以及有限增益和电源限幅的运放。它面向课程实验、概念验证和参数比较。

当前模型不包含晶体管寄生电容、器件击穿、温度漂移或完整工艺参数。MOS 没有体二极管与体效应；运放没有完整的频率补偿、压摆率、输入偏置或噪声模型。AC 是工作点附近的小信号线性化，不能代表大信号削顶后的频谱。本实现不是工业 SPICE 仿真器，结果应结合课程模型假设与解析计算判断。
