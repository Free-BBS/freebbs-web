# 2026-09-27 页面壳、牧场与工具切换补丁

基于 main 301112f（已包含 PR #140、#150、#151），保留新版羊群广场、染坊和既有经济规则

## 修改

- 统一桌面导航不再依赖 main-content 类名，修复电路闯关、发布讨论漏接顶栏；补齐发布、图谱编辑、知识点编辑、羊群广场、染坊标题及 publish.html 重定向
- 知识点阅读和课程图谱编辑通过显式 immersive 标记保持原有全屏体验，手机导航结构不重排
- 牧场和羊群广场顶栏背景横向铺满，羊群页标题避让实际顶栏高度
- 牧场先应用场景偏好、显示真实风景加载占位，再请求账号数据；不缓存账号、余额或羊的状态
- 修复牧场学习背景按钮及夜间操作按钮的颜色覆盖冲突；学习背景模式隐藏新顶栏，退出后恢复
- 商城购买成功、失败等消息使用主题文字颜色，不再继承旧主题的浅色文字
- 小工具每次打开/重载使用独立 iframe，关闭释放旧实例，忽略旧 load/close 事件；增加加载状态及重载入口，保留 opaque sandbox 和原 CSP
- 外部 Google Fonts 样式异步加载，慢速/不可达时使用已有系统字体回退，使用 display=optional 减少迟到字体替换
- 模拟预览明确不连接独立发展端，避免模拟空响应被当作已授权而反复跳转

## 验证

- 302 项相关单元/回归测试通过，含导引、字体、页面壳、牧场规则、工具隔离、预览、静态响应
- 最后补查的页面壳、钱包 UI、工具和静态响应 65 项通过（与上项有重叠，不累加）
- 全站 HTML 页面壳浏览器巡检；管理员入口使用普通模拟账号，只验证其权限跳转，不声称已验证真实管理员业务
- 1440 / 901 / 390 / 320 宽度，明暗模式、大字号：闯关、发布、工具、羊群、个人牧场和商城消息
- 购买成功及模拟余额不足的消息文字对比度均不低于 4.5:1；夜间学习/暂停按钮同样达标
- 20 次同一任务内快速开关后打开第二个工具，再重载及 Escape 退出，无未捕获异常
- 牧场 24 组布局/弹窗组合；染坊、羊群、学习背景 6 组兼容检查；染色后喂养/剪毛/摩擦及奖励规则保持不变
- CPU 4 倍降速：问问 Max、设置、实验室首屏主题/字号正确，CLS 小于 0.1
- 外部字体 CSS 模拟延迟 1800ms：旧路径首屏约 1856–1884ms，异步路径约 28–40ms；不可达也正常显示
- 改动 JS 无 ESLint error；相关文件通过格式检查

这些时间来自受控本地测试，只证明字体等待不再阻塞首屏，不代表线上整站加载时间或提速倍数

## 边界

小工具简单样例未复现用户报告的特定白屏，本次针对实例复用和异步切换做隔离修复并通过快速切换回归
若某个已发布工具自身有脚本错误或依赖被沙盒禁止的外部资源，仍需提供具体工具名称/链接复现，不能放宽沙盒权限来绕过
测试只使用本地内存模拟账号；未操作线上账户、余额、数据库，未部署或合并
