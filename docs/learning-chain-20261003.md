# FREE BBS：让同一套知识材料支持不同的学习

学习链设计、实现与验收说明 · 2026年10月3日 · 本地预览版

## 1. 核心结论：完整的是支持系统，不是必走的流程

正文只需要一套。概览、知识起源、正文、题目、知识关系共同构成课程组审核的公共知识层；个人批注是附着在同一正文上的私有层。不同起点和目的改变的是入口、题目选择、指导密度与下一步顺序，不要求课程组为每种组合再写一份正文。

稳定的基准通道保留：了解概览与起源 → 阅读正文并标注 → 分层练习 → 正式自测 → 根据反馈补学、订正 → 继续下一点或探索。它适合系统学习，但不设为所有人的门禁。熟悉者可以从题目开始；查阅者可以找到所需条件后结束；研究者可以从关系、边界或探索问题切入。

| 保持一致                         | 允许变化                         |
| -------------------------------- | -------------------------------- |
| 审核后的正文、来源和版本         | 本次入口、顺序、提示量和阅读范围 |
| 正式题目范围、判分规则、授星证据 | 练习难度、探索方向、是否进行自测 |
| 私人记录的账号归属与访问权限     | 调整自报起点、改目标、跳过推荐   |

“看正文 - 做题 - 拿星”是一条可靠的支持路线，不是价值排序。没有星不等于不会，也不等于使用无效；勾选路径完成不等于通过自测。

本轮已落实：四档起点、三项目的和十二套初始策略；一份正文上的私人批注；分层题卡与用途分离；简短而可编辑的下一步；共享受控学习状态的右侧 Max；个人证据与管理员描述性分析；五步可重复新手导引；与网页兼容的课程组 V4.2 模板。未提交 PR、未部署、未修改真实学生数据。语音仅提出方案，未接入。

## 2. 为什么这样设计：研究支持原则，不直接证明我们的矩阵

纵向看，掌握学习关注目标、反馈和纠正；之后的先验知识、提取练习与自我调节研究，要求把指导量、时间和任务条件纳入考虑。横向看，学习产品通常区分练习表现、诊断或起点、完成记录与正式结果。我们取其可解释结构，不照搬 K12 分数或等级制度。

| 原始研究                                                    | 可以支持的取舍                                       | 不应外推的结论                                                 |
| ----------------------------------------------------------- | ---------------------------------------------------- | -------------------------------------------------------------- |
| Reisslein 等，2006；185名大学工程入门学生，电路分析实验 [1] | 新手宜先看例子和解释；有经验者宜允许先尝试、按需查例 | 不能证明四档自报就是可靠能力分类；不能保证同样效果覆盖所有课程 |
| Hattie 与 Timperley，2007；反馈研究综述 [2]                 | 反馈应说明目标、当前表现和下一步，而非只给赞扬或分数 | 不能据此宣称任意 AI 回答都有效                                 |
| Roediger 与 Karpicke，2006；大学生短文学习实验 [3]          | 提取与稍后复查值得保留；立即会做与延迟记得应区分     | 不直接证明复杂推导或工程迁移；同题订正不是长期保持             |
| Pan 与 Rickard，2018；122项实验的迁移元分析 [4]             | 新情境任务应独立设计和测量，不能用原题通过代替迁移   | 不保证任何提取活动都会产生远迁移                               |
| Ryan 与 Deci，2020；教育动机综述 [5]                        | 给清晰结构，同时保留自主选择、调整和退出             | 自主不等于取消支持，也不等于增加越多选项越好                   |

这些证据支持“先验知识影响支架、练习与反馈重要、用户需有控制、保持与迁移分开”，但不直接验证本平台的三个目的或十二组合。本轮矩阵是可解释、可修订的工程方案，不是经过本平台实验验证的诊断算法。

产品对照：Khan Academy 的技能等级依据规定的练习与评测证据；Brilliant 的起点检查与课程完成具有各自条件；Open edX 将内容完成与成绩分开 [6-8]。因此，本平台的自报、手工标记、活动记录、正式题表现和星标也必须各有来源，不能合成一个不透明的“掌握指数”。

调研为有边界的原始文献和官方产品资料核查，不是穷尽式系统综述；不报告自行合成的效应量。arXiv API 未取得结果，摘要页补查只作辅助线索；核心取舍以上述正式研究为主。

## 3. 少量选择：起点决定支架，目的决定这次想做什么

进入课程时必须确认一次起点；同一标签页、同一账号会话和课程内换知识点不重复拦截。上次选择可预填，随时能调整。四档均为学生自述，不是考试结论，更不是永久身份。

| 起点文案   | 初始支持                                                   | 未选目的时建议 |
| ---------- | ---------------------------------------------------------- | -------------- |
| 第一次学   | 解释必要术语，从直观例子和最基本原理展开，允许细致分步示范 | 理解知识       |
| 不甚熟悉   | 定位能解释与不确定的部分，针对卡点补学                     | 理解知识       |
| 能独立做题 | 减少重复示范，先独立尝试，再核对条件和理由                 | 练习解题       |
| 完整掌握   | 少提示，查边界、反例、替代方法与跨点联系                   | 探索研究       |

本次目的可选，只有三项：理解知识、练习解题、探索研究。复习不是第四种能力或目的，可通过订正、重做和回看支持；查阅也不另加一道问卷，正文、概览和关系始终可直接打开。

用户不选目的时系统使用建议顺序，但不把建议写成用户已选择的目的。起点也不限制可看的题目：第一次学仍可探索，完整掌握仍可回基础。

旧数据迁移尤其注意：旧版 advanced 的含义是“想深入”，不是新版“完整掌握”。旧确认票据失效并重新确认；不能把学习意愿偷偷改成掌握自述。其他旧档可预填，但仍需确认新的选择。

## 4. 十二组合：明确初始顺序，允许随任务改道

下表对应实际共享策略模块。箭头是初始建议，不是锁定流程；同一正文始终可见。题目按已有用途和教师估计难度选择，缺资料时明确回退，不编造题库、起源或关系。

| 起点       | 目的     | 初始学习顺序                                         | 适合思考的问题                   |
| ---------- | -------- | ---------------------------------------------------- | -------------------------------- |
| 第一次学   | 理解知识 | 直观例子与术语 → 用自己的话解释 → 基础题核对概念     | 我能举什么例子？必要条件是什么？ |
| 第一次学   | 练习解题 | 看一种基本做法 → 基础题独立尝试 → 记录仍需示范的步骤 | 第一步确认什么？每一步为何成立？ |
| 第一次学   | 探索研究 | 起源与问题背景 → 提出一个为什么 → 整理疑问交流       | 为什么引入它？继续探索需补什么？ |
| 不甚熟悉   | 理解知识 | 标出不确定处 → 回看定义与条件 → 题目核对疑点         | 混淆的是定义、条件还是结论？     |
| 不甚熟悉   | 练习解题 | 针对卡点查说明 → 基础题尝试与订正 → 写清薄弱步骤     | 错因是什么？能独立重新说明吗？   |
| 不甚熟悉   | 探索研究 | 查真实知识联系 → 写可能的联系 → 检视猜想前提         | 哪个联系只有直觉、还缺证据？     |
| 能独立做题 | 理解知识 | 先写自己的解释 → 核对必要条件与例外 → 对照关系       | 会用与理解为什么有什么差别？     |
| 能独立做题 | 练习解题 | 标准题独立作答 → 检查假设与论证 → 回看薄弱步骤       | 为什么选这个方法？漏了什么假设？ |
| 能独立做题 | 探索研究 | 查看可延伸联系 → 核对推导边界 → 讨论变式检验         | 改一个条件会怎样？如何检验？     |
| 完整掌握   | 理解知识 | 精确说明 → 边界与反例 → 反向核对关系                 | 自信的依据是什么？能给反例吗？   |
| 完整掌握   | 练习解题 | 挑战题少提示作答 → 复核严密性 → 交流替代方法         | 特殊情形覆盖了吗？他人能复核吗？ |
| 完整掌握   | 探索研究 | 关系与边界 → 形成可检验问题 → 交流已证实和待证实部分 | 假设、检验与限制分别是什么？     |

“继续学习”首屏只有一个主要建议和最多两个替代入口；完整顺序折叠保存，可重排、完成、跳过和修订。已有私人路径不被新推荐静默覆盖；同版本正式错题或待复核记录会参与下一步建议，但探索与直接自测仍开放。

缺对应难度时使用真实可用题目，不声称难度等价；没有正式题则不出现虚假正式自测；没有题目则退回解释、笔记或讨论。探索思考题只是引导问题，不自动判分或授星。

## 5. 同一正文与私人批注：不再维护第二个阅读空间

官方正文只渲染一次。选择文字后高亮、划线或写评注；“我的批注”在正文旁打开工具与折叠目录，并定位回原文。补充笔记、从 Max 主动保存的解释仍可保留，但不生成一份内容逐渐脱节的原文副本。

批注独立存储，按登录用户鉴权。读、改、删只允许本人；课程负责人和全站管理员的分析权限不自动包含私人批注正文。不同账号加载时先清空旧私有状态，再读取当前账号数据，迟到请求不回填旧记录。

锚点包含知识点、完整正文版本、块指纹、文本范围和上下文。正文改变后，仅在可靠匹配时重定位；存在歧义则保留为待定位，不把批注贴到相似句子。公式、表格和图片可以整块评注。个人操作不覆盖官方内容。

这套结构减少课程组维护负担，并保留完整学习通道中的主动解释与标注。它不声称“批注多就是学得好”；管理员只可看到授权后的使用动作计数，不能读取笔记内容推断思维水平。

## 6. 题目、判分和星标：适配练习，严格保持正式证据

| 题目字段                      | 当前契约                                                               |
| ----------------------------- | ---------------------------------------------------------------------- |
| difficulty                    | basic / standard / challenge；教师估计，不是统计校准难度或学生能力等级 |
| assessmentRole                | practice练习 / selftest正式自测 / exploration探索；用途与难度独立      |
| learningObjective             | 本题希望检查的目标，展示给学生                                         |
| explanation / misconceptions  | 解析与常见误区；评分扩展里的答案依据在作答后提供                       |
| source / reviewedBy / version | 出处、审核人和版本；未审核内容保持draft                                |

练习面板可选基础、标准、挑战及探索题。推荐题可采用合适的已有难度，但用户能改选全部题。正式自测不接受难度筛选缩小题目范围；即使初学者选基础练习，也不能只做基础题就当整个知识点自测已通过。

客观题由发布规则判断；主观题提交后待课程负责人复核，不被当作失败或通过。练习正确不能抹去正式错题，探索作答也不能冒充正式通过。订正看同题、同正文版本和同题目版本的正式记录。

自主学习星只采用当前发布的全部正式题目：每题最新正式记录均需匹配版本并已判通过。练习、自述、阅读时长、路径勾选、AI 临时题和赞扬不授星。核心/一般知识点保留三颗星，拓展点保留二颗；深入掌握等未完成机制保持灰色。已得星保留历史来源，内容更新不伪装成当前已通过；本轮不增加货币奖励。

评分扩展沿用schemaVersion 1和旧上传方式。旧发布题默认正式自测，旧草稿为练习；旧题未填难度保持未知，不偷偷贴基础标签。新字段需先部署兼容解析器，再上传。模板展示的是本地draft样例，不是正式课程组已审核材料。

形成性自测不是监考考试。正文可能有示例及折叠解答，不应承诺防作弊或把重复通过直接当课程成绩；未来若做高风险考核，需要独立题库、暴露规则、量规与效度验证。

## 7. Max 是辅助老师：共享上下文，不代替课程与评测

不增加另一套聊天。右侧 Max 获取同一课程和知识点、学生确认的起点与目的、当前主动打开的任务，以及本人当前版本的近期正式题证据。基础支持需要术语、原理、示范和原因解释，不应只反问；有经验者可减少重复、比较条件、反例与联系。

服务器重新读取真实课程稿、题目和本人的测评记录，不信任浏览器伪造的正文、通过数或他人身份。评分扩展及隐藏答案不直接作为聊天上下文；私人批注不自动送给 Max。学生可在消息中主动提供自己的疑问或片段。

近期证据最多读取51条，明确是局部视图，缺记录表示未知；待复核不是失败。这防止为了让 Max“更懂用户”而把局部数据包装成全面能力画像。推荐策略与 Max 提示使用同一模块，不维护两套相互矛盾的起点逻辑。

Max 的回答应区分审核结论、条件与推测；资料不足时说明不确定。它可以辅助解释和检视思路，不能改变题目判分、授星或发表私人内容。推荐和打开聊天不自动发送请求；用户自己触发交流。

语音建议分阶段：第一阶段采用主动按住或点击录音 → 转文字供确认 → 复用现有 Max → 可选朗读，同时始终保留文字和公式。第二阶段才评估可打断的实时语音。先验证数学符号、中文术语和延迟，不默认持续监听、不默认保存录音，不让转写结果直接提交正式答案。模型供应商、费用、保留期限和校内合规需另行确认。本轮没有录音按钮或语音模型上线，架构参考官方语音代理说明 [9]。

## 8. 看得见结果，也看得见未知：个人与管理端各有边界

| 信息                         | 本人                         | 管理端                                 | 解释边界                             |
| ---------------------------- | ---------------------------- | -------------------------------------- | ------------------------------------ |
| 自报起点、目的与修正         | 查看并调整                   | 开启采集后的受控聚合                   | 自述不是能力诊断；没选目的保持未知   |
| 私人批注、私人路径           | 阅读、编辑和保存             | 不读取私人正文                         | 动作次数不表示质量                   |
| 正式作答、练习、订正、待复核 | 真实业务记录与个人证据卡     | 聚合计数；课程负责人处理授权待复核作答 | 次数含重复，不等于题目全集通过       |
| 探索选择 / 探索作答          | 分别显示                     | 分别计数                               | 点击入口不是参与证据，更不是研究成果 |
| 前台活跃时长估计、工具动作   | 自愿开启后可查看、导出、删除 | 授权后的描述统计                       | 不是真实净学习时间，不排名           |
| 延迟保持、新情境迁移         | 显示尚未采集                 | 显示尚未采集                           | 不凭立即订正生成长期掌握结论         |

细粒度过程采集默认关闭，关闭不影响笔记、必要测评记录和授星。过程记录只含受控类型与枚举，不含笔记、聊天、答案正文或自由文本；支持导出、删除并暂停采集，保留期180天。

管理分组单位是“学生 × 课程 × 知识点”，另显示独立人数，不能混成同一分母。分组只使用窗口内第一次明确选择之后的真实行为；目的空缺、版本未知、选择前记录和同一时刻无法确定先后均单列。正式作答与练习、探索分开；人工复核的处理时间不冒充学生提交时间。小样本只陈列计数，不作群体结论。

“这个新范式是否帮助学习”尚不能只靠活跃和星数回答。下一步应在自愿、明确授权的试点中，用同知识点可比前测、未暴露的平行后测、例如一周后的延迟检查和新情境题，记录外部学习与退出情况；比较完整基准支持与现有使用方式，分层或随机安排须事先确定，报告效应及不确定性。保持相同评分蓝图，避免把练习过的原题当独立后测。

当前同题、同版本“首次未通过后再次通过”只是订正变化证据，不能单独归因于平台或 Max。不应把不做题的科研用户记为学习失败，也不能因关闭记录而降低服务或评价。

## 9. 课程组提交与新手导引：一份包即可支撑整条链

V4.2 提交包保留三个分区：基本信息、知识背景与应用、知识点正文。每知识点一份完整 Markdown，整理工具拆成网页现有接口所需字段；不为十二组合另写十二份讲义。

| 课程组准备                                     | 网页用途                                   |
| ---------------------------------------------- | ------------------------------------------ |
| 真实章名、知识点编号、层级、署名、简短概览     | 0级章节与知识概览；参与同学统一展示        |
| 起源：为什么需要这个知识、问题背景与条件       | 正文前可收起的吸顶起源区；缺资料不编造史实 |
| 一套正文、示例与可靠来源                       | 所有用户共享；批注按用户私有叠加           |
| 分层练习、正式自测及探索任务；解析、误区与审核 | 题卡、自测、订正及 Max 有依据的辅助解释    |
| 每章0级稿、已确认坐标、已复核关系              | 章网络和选中知识点的直接关系；含跨章实例   |

正式达标题目不必把每个目的都变成考试。课程组先明确知识点目标与正式题全集，再补不同难度练习与一个有依据的探索入口；不要为填满字段赶制未经复核的内容。多套等价自测、自动探究评估和新的深入掌握判据尚未实现。

包内有README、课程组编写指南、模板、两章三点和跨章关系样例，以及三个无需联网的Node检查工具。编写指南区分概览、起源与正文，给出最低可交付清单、难度估计、题目用途、解析误区、审核责任和回读步骤；不要求凑齐题数或编写十二份教材。所有样例是draft，本地检查须显式允许演示；格式通过不能代替教学审核。发布人员按现有权限上传并回读；不含密码、学生数据或自动批量覆盖。

页面“学习指南”可重复打开，五步分别是：看概览与起源；在正文上批注；练习与自测分开；调整继续学习；需要时打开 Max 和个人记录。引导可关闭，不自动开启采集、不修改起点、不发 AI 消息、不改变星级。

独立新手说明见同目录 learning-guide-20261003.md。它既介绍完整路线，也说明直接查阅、从题目开始和探索的用法，不要求熟悉者重走全部流程。

## 10. 预览、验收与发布边界

## 11. 授星方案：记录真实经历，不把奖励变成门禁

建议保留V1.0的三类知识点星与课程星，不把自报起点直接换成星级，也不以星数决定谁能阅读、探索或咨询Max。游戏化元分析发现结果受情境与设计影响，部分动机和行为结论在高质量子样本中不稳定；它并不能证明本平台三颗星或星标单独有效 [10]。因此，星标应是可追溯的反馈，不是外在压力或能力排名。

| 记录                      | 判据及含义                                                     | 本轮状态                                 |
| ------------------------- | -------------------------------------------------------------- | ---------------------------------------- |
| 知识点：课程学习          | 核实通过该课程，记录课程经历；不声称逐点掌握，导入课表不算通过 | 未接入成绩证明，灰显尚未开放             |
| 知识点：自主学习          | 全部当前正式题逐题达到已发布标准；可阅读后做，也可直接自测     | 已实现；练习、探索、待复核不替代         |
| 知识点：深入掌握          | 未来以解释、论证、迁移或作品为依据，先制定量规和复核机制       | 保持灰色，不自动授予                     |
| 课程：点亮                | 全部非拓展知识点至少有一种真实经历星；表示经历覆盖             | 已实现自学星汇总，未知层级不纳入虚假覆盖 |
| 课程：完整复习 / 全面掌握 | 按V1.0分别依赖有效复习覆盖、适用知识点的完整星证据             | 保持灰色，判据与相应证据待建设           |

历史获得与本版表现应并列：例如“保留历史版本的星记录；本版自测3/4题通过，1题待复核”。新版材料不自动继承旧版通过，新失败也不抹去过去努力。本轮修正旧版星遮住本版进度的展示问题；不增加条件说明，不改变授星规则，不发放新的货币奖励。

当前“每道正式题达标”是实现采用的保守规则，不是教育学证明的通用100%掌握阈值。课程组需确认正式集合的代表性、每题通过线、反馈可见条件及人工复核负担；可选挑战应在发布前归入练习或探索，不能按用户自述悄悄减少正式分母。普通参考解答可查看，正式自测仍是形成性证据，不是监考成绩。

待课程组讨论的方案，不在本轮自动实施：深入掌握的公开量规；什么构成有效复习；是否以未暴露平行题、延迟检验或新情境任务补充证据；课程成绩证明与点级映射。课程星的范围变更提示目前只追踪节点集合，未来还需分开呈现各点版本更新后的当前证据。不要按时长、消息轮数、文字长度或选择“完整掌握”授星。

## 12. 当前网站还缺什么：先补内容与真实闭环

对新手、熟悉者、查阅者和探索者的检查，结论不是继续增加入口，而是补齐真实材料、反馈归宿与发布条件。下列缺口与本轮已实现功能分开，不包装成已上线。

| 优先级   | 当前缺口                                            | 下一步与验收依据                                                         |
| -------- | --------------------------------------------------- | ------------------------------------------------------------------------ |
| 发布前   | 本地演示不是正式课程；真实数据库和Max尚未端到端验证 | 按课程组审核稿部署、回读；抽样核验公式、评分、主观复核权限及Max依据      |
| 发布前   | 自测证据与课程组目标是否充分对应尚待教学确认        | 提交目标—题目蓝图、通过线、复核负责人；防止用高难题误设所有人的门槛      |
| 发布前   | 正文无节点级草稿/发布状态，保存后直接可见           | 本地完成教学审核后再上传；题目draft不能隐藏正文，后续再考虑独立发布流程  |
| 下一阶段 | 知识点资源仍为占位，尚无完整课程/知识点资源库       | 先落实少量授权资源及真实入口，再实现检索、分类和审批，不显示虚假资料     |
| 下一阶段 | 已有探索题与私人路径，但缺研究任务的完整成果闭环    | 支持问题、假设、证据、结论与限制的主动记录，区分私人作品与自愿公开共建   |
| 下一阶段 | 单点跨章直接关系已可用；跨课程与六类学术关系未迁移  | 先复核关系语义与来源，再升级接口；不递归展开全章、不将旧顺序当先修证据   |
| 下一阶段 | 订正按点有效，跨点复习与长期学习效果证据尚不完整    | 提供课程级复查清单；另设计延迟和迁移任务，不能用点击、星数和立即订正代替 |

已有的个人业务记录、私有批注、授权过程统计及描述性管理分析可以使用；管理端尚不能声称已经验证“平台提升了学习”。对真实模型还需做基础解释、条件边界、错误纠正、引用可靠性、资料不足时的拒绝猜测及故障恢复抽样；这些不是模拟响应能够证明的。

Max的真实运行还依赖模型配置、上游服务及RAG索引版本同步。当前索引主要包含官方正文分区与课程内连接，不将未接入的独立资源库、社区资料和跨课程关系宣称为已具备的完整来源层。

建议顺序：先让少量经审核知识点完整可用，并明确待复核处理人；再做资源与探索成果；最后扩大关系语义、课程级复习、教学效果测量及语音。当前接口接缝已补回归，未因列出缺口擅自扩大本轮范围或提交PR。
