# 全站搜索与 Max 站内导览

点击顶栏搜索入口，或按 Ctrl / ⌘ K 打开搜索；不在输入框中时也可按 `/`。独立页面 `/search?q=关键词&type=post` 可分享或收藏。分类包括页面、帖子、课程、知识点、电路，支持中文分词、正文匹配、分类筛选和继续加载。

搜索实时读取现有数据库，只返回当前登录状态可读且未删除、未隐藏的帖子。停用版块与停用课程不参与检索，匿名帖不返回作者身份。私有对话、校园授权数据和账号资料不进入搜索。搜索入口根据标题与账号区域之间的实际空间展开，不足 180px 时缩为放大镜；手机使用图标。

Max 在询问本站位置、查找内容或推荐帖子时，按服务端认证身份使用同一检索服务，读取相关正文与评论；支持本站帖子和知识点链接。页面入口说明统一维护在 `backend/site-search.js`。这是页面用途导览与实时内容检索，不是页面截图或通用网页浏览器。普通聊天不运行站内检索，不例行附加链接；帖子、评论作为不可信资料处理。

Max 输入栏在所有尺寸下均为单行：加号打开文件、拍照和照片菜单，大脑打开模型与思考设置，右侧发送。附件显示在上方，输入多行文字时自动增高。手机输入状态使用 VisualViewport 的可见高度和偏移调整布局并隐藏全站导航。对话区域没有外框或重复标题；手机对话记录入口在顶栏。

新旧帖子默认开启“登录后可见”，发帖时可关闭，作者或管理员可在详情页修改。未登录时列表和搜索不返回受限帖子，详情和评论 API 返回 401。打开链接显示登录提示弹窗；进入登录页时保留本站帖子路径，成功后回到原帖。此选项独立于“隐藏帖子”（仅作者可见），不改变隐藏帖的阅读权限。

数据库字段由启动检查或 `043_discussion_login_required.sql` 添加。验证包含权限、默认值、非法修改、链接登录提示与安全回跳、站内搜索和 Max 上下文测试；桌面 901/1024/1280/1366/1440/1920px 与手机 320/390/900px 的搜索入口碰撞检查；附件菜单及 420px 可视窗口模拟。原生拍照和 iOS 键盘仍需真机确认。
