# 全站搜索与 Max 站内导览

点击页面顶部放大镜，或按 Ctrl / ⌘ K 打开搜索；不在输入框中时也可按 `/`。独立页面 `/search?q=关键词&type=post` 可分享或收藏。分类包括页面、帖子、课程、知识点、电路；支持中文分词、正文匹配、分类筛选和继续加载。搜索失败和无结果会分别提示。

搜索实时读取现有数据库，不建立包含旧内容的旁路索引：只返回公开且未删除、未隐藏的帖子，停用版块与停用课程不参与检索。匿名帖不返回作者身份；私有对话、校园授权数据、账号资料不进入搜索。已保存电路与现有公开分享接口保持一致。查询有长度、结果数和执行时间限制，无需数据库迁移。

Max 在用户询问本站位置、查找内容或推荐帖子时，使用同一检索服务，读取相关帖子的正文与最近公开评论；也能读取提供的本站帖子或知识点链接。页面入口说明统一维护在 `backend/site-search.js`。这是一份页面用途导览与实时内容检索，不是页面截图或通用网页浏览器。

普通聊天不运行站内检索、不附加页面目录。回答提示要求仅在有需要时提供链接，推荐或引用必须使用真实检索结果；读取到的帖子、评论均作为不可信资料处理。前端不再在空导航结果时强行附加课程入口，也不会因一般知识问题自动显示导航卡片。

Max 手机输入状态使用 VisualViewport 的可见高度与偏移调整布局，收起模型设置并隐藏全站底部导航；附件图标、文字输入与发送保持一行，选中的附件仍可见。退出输入后恢复页面。桌面端保持常规布局。

验证包括后端检索、权限条件、读取失败、Max 上下文、自然回答与视口状态回归测试；真实生产数据库只读查询；浏览器 320/390/1440px 搜索交互、失败与空状态；420px 可视窗口模拟。iOS 原生键盘工具栏由 Safari 控制，网页不能移除。
