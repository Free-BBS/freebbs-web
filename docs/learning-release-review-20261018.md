# 学习端按需流程与导航：提交前检查

日期：2026 年 10 月 18 日（北京时间）。本轮承接已合并的 PR #190，在独立分支提交；已合入检查时的 `origin/main`（`de13752`）。本文是工程验收记录，不是上线公告或学习效果结论。

## 本次内容

- 在同一套课程资料上提供四种当次目的与四档自述程度的起始建议；偏好可记住、可调整，不作为能力诊断，不复制 16 份教材。
- 复习先回忆或尝试，有缺口才定点查漏；理顺即可结束或暂停，不自动产生正式通过、星标或路径完成记录。
- 探索四档都先接住本人问题；正文、起源、练习和关系按需调用，不强制重读或做题。
- 用户主动发送消息时，Max 接收服务端校验后的当前步骤与任务问题，结合本人当前知识点已保存资料提供帮助；草稿不自动发送，正式评价与自述分开。
- 并存分段路线、宽幅可查找目录和单点直接关系；保留实际章节名称，不将目录顺序伪称先修关系；补齐加载失败恢复、返回上下文与 Max 导引。
- 课程组当前模板同步四种目的与按需支持，重建作者下载包；研究论述与参考文献随仓库保存于 `docs/learning-design-position-20261017.md`。

## 本轮检查后补充修复

1. “查找本章知识点”先展开闭合的筛选区，再定位并聚焦，避免点击没有可见反应。
2. 只有知识起源、没有正文时，反思步骤仍可真正打开起源批注工具。
3. 原生概览关闭事件迟到时，不抢回用户已经移到下一知识点或其他控件的焦点；保留正常返回目录及新打开概览的状态。
4. 路线浏览器验收使用新的页内学习方式表单，不再等待已取消的旧弹窗。
5. CI 显式执行 `test:learning-policy`，包含策略、条件流程、视图、步骤同步与隔离预览测试；补防遗漏断言。
6. 本地合成账号预览兼容主站新增隐私状态接口，明确返回模拟状态，不写真实同意、不改生产隐私逻辑；无效身份、外域和注入失败仍保留原有拒绝与错误。
7. 预览测试统一使用已有允许端口选择器，避免操作系统分配 Fetch 禁用端口造成随机失败。

## 提交与后续边界

- 本轮没有新增数据库迁移、第三方运行依赖或生产配置；同步主分支不代表将其已有修改重复计入本次功能。
