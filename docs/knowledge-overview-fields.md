# 学习概览展示字段

课程图谱与知识点页面共用 `public/knowledge-overview.js` 的展示模型；不修改或迁移原文，现有三段 Markdown、编辑权限和版本检查保持不变。

| 展示字段       | 来源 / 推荐写法                                    |
| -------------- | -------------------------------------------------- |
| 名称、编号     | 节点的 `title`、`id`                               |
| 课程           | 当前课程 `name`，旧资料兼容“课程名称”              |
| 章节           | `章节/单元：第一章`                                |
| 类型           | `知识点类型：概念`                                 |
| 层级           | `知识点层级：核心`（由课程组填写，不推断）         |
| 难度、重要程度 | `难度（1-5）：2`、`重要程度（1-5）：4`             |
| 建议时长       | `建议学习时长：20 分钟`                            |
| 参与同学       | `参与同学：张三、李四`                             |
| 简介           | 节点 `summary`；无摘要时取应用 Markdown 的首段正文 |

上述字段写在“基本信息 Markdown”内。兼容标题后换行给值、冒号键值、Markdown 双列表格。旧资料中的填写人、编写人、作者、修改人、修订人、审核人、贡献者统一展示为“参与同学”，保留所有名字并按首次出现顺序去重；不从姓名猜测用户 UID 或生成个人主页链接。

简述默认最多 150 字；“完整说明”保留原有基本信息和应用原文。缺失字段不伪造，“参与同学”缺失时显示“暂未署名”。这次不改动客观完成度星、学习状态或课程关系模型。
