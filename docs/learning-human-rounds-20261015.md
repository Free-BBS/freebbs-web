# 学习世界：从同学的实际任务再走三轮

本轮继续补入未合并的 PR #190，不操作生产课程、账号、题目或成绩。这里的“新手、回访、查阅、探索”是当下任务，不是给同学固定分层。

## 第一轮：进来知道去哪儿

- 回访者看到本人真实上次查看的知识点，主动选择继续阅读或查看它的位置。没有有效记录、换账号、访客或章节点时不虚构“上次”，也不自动打开内容。
- 全课程搜索分别列出真实章节和知识点。旧课程没有 0 级章稿也可以搜真实章名、选择已有章节；不把派生章节当可请求的作者文档。
- 全课程与章节内搜索保留可见的范围说明。手机选择后部章节时只滚动目录内部，使当前章可见，不改变整页位置或抢走焦点。

## 第二轮：读得到，找得到，回来接得上

- 主动选择“进入学习”且没有可恢复书签时，落到阅读区，而不是留在正文上方两屏。已有书签、明确题号/起源目的地及用户主动操作仍优先；访客同样可以读。
- 本页目录按需打开，只列当前正文实际可见标题。没有复制教材或增加作者 ID；闭合参考解答不列入，不自动展开答案。选择后定位原标题并提供键盘焦点，临时焦点属性离开后还原。
- 长文读到中段后显示一个小的阅读导航入口，可就近查目录、去做题或看下一步建议，不展开新侧栏。切题前捕获当前段落，返回正文继续原位置。
- 导航避让 Max 入口及固定返回控件；手机 Max 面板打开时不叠加浮动入口。脚本迟到时可从已确认的公开上下文初始化；导航脚本未到不阻断正文阅读。

## 第三轮：帮助不替人作决定

- Max 快捷解释、小题和事件求助先准备问题草稿，由本人修改或发送；不覆盖手写问题、原文引用或等待回答时的新稿。正式发送与模型请求仍由原表单完成。
- 默认建议改为“先读一小段”，明确可以只读一个概念或例子。分钟数展示为建议投入，不把长正文的完成时间当作系统预测。
- 暂停如实表述为这条路径暂停；暂停期间，不累计“继续学习”板面的活跃停留估计，转去正文等其他活动仍正常记录。不暗示刷新后自动保存暂停状态。保存路径、完成、跳过、正式评分与星标规则不变。

## 验证与解释边界

使用现有公开数学/信号课程快照及作者示例，在隔离内存账号与模拟 Max 中验证实际点击、键盘、中文搜索、明暗模式、桌面/手机/短屏、账号隔离、书签、缺脚本与闭合答案。公开快照不是包含评分配置的完整作者备份；实体触摸选文、读屏软件、生产模型教学效果及跨设备同步不由这些检查证明。

发现的浮钮重叠、错误的手机面板状态判断和标题遮挡保留了修改前证据，再按原严格判据复验；不将重复跑同一条路线算作更多真实学生。历史 material-gaps 浏览器脚本仍含旧界面假设，本轮未完成现代化，不计为本轮通过。

下一步适合邀请真实同学做“不教点击顺序”的任务观察：陌生课程找一个入门点，回访继续昨天的段落，临时查清一个条件，练习后回查依据。操作验证只能证明能用；是否更好地掌握知识仍须课程部与战略部按独立题、延迟保持和新情境应用另行研究。
