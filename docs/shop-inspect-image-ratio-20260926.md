# 端详物品图片比例修复

## 原因与处理

原图宽高为 512×512，渲染器也输出了对应的 width / height 属性。旧的详情样式只缩小图片宽度，没有重置高度，默认 object-fit: fill 把图片拉长；本地橡胶棒实测显示约 114×512。

共享详情弹窗现将直接子图片设为 height: auto、aspect-ratio: auto、object-fit: contain，并按列宽等比例缩放，最大宽度 240px。图片区独立顶端对齐，不受右侧长说明拉高。移除移动端遗留的 64px 图标宽度，手机上也可清晰端详插画。

选择器限定为直接子图片，不覆盖头像框、铭牌、主页主题和 Max 的真实组件预览；商品图片文件、价格和交易逻辑不变。
