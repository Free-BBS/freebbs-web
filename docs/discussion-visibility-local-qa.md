# 讨论区显示与可见性修复 · 本地验收

初始验收在隔离环境中完成，未执行真实数据库迁移。以下包含与最新主分支整合后的权限约定。

## 修改范围

- 详情页版块、作者、时间、回应控件垂直居中对齐，保留手机端自然换行。
- 公开列表、详情、评论默认不展示软删除帖子。管理员可通过显式 includeDeleted=1 在公开范围查看已删除帖的原文；该入口不绕过隐藏权限，“我的帖子”仍排除删除帖。首页/课程讨论使用相同的公开列表接口；公开个人主页、板块计数排除隐藏/删除内容。
- 讨论区新增“我的帖子”，沿用板块与排序筛选；以游标分页加载较早的帖子，每页最多 50 条。
- 本人详情工具栏可“隐藏帖子 / 恢复公开”。隐藏内容只允许作者读取；普通用户、版主、管理员都无阅读旁路，匿名作者管理查询也遵守隐藏权限。本人仍能查看原评论或删除隐藏帖。
- 隐藏期间暂停评论、评论点赞/删除与帖子回应，取消置顶/精华；恢复公开不自动恢复这些版主管理状态。
- 后端校验身份和布尔参数，互动与隐藏/删除共享帖子行锁；后台 Max 回复在生成前过滤、落库前再次检查。页面切换范围/账号会清空私有缓存并使旧请求失效，详情不使用未经重新验证的缓存正文。
- 隐藏/删除会将相关 reply、reaction、comment_like 站内通知的旧标题、评论摘要替换为通用提示，保留通知历史。已被他人阅读/保存的内容、已投递邮件不能撤回；隐藏帖子不等同于为原来公开的上传文件提供独立文件权限。

## 数据库与部署

新增 `discussion_posts.is_hidden`，默认 0，旧帖子保持公开；现有 `is_deleted` 不变，不硬删除帖子。
`backend/server.js` 启动时会按 information_schema 检查并只在缺失时补列。对应人工迁移为 `database/migrations/035_discussion_visibility.sql`；如果启动已补列，不要重复执行同一 ALTER。发布需重启后端，不能只更新前端。

## 本地验证

```bash
npm run test:discussion-markdown
npm run test:public-pages
npm run lint -- --quiet
```

- Node 测试实际执行主服务中注册的路由，数据库使用内存替身；覆盖公开/本人/访客/他人/管理员、删除、隐藏/恢复、类型检查、SQL 参数、分页、评论和点赞竞争写入，以及旧会话响应。不是实际 MySQL 集成测试。
- Chrome 隔离预览：1440、768、390、320 宽度 × 明暗主题；验证作者对齐、我的帖子、隐藏与恢复、暂停互动、删除后无占位、跨标签页会话失效、大字号和无横向溢出。API 均为隔离模拟，不修改账号和帖子。
- 真实 MySQL 的 7 项集成测试未运行；未经授权没有启动真实后端/发送通知邮件。待用户确认本地数据库配置后，可用 `bash scripts/start-local.sh`、访问 `http://127.0.0.1:3000/discussion` 联验两个测试账号的可见性与迁移。
- 汇总回归覆盖 76 个独立测试文件：859 项测试，852 通过、0 失败、7 项按条件跳过。全仓 ESLint（错误级）与改动文件格式、diff 空白检查通过。讨论区新增 47 项定向测试；首页已有 25 项测试。浏览器为上述 8 组讨论区场景及 12 组首页场景。
