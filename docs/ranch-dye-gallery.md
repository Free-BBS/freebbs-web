# 羊的染坊与羊群广场

## 入口与使用

- 自己的 `/ranch` 底部新增「染坊」；顶部「羊群广场」对访客也可见。
- `/ranch-dye`：登录并领养 Max 后，分别编辑羊毛、脸部。点按落笔；高斯泼染支持拖动，一次拖动可整体撤销。脸部编辑自动放大。
- 花纹：高斯泼染、同心扎染、波纹条染、旋涡扎染。叠色：自然、正片叠底、滤色、叠加、柔光。
- 可调颜色、大小、浓度、方向；可铺底色、清空当前部位、撤销，或叠加晨光／湖水／莓果预设。
- 保存免费且只改变外观，不消耗羊毛、货币，也不影响喂养、剪毛或专注计时。
- 保存后，外观在个人主页、牧场及广场公开显示。没有保存的编辑不会上传；离开时提醒。
- `/ranch-gallery` 展示公共牧场，自动加载所有已领养的羊（包含未染色的原色羊）。羊在同一背景的地面区域分层散步，保留各自主人的染色。点击羊打开互动栏，可打招呼、摸摸它、与附近的羊一起散步，或进入主人的牧场。
- 公共牧场互动是当前页面里的动画反馈，不向其他用户发送通知，也不扣除货币或更改对方资产。不同访客的行走位置不实时同步。只显示公开 UID、用户名、外观，无真实姓名、学号等私密资料。

## 数据与安全

- `054_ranch_designs.sql` 由启动时 `ensureRanchDesignTables` 幂等建立，不修改旧有经济表。
- 外观仅为版本化 JSON：每个部位最多 64 层；颜色限定六位 HEX，所有坐标、尺寸、透明度、角度有界；模式／混合方式为枚举。未知字段丢弃，不接受上传 SVG、脚本、HTML 或外部图片。
- 浏览器和服务器共用校验器 `ranch-design-data.js`。损坏／旧版本记录安全回落到原色。
- PUT `/api/ranch-designs/mine` 只使用服务端认证的 user ID；需要领养资格。锁定用户行和设计行，比较 revision，冲突返回 409，不覆盖其他标签页的修改。
- GET `/api/ranch-designs/mine` 需要认证；GET `/api/ranch-designs/:uid` 和分页列表为公开数据。所有接口 no-store。
- 跨标签页身份变化立即清除编辑状态、禁用保存；重新载入会刷新页面，不能复用旧内存凭据。保存响应也校验会话和请求版本。
- SVG 使用原羊形状裁切，不覆盖眼睛、鼻子、眼镜；不同羊的渐变／裁切 ID 独立。公共牧场使用现有四足行走动画，页面隐藏时暂停，减少动态效果偏好下显示静止羊群。牧场刷新、长／短羊毛及漫步动画不受影响。

## 验证

- `node --test scripts/ranch-design.test.js`：输入边界、恶意参数、公开数据最小化、认证、领养资格、自己的身份、版本冲突和分页。
- `npm run test:mysql:isolated` 的 community 集成测试：实际建表、持久化、并发初始保存、只公开已领养的羊、跨账号隔离、重置设计。
- Chromium / WebKit 本地真实页面壳：鼠标染脸、拖动染毛、整笔撤销、四种花纹、保存／重载、24+3 分页、SVG ID 唯一性、牧场／个人主页同步、跨标签页凭据失效。
- 1440、390、320 像素宽度及亮／暗主题检查；手机高级笔触默认折叠。
