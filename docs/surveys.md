# 活动报名与抽签

公开入口：主界面左侧“活动报名”（`/surveys`），手机端在导航栏内。管理入口：`/system-settings/surveys`，也可从系统设置中的“活动报名”进入。列表和详情始终公开，无需登录。

## 管理员使用

1. 新建问卷，填写说明、开放及截止时间、抽签名额和抽签方式。时间按浏览器所在时区输入。
2. 可勾选“需要登录后才能报名”，默认关闭。此设置与题目一样发布后锁定，复制及自动生成下一期会继承该设置。开启后由后端校验有效登录身份，并按账号和联系邮箱去重；访客仍可查看详情，点击登录后返回该活动。
3. 添加单选、多选、简短填空或长文本题；每题可设置必填，选择题每行一个选项。联系邮箱为内置必填项。
4. 保存草稿，检查后发布。发布后问卷内容和报名时间锁定，避免报名过程中改变规则；需要调整时可取消本期或复制成新草稿。
5. 点击“复制邀请链接”，将邀请内容发送给同学。公开报名大厅会自动展示已发布问卷和未来开放的问卷。
6. 截止后自动抽签，或点击“执行抽签”。查看报名详情、抽签时间、执行者及中签状态，导出 CSV 后联系中签同学。

管理列表每页显示 200 条活动，可通过“上一页 / 下一页”查看历史活动。退出登录、切换账号或服务端返回无权限时，页面会清空报名资料并禁用导出；每次导出都会重新请求服务端校验权限。

“重复发布间隔”设为 7 表示每 7 天自动发布新一期，每期独立报名和抽签；0 表示单期。重复周期不得短于报名时长。下一期在当前期截止后生成，开放/截止时间均按周期顺延。“停止后续重复”会停止当前问卷及已生成后续期次继续生成新问卷，已发布期次仍有效；如需停止报名，再取消对应期次。取消本期不会撤销之前已生成的下一期。

这里的定期发布是自动在公开大厅发布新一期，不会自动向外部邮箱发送邀请或中签邮件。管理员使用邀请链接分发，并通过导出的联系邮箱安排测试。

## 学生使用

未开启登录限制时，打开链接即可填写，无需平台注册或登录。开启限制时需登录后提交。同一期邮箱不区分大小写，只能报名一次；不验证邮箱所有权，因此这是轻量报名去重，不能保证每个自然人只有一个名额。

报名成功后请下载回执。回执是随机 256 位凭据，仅存储哈希到数据库，支持匿名查询自己的抽签结果，不公开姓名、邮箱或回答。回执只在当前标签页的当前登录会话内保存，支持同一会话刷新后查询；登录、退出或切换账号时清除，不跨标签页自动读取。旧版浏览器共享缓存因无法确认归属，不会迁移，页面会删除旧缓存。请务必下载回执备份，后续可手动输入查询。回执丢失可联系管理员通过报名详情核对，不提供按邮箱公开检索。

提交使用同一回执重试时返回已有成功结果，不会重复报名或修改原答案。公开 API 有单进程 IP 速率限制（每分钟 120 次提交/结果查询，兼顾校园共享出口），多实例部署可在入口代理增加统一限流。

## 部署与验证

后端启动时自动执行幂等建表逻辑，对应 `database/migrations/032_surveys.sql` 和 `033_survey_login.sql`。旧的报名表会自动补齐登录要求、账号关联字段与唯一索引；原活动默认保留免登录。033 会检查字段与索引是否存在，因此后端自动升级后仍可执行正式 `scripts/migrate.sh`，由正式脚本登记迁移记录，也支持重复执行。使用 `surveys` 与 `survey_entries` 两表，无需修改 Agent 服务或安装新依赖。运行环境遵循仓库要求 Node.js 24+、MySQL 8。

前端 Node 服务已注册上述路径，并将 `/api/` 和 `/uploads/` 同源代理到 `API_HOST`/`API_PORT`（默认 `127.0.0.1:3001`），确保本地双端口下自定义头像可加载。活动页及其共享导航始终请求同源 `/api`，支持自定义本地前端端口与正式 HTTPS 域名，无需硬编码后端地址。从活动页进入登录、注册或找回密码时会保留活动返回地址，成功认证后回到原活动。升级后需重启前端与后端。如部署使用直接托管 `public/` 的反向代理，需要将 `/surveys` 映射至 `/surveys.html`，将 `/system-settings/surveys` 映射至 `/system-settings-surveys.html`，并保留现有 `/api` 和 `/uploads` 转发。

后台每 30 秒检查一次到期任务，启动时立即补检。服务需要持续运行；停机期间不会执行抽签，恢复后补抽已到期的自动问卷，并跳过已经过期的重复期次，生成下一可用期次。手动问卷始终等待管理员操作。

报名、抽签、取消和发布均按问卷行加锁并使用数据库事务。抽签采用 `crypto.randomInt` 驱动的部分 Fisher–Yates 洗牌，不放回随机抽取；报名不足时全部中签，无人报名时记录空抽签。抽签结果与抽签状态在同一事务内提交，多实例重复触发不会重抽。

```bash
npm run test:surveys
# 在隔离 MySQL 实例上执行真实 HTTP/数据库集成测试；测试会创建并删除随机测试库。
SURVEY_TEST_MYSQL_SOCKET=/path/to/test-mysql.sock npm run test:surveys
# 同时提供该隔离实例的 TCP 端口，可验证正式迁移脚本与启动升级的兼容性。
SURVEY_TEST_MYSQL_SOCKET=/path/to/test-mysql.sock SURVEY_TEST_MYSQL_PORT=3306 npm run test:surveys
```

测试覆盖题目/答案校验、抽签算法、管理员接口权限、公开回执查询、重复报名、并发幂等提交、截止边界、并发抽签、空抽签及周期恢复。可通过 `SURVEY_TEST_MYSQL_USER`、`SURVEY_TEST_MYSQL_PASSWORD` 配置测试账号；该账号需具备创建与删除测试数据库的权限。

登录限制及导航变更必须部署新版前后端后才会在远端生效。本地测试不能替代线上部署；正式域名继续使用现有 `/api` 反向代理。
