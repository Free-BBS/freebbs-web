# 个人主页、规则弹窗与讨论装扮：本地验证

- 个人主页取消 900px/1240px 宽度限制，沿用全局内容区边距；不调整用户字体。
- 电磁场系统弹窗按确认文案展示，余额居中、规则左对齐；移除资产列表，保留商城、仓库入口。本轮未改变奖励计算。
- 讨论区头像复用个人主页装饰，小尺寸收敛；匿名帖不显示个人装扮。环流保留细环轨道；极光升级为宽渐变光幕、弧形光丝和多星星冠，采用独立动画。
- 激光器在列表卡片及完整详情卡片显示淡黄色缓慢流动的柔光，内侧边缘渐亮、中央保留淡金底光；星月图案位于背景层。没有硬描边、内容覆盖层或拦截点击的元素。
- 激光器仍按服务端有效期判断；切换帖子清理旧状态，到期停止发光。
- 减少动态效果偏好下保留静态柔光和头像装饰；强制对比模式下关闭激光器光晕。
