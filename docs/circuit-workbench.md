# 电路实验、图像与报告

## 多图和坐标

“波形与读数”支持分别设置 X、左 Y 和右 Y 轴的 linear / log 刻度。
X=log、Y=linear 即 semilogx；X=linear、Y=log 即 semilogy；两个 log 即双对数图。
对数轴只绘制正值，零和负值作为断点，固定上下限必须为正。
“混合坐标”可以把选中的曲线放在右 Y 轴；两侧分别自动缩放。

“添加一张图”最多保留 6 张图，每张图独立选择 XT / XY、通道、数学表达式、坐标和标题。
图像配置随电路版本保存，固定版本的波形引用也包含这些图。

## FFT

在数学表达式中输入 `fft(CH1)` 或 `fft(CH1-CH2)`。
先计算括号中的时域表达式，再使用 radix-2 FFT 转换为独立的 Hz 频谱图。
仅支持等间隔瞬态采样，采用矩形窗，补零至下一个 2 的幂；幅度按原始样本数归一化。
单边峰值幅度中，DC / Nyquist 不翻倍，其余频点翻倍。
FFT 通道不能直接与时域通道相加，也不能跨时域 / 频域组成 XY 图。
CSV 导出为 FFT 通道单独附上频率列；频谱暂不支持原时域的采样标记。

## 任意波形电源

选中电压源或电流源，点击“导入 CSV / MATLAB 波形”。
选择时间列（秒）与波形列（V / A），支持 2–4096 个点，时间非负且严格递增。
导入后直流偏置置零，可重新调整；瞬态输出为文件值加直流偏置。
提供线性插值 / 阶梯保持、末值保持 / 循环播放。循环周期为首末时间之差。
延迟之前使用直流偏置。DC 工作点和 AC 小信号仍使用各自参数。
文件最多 4 MB，单电源保存的采样 JSON 最多 180 KB，整个电路仍最多 256 KiB。

支持格式：

- CSV / TXT：时间与波形列，可有一行列名。
- MAT：Level 5 的二维实数数组，包括 MATLAB v6 和压缩 v7；不支持复数、结构体和 v7.3/HDF5。可用 `save('wave.mat', 't', 'y', '-v7')` 转存。
- `.m`：仅读取 `t=[0 0.001 0.002]; y=[0 1 0];` 这样的数值数组，不执行脚本、函数、冒号表达式。

MAT 格式依据 [MathWorks MAT-File Format](https://www.mathworks.com/help/pdf_doc/matlab/matfile_format.pdf)。

## 版本历史与 Fork

“版本历史 / Fork”显示保存节点、说明、时间、fork 来源、恢复来源和实验分支。
保存存档和普通保存都产生不可变版本。Fork 会创建由当前用户拥有的新 CID，源电路保持原样。
恢复会追加一个新版本，不删除之前的实验记录；有未保存修改时先自动存档。
恢复仅允许作者或管理员，使用 expectedRevision 检测并发更新。

接口：`GET /api/circuits/:cid/history?before=...`（每页 50 条）、
`POST /api/circuits/:cid/fork`（revision、可选 message）、
`POST /api/circuits/:cid/restore`（revision、expectedRevision、可选 message）。
原 POST / PUT 电路接口增加可选 `message`。

## 实验报告

“一键生成报告”根据当前配置和仿真数据建立 Markdown 报告，并插入原理图与当前波形图。
没有仿真结果时明确标注，统计值不会由 AI 编造。
报告编辑器支持实时预览、公式、上传图片、粘贴截图、拖入图片，以及仿真图插入。

Max 的修改建议单独显示，支持停止、编辑建议、采纳、舍弃；原稿在生成期间发生修改时不会直接覆盖。
报告保留本地草稿，并可保存到服务器；只有报告作者可以读取和编辑，电路仍沿用公开版本规则。
图片使用站点上传链接，与站点其他上传图片一样可由链接访问。
支持 MD、HTML 和浏览器打印 / PDF。HTML 尝试嵌入图片；无法下载的外链图片保留绝对地址。
公式样式通过站点 KaTeX 资源加载，完全离线查看时需同时保存这些样式资源。

报告接口在 `/api/circuits/:cid/reports`，使用版本号检测覆盖冲突。
报告表和版本事件表由 migration 036 / 后端启动时幂等创建。
