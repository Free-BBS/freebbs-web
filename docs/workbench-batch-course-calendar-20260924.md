## 批量安排

用户原句：

> 我今天晚上9点要开书记会，罗姆楼5103；10点要开支书例会，罗姆楼10-206，两个会都是1小时

在当天下午生成，预期为：

| 事项     | 北京时间    | 地点/备注    |
| -------- | ----------- | ------------ |
| 书记会   | 21:00–22:00 | 罗姆楼5103   |
| 支书例会 | 22:00–23:00 | 罗姆楼10-206 |

用户预览时不写入；可以逐条修改后一次确认。超过 3 件会提示分次输入，不截取前三件。某件缺日期、时长等信息时不会仅保留第一件。批内冲突或与现有安排冲突则整批不保存。

周常和空档计划可展开为多个时间段，总展开上限仍为 52，不把“3 件事项”错误地限制成“3 周”。空档计划同时避让同批固定安排、已有个人日程及已生成的课程。

## 网络学堂固定课程

当前连接器已有课程 `scheduleText` 和 `locationText`；这些来自真实同步快照，但原先只是展示文本。新功能根据最新快照动态生成上课事件，不向 `schedule_items` 重复插入副本。

1. 连接网络学堂，重新同步所需学期。
2. 在“分学期课程与公告 → 固定课程自动入表”设置该学期第一教学周的周一日期。
3. 时间完整的课程自动进入七天表/列表，带课程来源、地点和教学周。后续同步更新投影，重复同步不重复生成。

支持明确教学周、单双周/分段周、星期与起止钟点，或已约定的第 1–6 大节。普通“节/小节”未有可靠时间映射时不能当作大节；缺教学周、缺校历起点、调停课说明或无法完整理解时显示具体原因，不猜测排课。未提供的节假日及调课例外不能自动推断，以教务通知为准。

固定课程为来源只读信息，点击查看详情，不提供手工日程的编辑/删除按钮；不会改动网络学堂、手工日程或作业完成状态。不同账号、学期和连接代次隔离；旧快照需重新同步后才有资格自动排课。

AI 预览和确认会检查当时可见的课程占用。后续校历更改或重新同步导致的时间变化，仍可能与已经保存的个人安排重叠，需要用户复核；不会自动移动或删除手工日程来消除冲突。
