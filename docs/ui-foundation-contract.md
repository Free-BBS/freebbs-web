# UI 基础规范与回归边界

本规范对应 PR #177 的三批改动。目标是共用请求、主题、字体、普通操作按钮和加载状态，保留页面布局与专业控件的独立职责；不是一次性删除所有历史样式。

## 职责划分

| 层       | 入口                                                       | 职责                                                     |
| -------- | ---------------------------------------------------------- | -------------------------------------------------------- |
| 请求     | `public/request-runtime.js`                                | 有限超时、取消、响应体读取；不自动重试写请求             |
| 字体     | `public/typography-preferences.js`、`public/typography.js` | 两个前端共用合法偏好、字体角色和字号；存储失败可降级     |
| 主题     | `public/theme.css`                                         | 语义色彩、焦点及禁用状态的公共变量                       |
| 普通操作 | `public/actions.css`                                       | 显式接入的主、次、轻量、危险操作；不负责业务权限         |
| 状态     | `public/ui-state.js`、`public/ui-state.css`                | loading / empty / error / ready 与可访问语义；不发起请求 |
| 页面     | 各页面 JS / CSS                                            | 布局、数据、权限、请求世代、重试入口和特殊交互           |

发展端复用已有 React 状态组件，调用共享请求及字体契约，不向 React 页面注入主站 DOM 组件。

## 新页面接入

1. 沿用页面外壳的运行时加载顺序。字体偏好应在首屏样式之前恢复，不能等业务请求返回才应用。
2. 用 `--font-zh-title` / `--font-display` 表达普通标题、`--font-copy` 表达正文、`--font-ui` 表达界面。数学、代码、知识点 ID、实验标注与游戏保留对应专业角色。
3. 普通按钮添加 `.bbs-action` 和 `data-action-tone="primary|secondary|quiet|danger"`，保留原 ID、事件、表单类型和业务类名。旧局部 paint 声明使用共享变量、原值作 fallback；不新建页面专属色板。
4. 原生 `hidden` 与 `disabled` 保持有效。`aria-disabled` 仅提供语义，事件处理仍须自行阻止执行。普通按钮按下不得改变命中区域；圆形评论折叠、工具栏图标、地图、实验画布、编辑器及游戏不批量套用普通按钮。
5. 列表成功且确实无数据才显示 empty；失败显示 error，手动重试只重试对应读取。刷新失败可保留旧数据并明确报错；401/403 等权限失效须清理私有内容。
6. 异步结果应用前核验请求世代、目标及账户身份。取消不保证服务器停止执行，也不保证迟到回调消失；不得用自动重发补偿不确定的写操作。

## 第三批接入范围

- 20 个页面的普通表单、确认、编辑与管理操作；另覆盖动态活动、课程上传、管理员奖励及凭据按钮。
- 更多普通标题、导航、正文和数字对齐回归到共享字体角色，保留原默认字号。
- 讨论帖子与版块、管理员列表、Max 历史会话、站内搜索统一失败与重试语义，加入迟到响应隔离。
- Max 保存回执、即时发送及后台恢复也核验账户 / 会话 / 视图，旧回调不会解锁新任务；切换会话释放旧界面的等待状态，不自动重发、取消或改写服务器任务。
- 搜索分页失败保留已显示结果并重试原分页；活动请求共用有限超时，存储不可用时可以使用当前内存会话。
- 修复侧栏数字简写覆盖等宽数字、320 px 手机经济栏初始裁切，更新旧浏览器测试以遵循必选学习起点和明确课程接入流程。

## 可重复检查

```sh
npm run test:ui-foundation
npm run test:ui-components
npm run test:ui-page-migration
npm run test:ui-page-migration:browser
npm run check --prefix development
```

浏览器脚本要求本地可用的 Chromium / Puppeteer；可以通过 `PUPPETEER_MODULE`、`CHROMIUM_EXECUTABLE` / `CHROME_PATH` 指定安装路径。`typography-role-migration.test.js` 的真实浏览器子项在未配置 `PUPPETEER_MODULE` 时明确跳过，不能把跳过算作浏览器验证。

CI 执行第三批合同与行为回归。浏览器回归使用本地内存数据、隔离账户和测试响应，覆盖桌面 / 手机宽度、明暗模式、字号与交互；不会对线上账户购买、发帖或调用付费模型。

## 本地验证边界

| 功能域         | 检查内容                                                                      |
| -------------- | ----------------------------------------------------------------------------- |
| 页面外壳与偏好 | 全站直接入口、加载首屏、主题、字体、长标题、窄屏余额、导航与搜索              |
| 学习           | 必选起点、概览到正文、起源吸顶、练习与星标、批注、讨论和课程关联              |
| 工作台         | 计划偏好、时间范围、事件 CRUD、课程接入确认、单次课程修改、并课、假期及跨午夜 |
| 社区           | 帖子 / 版块 / 回复失败恢复、权限失效、折叠及定位、装扮与成就                  |
| 实验和工具     | 语言环境状态、五类嵌入工具裁切与交互、电路成就、俄罗斯方块颜色与显示          |
| 账号和商城     | 行内校验、验证码壁钟倒计时、余额、购买 / 错误状态、商品及仓库展示             |
| 活动和管理     | 普通 / 动态操作、列表失败与手动恢复、未保存编辑保护、账户切换                 |
| 发展端         | lint、格式、类型、单元、操作脚本、工作流与生产构建                            |

视口模拟不等同于真实手机。当前实测浏览器为 Chrome；本机 Edge 无头启动失败，不能宣称 Edge、Safari、Firefox 已验证。真实 MySQL、语言运行环境及服务集成由独立 CI 验证；实际校内账号、邮件送达、外部模型质量和生产网络不由本地模拟证明。以上不是“所有功能在所有设备上完备”的保证。
