# 「無体育」Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将体育入口升级为“無体育”，交付可维护的马杯比赛时间线和由队长维护的代表队图文风采。

**Architecture:** 在 sports 模块中增加独立的 match 与 showcase 资源，沿用统一 DevelopmentStore、作用域授权和审计机制。Web 端新增赛程页与图文编辑组件，体育首页只负责首发入口和队伍列表，队伍详情通过独立接口读取与保存风采。

**Tech Stack:** React 18、React Router、TypeScript、Express 5、Zod、Multer、MySQL、Vitest、Testing Library、Playwright。

## Global Constraints

- 侧栏和页面标题统一使用“無体育”。
- “马杯立刻看”位于模块首页最上方并高亮，原有代表队列表下移。
- 比赛按日期横向切换，并在纵向时间轴上交错展示；窄屏使用单侧时间轴。
- 体育中心全部部员可以创建比赛；部员管理本人创建项，部长、负责人和管理员管理全部比赛。
- 队长仅能维护其 `sports_team` 作用域内的风采；部长、负责人和管理员可维护全部。
- 风采正文使用 Markdown 存储，通过工具栏完成基础排版和图文插入；不运行完整 LaTeX 编译器。
- 所有文件、内容和 URL 在服务端校验，所有写操作记录审计事件。
