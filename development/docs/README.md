## 当前平台范围

当前 MVP 包含九个页面：工作台、经验库、信息与咨询、社群与俱乐部、活动、联络资源、体育代表队、财务治理、权限与模块管理。平台核心已经提供主站身份适配、统一授权、模块注册、审计、MySQL 持久化和运维脚本。

其中，主站身份适配器按照 `GET <MAIN_SITE_API_BASE_URL>/api/auth/me` 实现，仍需在生产上线前与真实主站完成契约和异常场景联调；部署文档中的域名、TLS、服务器路径和密钥均为需要部署负责人填写的环境参数。

## 责任与贡献入口

- 项目负责人 / 核心平台组维护主站身份对接、权限与 Tag、公共契约、模块注册、审计和部署基线。
- 各部门或认领团队维护经验库内容以及信息咨询、俱乐部、活动、联络、体育和财务等领域模块。
- 体育团队可独立迭代代表队系统；平台核心负责队长 Tag、代表队作用域隔离和敏感操作审计。
- 新模块接入前，应在 Issue 或 Pull Request 中写明负责人、目标用户、数据归属、所需权限、接口、长期维护方式和验收标准。

所有模块共享主站登录身份，但不会共享无限权限。领域团队对本模块的开发和维护责任，不会自动转化为对全部领域数据的访问权；最终授权以服务端角色、动作、资源、作用域和 Tag 判断为准。

## 常用命令

命令均从仓库根目录执行：

```powershell
npm ci
npm run dev
npm run check
npx playwright install chromium
npx playwright test
```

本地 Web 入口为 `http://localhost:5173/development/`。生产路径约定为 `https://<主站域名>/development/`，实际域名和上线状态应以部署负责人公告为准。
