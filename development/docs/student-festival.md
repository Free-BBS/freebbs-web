# 「我要上学生节」特别栏目

活动页顶部的暖色置顶入口进入 `/development/events/student-festival`。用户填写标题（最多 120 字符）、说明（最多 2000 字符）并上传一个视频。支持 MP4、WebM、MOV，单文件最多 100 MiB，优先使用浏览器兼容性更好的 MP4。服务端检查上传大小、媒体类型与文件头；视频流写入磁盘，不把整个上传文件放进 API 内存。上传解析使用 [Express Multer 的磁盘存储与大小限制](https://expressjs.com/en/resources/middleware/multer/)。

## 展示与权限

「我愿意即时展示」默认不勾选，旁边明确注明审核通过后展示。

有审核权限的用户可点击页面顶部的「审核投稿」，直接进入下方审核区；也可以点击「投稿审核」标签。预览环境的右上角「预览身份」现已包含文艺中心、体育中心、联络中心、权发中心各自的部员、部长和负责人。选择「文艺中心部员」即可体验审核流程。正式环境的身份由平台授权管理维护，预览身份切换不会出现在正式主站认证模式中。

| 情况               | 状态     | 普通登录用户     | 投稿者             | 审核人员         |
| ------------------ | -------- | ---------------- | ------------------ | ---------------- |
| 不勾选展示         | private  | 不可查看         | 查看投稿回执和状态 | 查看作品         |
| 勾选展示，尚未审核 | pending  | 不可查看         | 查看投稿回执和状态 | 查看、通过或拒绝 |
| 审核通过且愿意展示 | approved | 展示流中查看视频 | 查看作品           | 查看、撤下展示   |
| 审核拒绝或撤下展示 | rejected | 不可查看         | 查看投稿回执和状态 | 查看作品         |

已同意展示的作品被拒绝或撤下后，审核区显示「重新审核并展示」，有权限的审核人员可重新填写审核说明并恢复展示。服务端使用独立的 `reapprove` 操作，只接受已同意展示且状态为 `rejected` 的作品，并记录复核审计日志；过期的首次审核请求不能覆盖退回结果。未同意展示的私密作品不提供此操作。

审核人员包括文艺部成员 `department.arts_member`、文艺部部长 `department.arts_director`、文艺领域负责人 `domain.arts_lead`、团委负责人 `affiliation.tuanwei_lead` 和平台超级管理员 `platform.super_admin`。不自动包含其他部门负责人或普通团委成员。未勾选展示的作品无法通过审核强制公开。投稿者仅能读取自己的非公开投稿回执，私密视频本身仍遵循「仅审核人员查看」要求。

展示范围为已登录的主站用户。列表和视频接口都由服务端验证身份、角色、同意状态和审核状态；媒体链接不是静态目录。浏览器点击播放后才携带认证头获取视频 Blob，切换页面时撤销临时地址，不把登录凭据放进 URL。列表分页每页 12 条，按投稿时间倒序。上传、审核和撤下操作记录审计日志；并发审核在数据库事务内锁定当前记录。

## 存储和发布

1. 执行增量迁移 `database/migrations/010_student_festival.sql`，保存投稿元数据。现有 memory 模式支持开发演示，生产使用 MySQL。
2. 设置 API 环境变量 `FESTIVAL_UPLOAD_DIR` 为 Web 根目录之外的绝对持久目录，例如 `/var/lib/freebbs-development/festival`。生产环境未配置时上传接口返回 503；开发默认写入 API 工作目录下 `.data/student-festival`（已忽略 Git）。
3. systemd 模板使用 `StateDirectory=freebbs-development` 维护可写状态目录，并提供默认路径。Docker Compose 已挂载 `festival-videos` 持久卷，镜像为应用进程准备相应目录；采用其他容器部署方式时须配置同等的持久挂载与写入权限。多实例须共享媒体目录。
4. Nginx 模板允许 101 MiB 请求体（包含 100 MiB 文件和表单开销），上传相关超时为 300 秒。上游反向代理也须允许该请求大小。其余 JSON 接口仍受 Express 的 64 KiB 限制。
5. 发布与回滚不能删除媒体目录。数据库备份与媒体目录须一起备份，恢复时保持文件键对应。现有数据库备份脚本只覆盖数据库，运维需另外备份此目录。

上传中断和校验失败会清理临时文件，元数据事务失败也会清理文件。进程意外终止仍可能留下孤立文件；定期核对目录内文件键与数据库引用后再清理。文件名由服务端随机生成，真实路径不进入客户端响应。

浏览器播放前会完整读取所选视频，因此较大文件需要等待；列表不会自动下载或自动播放全部视频。文件头验证不进行转码，特定编码不能播放时可重新导出为常见的 H.264 MP4。
