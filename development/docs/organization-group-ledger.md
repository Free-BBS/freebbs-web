# 组织组活动台账

入口不变：风采展示 → 团委 → 组织组 → 活动台账，地址为 `/development/organizations/youth_league/organization/ledger`。

## 填报内容

新版班级活动表包含八项内容，活动台账与 Excel 使用相同列顺序。

| 字段         | 要求                                                    |
| ------------ | ------------------------------------------------------- |
| 班级         | 必填，只能选择当前团支书授权的班级                      |
| 参与人数     | 必填，填写正整数                                        |
| 活动时间     | 必填，填写实际活动日期；须符合管理员设置的学年日期范围  |
| 活动标签     | 必填，可多选                                            |
| 活动内容     | 必填，最多 200 字，包含空格与换行                       |
| 活动照片     | 选填，最多 5 张，每张不超过 5 MiB；支持 JPEG、PNG、WebP |
| 备注         | 选填，最多 2000 字                                      |
| 具体参与人员 | 必填，自由填写文本，最多 4000 字                        |

默认九个标签：主题团日、支部事业、社会实践、志愿服务、学风建设、体育建设、美育建设、党团共建、宣传成果。

提交时间、填报人由系统记录。多标签活动的总活动数只计一次，标签分项分别累计。Excel 右侧保留提交时间、填报人和历史附加题目；照片列显示照片数量，原图在台账详情查看。

## 查看与修改范围

- 团支书填写被授权班级的活动，只查看本人提交的记录；同班其他填报人的记录不会共享。开放修改、未归档且未锁定时，可修改本人记录。
- 组织组有效岗位、有效全局辅导员岗位，以及已有业务管理员或台账管理者，可查看全局表格。全局查看能力不自动授予管理设置或修改他人记录的权限。
- 列表、详情、统计、照片和导出均由后端执行相同的记录权限。普通用户导出须由管理员开启，导出仍只包含本人可见记录。
- 截止事项和资料按其发布范围显示；当前团支书可读取负责班级的事项与资料。旧人工名册仅保留原有历史读取，不能代替当前团支书授权进行新填报或修改。

## 授权与班级配置

1. 具备本台账“管理设置”权限的管理员先维护班级目录，每行填写 `班级编号,班级名称`；已有活动引用的班级不能删除。
2. 发展端业务管理员或组织组同学进入本页面的“团支书授权”，搜索现有账号，核对用户名、姓名、学号，选择负责班级并保存。
3. 撤任时使用“撤销团支书”；换届时撤销前任、授权新任，历史记录归属保持原填报人。

授权复用统一账号和共享的 `class.youth_league_secretary` 班级标签，不另建人员关系。组织组的一般岗位只能管理这项团支书授权，不能由此授予其他组织身份、管理员身份或问卷管理权限。

## 新模板与历史记录

新空库自带正式班级活动表；仍须配置真实班级并授权团支书。已有问卷不会自动替换。管理者可在“管理设置”中点击“发布班级活动表”，明确发布一个新版本。

历史问卷、字段名称、单选活动类型和附件均保留；旧记录按原版本修改与校验。新记录使用当前发布版本，旧单标签在表格中自动按一个标签显示。归档学年保持只读。

## 存储与备份

生产必须配置绝对路径 `COLLECTIONS_UPLOAD_DIR`。台账问卷、记录和操作历史存于其 `organization-group/`，附件存于 `organization-group-assets/`；共享团支书授权在发展端数据库中。

完整备份须同时包含发展端 SQL 与上述文件目录。停止发展端写入后，按[数据库与业务数据管理](./data-administration.md#文件型业务资料也必须备份)生成并校验一致快照；恢复时在隔离环境核对本人/全局权限、团支书授权、活动记录和附件。仅导出 Excel 不能完整恢复台账。
