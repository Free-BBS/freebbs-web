# FREE BBS 管理员权限说明

本说明随本次版本上线生效。同一人兼任多个身份时，权限叠加。

| 身份                 | 管理权限                                                   | 财务权限                                               |
| -------------------- | ---------------------------------------------------------- | ------------------------------------------------------ |
| 最高管理员           | 双端全部设置；任免管理员及三类辅导员                       | 全系预算与报销、代发管理                               |
| 学习端管理员         | 学习端用户、课程及学习业务管理                             | 按实际组织岗位确定                                     |
| 发展端管理员         | 任免普通组织岗位和队长；组织配置、通知、奖励、业务模块开关 | 按实际组织岗位确定                                     |
| 发展端负责人         | 任免单独任命的发展端负责人；查看任命日志、运行状态         | 按实际组织岗位确定                                     |
| 团委书记、团委辅导员 | 自动获得双端管理员、发展端负责人权限                       | 查看全系财务；录入、导入预算；审批、退回及记录办理进度 |
| 学生发展辅导员       | 自动获得双端管理员权限                                     | 查看办公室·新生组、扬帆计划组财务                      |

最高管理员身份由平台配置确定，不能通过普通身份任命转授或撤销。

## 授权操作

1. 登录发展端，进入“管理员端 → 人员与组织 → 用户身份”。
2. 搜索用户名、学号或 UID，核对账号，选择实际岗位；队长需指定具体代表队。
3. 点击“保存身份设置”。

发展端负责人在“管理员端 → 负责人任命”中调整，点击“保存负责人设置”。换届时先任命接任人，再撤销旧岗位；历史记录保留。

学习端原有管理员身份在学习端用户管理中调整，取消额外任命不会撤销原有身份。

## 班级团支书授权

- 发展端管理员和组织组全体有效岗位可进入“组织组活动台账 → 团支书授权”，搜索已有账号，选择负责班级并保存或撤销。用户身份页也提供同一入口。
- 团支书只能填报被授权班级的活动、查看本人提交的台账；组织组和有效全局辅导员可查看全局。此授权不授予管理员或其他组织岗位权限。

班级目录与问卷仍由台账管理者维护，详见[组织组活动台账](./organization-group-ledger.md)。

## 财务权限随岗位生效

- 部门负责岗位：查看预算、提交本部门款项；修改本人草稿或退回记录，确认本人到账。
- 组织经费负责人：查看本组织各部门财务，记录报销已提交学校；科协选择“科协经费负责人”。
- 学生会执行主席、主席团及科协主席：查看本组织财务；提交款项需兼任对应部门负责岗位。
- 体育中心负责人、主任：额外查看全部代表队财务；提交范围为本中心。队长仅查看、提交所选队伍的款项。

BBS 同步记录办理进度；学校财务提交、代发邮件及实际打款仍按原流程办理。
